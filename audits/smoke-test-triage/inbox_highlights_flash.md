# inbox 第一批：1860s–1929 核心书目精选（Flash 速览）

> 依据 `sources/inbox_triage_part1.md` 的题名/年代初筛结果整理。判断均基于文件名与版本信息，尚未核验正文，入库后须由 `source-extractor` + `close-reader` 复核实际覆盖范围与原文语种。

## 一、最契合 1860s–1929 革命核心主题的 5 种

1. **《俄国革命史》（全三卷，托洛茨基）** — 1917
   1917 年革命的经典整体叙事，从二月到十月夺权的政治动力学分析。价值在于作者兼具在场者与理论建构者双重身份：叙述部分可作一手见证，其"不断革命论"解释框架须与西方社会史修正派对照，避免直接当作定论。

2. **《红色彼得格勒：工厂中的革命，1917–18》** — 1917–1918
   以彼得格勒工厂为单位的基层社会史，聚焦工厂委员会、工人自治与布尔什维克在车间层面的动员。正好补上"上层政治史"之外的社会史维度，是检验"十月是政变还是群众运动"这一争鸣的关键材料。

3. **《让工人成为苏维埃：权力、阶级和身份》** — 1917–1920s
   围绕"权力—阶级—身份"三条线追踪革命后工人自我认同与政权合法性的重构，衔接十月夺权与内战时期的阶级话语，是处理"soviet/苏维埃"概念语义漂移的核心参考。

4. **《平衡与非平衡：布哈林与普列奥布拉仁斯基之争》** — 1920s
   新经济政策时期党内经济路线论战（比例失调、原始社会主义积累、计划与市场）的专题研究，直接落在 1929 年"大转变"这一时间下限之前的思想前史，可与 `historiography/debates/` 中的 NEP 争鸣卡对接。

5. **《列宁再发现：在此背景下该做些什么》（Lars T. Lih）** — 1890s–1900s
   对 1902 年《怎么办？》的语境化重读，属革命起源问题（先锋队党与俄国马克思主义形成）的一流学术重构。可用于抵抗"列宁主义=先天极权"的目的论叙事。

**候补（视容量再取一种）**：托洛茨基《1905》— 覆盖 1905 年革命这一被忽视的"预演"环节，可与上述起源与 1917 叙事构成 1905–1917 连续谱。

## 二、超出 1929 下限的书目（建议另立"苏联后期史"支线，暂不进入核心库）

- **勃列日涅夫的十八年（苏联史第八卷，叶书宗）** — 1964–1982，与核心时段无关。
- **改革的孩子：莫斯科青少年谈论他们的生活和未来** — 1980s 末–1990s 初，口述史，属苏联解体期，无关。
- **士兵系列·焦土苏德战争（1943–1944）** — 军事史，无关。
- **斯达汉诺夫主义与苏联经济** — 1935 年起，超出下限且主题为斯达汉诺夫运动。
- **泥足巨人：苏德战争前夕的苏联军队** — 1930s–1941，主体在 1929 之后。
- **磁山：作为一种文明的斯大林主义（Kotkin）** — 主体为 1930s，仅边缘触及 1929。

**边界科目（起于 1920s、延至 1929 后，可有限征用）**：《发明敌人》（1920s–1953）、《斯大林时代：经济·镇压·工业化，1924–1954》、《斯大林的经济》、《斯大林模式的形成（苏联史第4卷）》、《20世纪20年代和50年代苏联远东地区的强制移民》、《俄罗斯—苏联在1917–1945 教科书第三卷》。前 1929 的段落可作背景，卡片论断不得越界引用其后内容。
