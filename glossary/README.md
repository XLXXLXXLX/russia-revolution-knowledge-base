# 概念系谱与政治术语消歧说明（`glossary/` & `cards/concepts/`）

俄国革命史（1860s–1929）的核心陷阱之一是**同一词汇在不同历史阶段与不同党派口中指代完全不同的社会现实**。

1. **名称消歧与化名映射**统一维护在 [`graph/aliases.yaml`](../graph/aliases.yaml)。
2. **具有重大理论张力与跨期语义漂移的核心概念**，应在 [`cards/concepts/`](../cards/concepts/) 下建立独立的 `CON-*` 概念系谱卡（例如 `CON-narodnichestvo` 民粹主义、`CON-soviet` 苏维埃、`CON-state-capitalism` 国家资本主义、`CON-smychka` 工农结合、`CON-kulak` 富农、`CON-socialism-in-one-country` 一国建成社会主义），按时间段分栏记录其词义裂变。
