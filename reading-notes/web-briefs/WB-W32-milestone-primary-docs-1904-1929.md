# W32 批次里程碑级历史原典入库汇总简报（1904—1929）

## 一、批次定位与史料总览

本批次（`W32_milestone_docs`）聚焦于 **1904年布尔什维克与孟什维克建党分裂、1905年第一场俄国革命策略分水岭、1917年二月革命罗曼诺夫王朝终结法理文书、1918年苏维埃国家资本主义与“左派共产主义者”论战、1923年“新方针”反官僚化大辩论，直至1928—1929年布哈林与斯大林围绕新经济政策（NEP）存废与强制集体化展开的终极路线决战**。

全批次共固化 **8 份 S 级一手历史原典**，全部落盘于 [`sources/web-archive/W32_milestone_docs/`](../../sources/web-archive/W32_milestone_docs/) 目录下，每份档案均严格按照本知识库规范配置：
1. **结构化 YAML 元数据头**（含真实可溯源外网 URL、俄国旧历 `[O.S.]` 与公历 `[N.S.]` 双重日期标定、俄国国家社会政治史档案馆 `РГАСПИ` / 俄联邦国家档案馆 `ГАРФ` 馆藏全宗号及权威出版物底本出处）；
2. **深度史料导读与概念防误读提示**（专门厘清二手文献常见的断章取义、同名文献混淆、倒签时间之谜及控辩文本引用链条）；
3. **多语种（俄、英、中、德）核心段落逐字对勘与完整一手原文固化**。

## 三、分篇核心史料价值与概念防误读要点解析

### 1. 1904年8月：托洛茨基《我们的政治任务》（“取代主义”预言与章节定位纠偏）
- **文件位置**：[`sources/web-archive/W32_milestone_docs/1904-08_trotsky-our-political-tasks-substitutism.md`](../../sources/web-archive/W32_milestone_docs/1904-08_trotsky-our-political-tasks-substitutism.md)
- **核心史料看点**：
  - 精确锁定俄国社会民主工党二大分裂后托洛茨基针对列宁《进一步，退两步》撰写的长篇论战小册子。
  - **关键防误读纠偏**：澄清西方史学引文中常将“取代主义（заместительство / substitutism）”三段式公式（*“党的组织‘代替’党，中央委员会代替党的组织，最后‘独裁者’代替中央委员会”*）误归入第四部分《雅各宾主义与社会民主党》的讹传——该公式实出于全书**第二部分（Part II: Tactical Tasks）末节《让政治“包办代替”一边去！》**，而将列宁比作罗伯斯庇尔的“马克西米利安·列宁（Maximilien Lenin）”及热月八日演说类比则出于**第四部分（Part IV）**。同时补齐了英文马克思主义文库（MIA）缺失的第四章第二节《对无产阶级的专政（Диктатура над пролетариатом）》。

### 2. 1905年7月：列宁《社会民主党在民主革命中的两种策略》（布尔什维克民主革命战略总纲）
- **文件位置**：[`sources/web-archive/W32_milestone_docs/1905-07_lenin-two-tactics-of-social-democracy.md`](../../sources/web-archive/W32_milestone_docs/1905-07_lenin-two-tactics-of-social-democracy.md)
- **核心史料看点**：
  - 完整对比1905年春布尔什维克伦敦三大与孟什维克日内瓦代表会议的相反决议，系统阐发“无产阶级和农民的革命民主专政（революционно-демократическая диктатура пролетариата и крестьянства）”口号、自下而上与自上而下相结合参加临时革命政府的行动条件，以及以“雅各宾派/平民方式”彻底清算沙皇专制制度并向社会主义革命过渡的理论链条。
  - **关键防误读纠偏**：专门警示俄文马克思主义文库中 `9-16.htm` 所收同名文章《Две тактики》实为1905年2月发表于《前进报》第6期的早期短文（载《列宁全集》俄文第5版第9卷），而非1905年6—7月撰写的这部单行本巨著（载第11卷）。

### 3. 1917年3月2—3日 [旧历]：尼古拉二世《退位诏书》与米哈伊尔大公《拒绝即位宣言》（二月革命法理闭环）
- **文件位置**：[`sources/web-archive/W32_milestone_docs/1917-03-02_nicholas-ii-abdication-manifesto.md`](../../sources/web-archive/W32_milestone_docs/1917-03-02_nicholas-ii-abdication-manifesto.md)
- **核心史料看点**：
  - 将1917年3月2日（公历3月15日）普斯科夫沙皇专列签署的尼古拉二世《退位诏书》与次日（3月3日/公历3月16日）彼得格勒米哈伊尔大公《拒绝即位宣言》合璧对勘。
  - **关键防误读纠偏**：详细考证了3月2日从下午“传位皇储阿列克谢”初稿到午夜“因不愿与患血友病的爱子分离而连同皇储一并退位、传位皇弟米哈伊尔”的戏剧性转折；揭示了尼古拉二世为何将深夜近午夜签署的诏书**倒签为古契科夫、舒利金抵达前的“15时05分”**；并从1797年保罗一世皇位继承法（《帝国根本法》第26—39条）视角剖析了代皇储放弃继承权的法理悖论，以及米哈伊尔大公如何通过“在普选立宪会议决定政体前拒绝接受最高权力、承认临时政府拥有全部权力”完成从君主主权向立宪会议主权的法理过渡。

### 4. 1918年5月：列宁《论“左派”幼稚性和小资产阶级性》（国家资本主义与NEP的思想先声）
- **文件位置**：[`sources/web-archive/W32_milestone_docs/1918-05_lenin-left-wing-childishness-state-capitalism.md`](../../sources/web-archive/W32_milestone_docs/1918-05_lenin-left-wing-childishness-state-capitalism.md)
- **核心史料看点**：
  - 完整收录1918年5月9—11日《真理报》连载的全部五节原文，聚焦列宁对布哈林、奥新斯基等“左派共产主义者”（《共产主义者》杂志第1期）的系统批驳。
  - **关键防误读纠偏**：突出固化第III节关于“没收（конфискация）容易、社会化（обобществление，即计算和监督）极难”的论断与**俄国过渡时期五种社会经济结构**（宗法农民经济、小商品生产、私人资本主义、国家资本主义、社会主义）的经典划分，以及第IV节“一个蛋壳里的两只鸡雏”（1918年德国的国家资本主义物质技术组织 + 苏维埃政权 = 社会主义）的论断，阐明该文为何在1921年春被列宁全文作为《论粮食税》单行本附录重印，并成为日后布哈林从极左转向捍卫新经济政策（NEP）的思想起点。

### 5. 1923年12月8日：托洛茨基《新方针》公开信及第一章《党内的辈代问题》（反官僚化论战引爆点）
- **文件位置**：[`sources/web-archive/W32_milestone_docs/1923-12-08_trotsky-new-course-open-letter.md`](../../sources/web-archive/W32_milestone_docs/1923-12-08_trotsky-new-course-open-letter.md)
- **核心史料看点**：
  - 完整收录1923年12月8日托洛茨基致莫斯科各区党员大会的公开信（12月11日刊于《真理报》第281号）、12月10日《后记》以及1924年1月单行本《新方针》序言与第一章《党内的辈代问题》中、英、俄三语全文。
  - **关键防误读纠偏**：还原了1923年12月5日政治局刚刚一致通过《关于党的建设》民主化决议后，托洛茨基为何在12月8日突然发出公开信，以第二国际领袖（倍倍尔、考茨基、伯恩施坦、盖得等）在议会与党机关膨胀中蜕变为机会主义者的历史教训，直接挑战“三驾马车（季诺维也夫、加米涅夫、斯大林）”自诩的布尔什维克“老近卫军（старая гвардия）”正统性，从而引爆1923—1924年冬俄共（布）党内大辩论。

### 6. 1928年7月10日：布哈林在联共（布）七月中央全会上的发言（反击“贡税论”与非常措施的第一场正面交锋）
- **文件位置**：[`sources/web-archive/W32_milestone_docs/1928-07-10_bukharin-july-plenum-speech-grain-and-smychka.md`](../../sources/web-archive/W32_milestone_docs/1928-07-10_bukharin-july-plenum-speech-grain-and-smychka.md)
- **核心史料看点**：
  - 首次将中文马克思主义文库译本（《苏联历史档案选编》第8卷 №05904）与俄国国家社会政治史档案馆原始速记本（`РГАСПИ Ф. 17. Оп. 2. Д. 375. Вып. II. Л. 50 об. – 66 об.`，刊于《苏联农村的悲剧》第1卷第319—355页）同档并列固化。
  - **核心交锋内容**：紧接斯大林1928年7月9日提出“超额税/类似贡赋（нечто вроде дани）”演说之次日，布哈林在全会上宣读各地农民暴动、老游击队员倒戈及国家政治保卫总局（ГПУ）截获的“继喀琅施塔得与1924年格鲁吉亚暴动之后的第三声警钟”报告，面对卡冈诺维奇、伏罗希洛夫等人的连番插话围攻，严正宣告决不能搞“非常措施的扩大再生产（расширенное воспроизводство экстраординарных мер）”，阐明“社会主义工业积累是农业积累的函数”，并痛斥令经济“头足倒立（экономика стала дыбом）”的超集中化官僚机关。

### 7. 1929年4月18日：布哈林在联共（布）四月中央全会上的发言（与斯大林4月22日演说构成完美控辩闭环）
- **文件位置**：[`sources/web-archive/W32_milestone_docs/1929-04-18_bukharin-april-plenum-speech-defense-of-nep.md`](../../sources/web-archive/W32_milestone_docs/1929-04-18_bukharin-april-plenum-speech-defense-of-nep.md)
- **核心史料看点**：
  - 完整固化布哈林在1929年4月18日晨会与晚会上的长篇抗辩演说（中译本全文+22条注释，以及1989年莫斯科政治书籍出版社俄文全本+110条档案校勘详注，总计逾50万字节），与本知识库已藏斯大林4月22日总结反驳演说 [`1929-04-22_right-deviation-in-cpsu.md`](../../sources/web-archive/E02_E10_core_classics/1929-04-22_right-deviation-in-cpsu.md) 形成**一字不漏的“辩方总陈述—控方总批驳”双边速记闭环**。
  - **关键防误读纠偏**：
    1. 厘清了**“军事封建剥削农民（военно-феодальная эксплуатация крестьянства）”**（出自布哈林1929年1月30日及三人2月9日书面纲领声明）与**2月9日政治局决议替斯大林“贡税（дань）”一词背书**之间的精确文件链条，完整呈现布哈林在4月18日讲台上对“贡税”范畴及粮食收购蜕变为“按户按口摊派的国家贡赋（государственная дань）”的痛斥；
    2. 完整收录布哈林当场宣读的**1928年6月1—2日致斯大林（“科巴”）私信全文**（*“国民经济不是执行秘书。你没法威胁要把它送交法庭，也没法冲它大吼大叫”*）与**农业积累问题笔记**（*“用一千张木犁也拼不出哪怕一台拖拉机”*）；
    3. 完整呈现布哈林对斯大林“阶级斗争必然日益尖锐化”奇谈的逻辑批驳、对卡冈诺维奇/米高扬伪造“富农和平长入社会主义”引文的当场对质、对列宁《论合作社》市场结合路线的捍卫，以及演说结尾“不要跑到加米涅夫那里去，但也不要用赤裸裸的肉体拳头政策（голая политика физического кулака）代替思想和思考”的悲壮疾呼。
