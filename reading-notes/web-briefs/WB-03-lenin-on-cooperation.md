# WB-03 列宁《论合作社》（1923）

1923 年已用公历。下列日期均为 `date_ns`，无俄历对照。篇名：俄《О кооперации》；英 *On Cooperation*（年表作 *On Co-operation*）；中文第2版标准译名《论合作社》，《论合作制》为旧译。

## 口授与发表

- **口授**：1923-01-04 与 1923-01-06。正文自署第一部分「4 января 1923 года」、第二部分「6 января 1923 года」。英文全集年表作 *dictates*（January 4, 6）；《列宁全集》中文第2版注〔242〕作「1923年1月4—6日口授」。
- **发表**：1923-05-26 与 1923-05-27，《真理报》第115号与第116号，署名 Н. Ленин。第5版题记：按秘书记录打字稿与报纸文本核对刊印。
- **刊前**：娜·康·克鲁普斯卡娅于1923年5月将文稿交俄共（布）中央。5月24日政治局决定尽快刊载，并在文后注明文稿所标日期（中文注〔242〕；瑞典文、西班牙文库注同此）。
