## 一、全书总命题与双重史学证伪

亚历山大·拉比诺维奇（Alexander Rabinowitch）在《布尔什维克掌权》（1976）中延续并深化了其前作《革命的序幕：彼得格勒布尔什维克与1917年七月起义》（1968），以高密度一手档案（党内会议记录、彼得格勒各区苏维埃纪要、驻军与波罗的海舰队决议、当时报刊及参与者早期回忆录）对1917年夏秋彼得格勒权力转移机制展开“自下而上”与“党内三层互动”的双重视角重构。

### 1. 对冷战西方主流/极权主义学派与苏联正统史学的双重证伪

### 2. 布尔什维克1917年胜利的两大结构性支柱

拉比诺维奇在《致苏联读者》和《尾声》中明确归因（`ch01#L13`, `ch18#L20-L24`）：
1. **相对民主、包容、去中心化的开放型群众政党结构**：1917年2月至10月期间，布尔什维克放弃了《怎么办？》时期的秘密职业革命家小团体模式，向成千上万新入党工人与士兵敞开大门（彼得格勒党员从2月约2,000人激增至6月底约32,000人）。地方党组织（彼得堡委员会与各区委）及军事组织拥有高度自主权，允许自由辩论与妥协，列宁在党内投票中多次受挫。这种“混乱但灵敏的弹性”使党能够迅速感知并顺应基层情绪。
2. **纲领与苏维埃合法性的高度契合**：战时经济崩溃、物价飞涨、前线溃败与临时政府一再拖延改革和停战，使其他所有主要政党（立宪民主党、孟什维克、社会革命党）因联合政府而信誉破产。彼得格勒工人与士兵将“一切权力归苏维埃！”理解为建立**民主的、多党参与的纯粹社会主义苏维埃联合政府**，而非一党专政。托洛茨基等谨慎战略家将夺权行动严密嵌入“保卫彼得格勒苏维埃与第二次全俄苏维埃代表大会”的合法框架之中，直至温和社会主义者退出大会才意外打开了全布尔什维克人民委员会（Sovnarkom）的道路。

## 二、逐章深度拆解（《致苏联读者》《前言》至第15章及《尾声》）

### 序幕：《致苏联读者》（`ch01`）与《前言》（`ch02`，覆盖 `1917-02` 至 `1917-06`）

- **学术史自述与方法论定位**（`ch01#L7-L15`, `ch02#L7-L28`）：拉比诺维奇回顾冷战时期求学背景，指出自己从1960年代起通过研读原始报刊与苏联已刊档案打破了“密谋政变论”成见，强调1917年布尔什维克民主实践随后在内战生存斗争中被削弱并被斯大林摧毁。本书选定彼得格勒为焦点，因其集政治首都（270万人口）、工商业中心（约39万工人，女性占三分之一）与布尔什维克最高总部及21.5万–30万驻军（含喀琅施塔得约3万水兵）于一体（`ch02#L12, L40-L42`）。
- **二月革命与《四月提纲》的党内折冲**（`ch02#L20-L40`）：`1917-02-23 [O.S.] / 1917-03-08 [N.S.]` 彼得格勒面包骚乱引发推翻沙皇；`1917-03-01 [O.S.] / 1917-03-14 [N.S.]` 彼得格勒苏维埃颁布《第一号命令》确立士兵委员会与武器控制权。`1917-04-03 [O.S.] / 1917-04-16 [N.S.]` 列宁返抵彼得格勒，其激进立场遭到以加米涅夫为首的党内温和派抵制。列宁妥协放弃“立即武装起义”，在 `1917-04-07 [O.S.] / 1917-04-20 [N.S.]` 发表《四月提纲》，主张耐心说服群众。在 `1917-04-14 [O.S.] / 1917-04-27 [N.S.]` 至 `1917-04-22 [O.S.] / 1917-05-05 [N.S.]` 的第一次彼得格勒全市代表会议上以37票对3票胜出；但在 `1917-04-24 [O.S.] / 1917-05-07 [N.S.]` 开幕的七月前全俄四月会议上，九人中央委员会中有五名温和派当选，保留了党内温和制约（`ch02#L35-L38`）。
- **四月危机、联合政府与六月示威交锋**（`ch02#L44-L58`）：`1917-04-20 [O.S.] / 1917-05-03 [N.S.]` 至 `1917-04-21 [O.S.] / 1917-05-04 [N.S.]` 针对米留科夫照会的大规模示威导致米留科夫、古契科夫辞职，五月组建第一届联合政府（策列铁里、切尔诺夫、斯科别列夫、克伦斯基等入阁），使温和社会主义者与不得人心的战争/经济政策绑定。布尔什维克党员从2月约2,000增至4月16,000、6月底32,000（`ch02#L49`）。第一次全俄苏维埃代表大会（`1917-06-03 [O.S.] / 1917-06-16 [N.S.]` 至 `1917-06-24 [O.S.] / 1917-07-07 [N.S.]`；代表中孟什维克与社革党占533席，布尔什维克仅105席）于 `1917-06-09 [O.S.] / 1917-06-22 [N.S.]` 迫使布尔什维克中央取消原定 `1917-06-10 [O.S.] / 1917-06-23 [N.S.]` 示威；但 `1917-06-18 [O.S.] / 1917-07-01 [N.S.]` 苏维埃自办40万人游行却几乎被布尔什维克“一切权力归苏维埃”标语淹没（`ch02#L50-L53`）。与此同时，彼得堡委员会激进派（如巴格达季耶夫）与军事组织在基层压力下屡屡突破中央克制，列宁在 `1917-06-18 [O.S.] / 1917-07-01 [N.S.]` 前线攻势开始后全力压制过早起义，疲惫之下于 `1917-06-27 [O.S.] / 1917-07-10 [N.S.]` 赴芬兰休养（`ch02#L55-L58`）。

### 第1章：七月起义（`ch03`，核心时段：`1917-07-03 [O.S.] / 1917-07-16 [N.S.]` 至 `1917-07-05 [O.S.] / 1917-07-18 [N.S.]`）

1. **三层党组织失调与危机爆发**（`ch03#L7-L34`）：`1917-07-02 [O.S.] / 1917-07-15 [N.S.]` 晚四名立宪民主党部长因乌克兰自治协议辞职，同时粮食、燃料危机与第5集团军前线抗命加剧。`1917-07-03 [O.S.] / 1917-07-16 [N.S.]` 中午，第1机枪团士兵发动武装示威并鼓动维堡区大型工厂（爱立信、新莱斯纳、俄罗斯雷诺）响应。当天下午党中央委员会试图阻止，但当晚在克舍辛斯卡娅宅邸，受驻军士兵压力的军事组织（涅夫斯基、波德沃伊斯基）与彼得堡委员会领导人眼见运动已不可逆转，公开支持并领导游行；中央随后被迫追认（`ch03#L28, L34`）。
2. **列宁返京与策略窘境**（`ch03#L7-L14, L29-L39`）：`1917-07-04 [O.S.] / 1917-07-17 [N.S.]` 清晨列宁乘火车急返彼得格勒，中午面对包围总部的一万名武装喀琅施塔得水兵，怒斥军事组织成员“该把你们都揍一顿！”，在阳台讲话中刻意强调和平示威，令渴求战斗的水兵与无政府主义者愕然（`ch03#L29-L30`）。此时党内意见撕裂：加米涅夫等右派坚决反对绕过苏维埃夺权；季诺维也夫与托洛茨基在7月3日白天支持遏制群众，7月4日深夜主张既已无法阻止则须主导并坚持和平性质；彼得堡委员会激进派（拉齐斯、中央委员斯米尔加）与军事组织（波德沃伊斯基、涅夫斯基）则等待武装推翻政府的信号（`ch03#L35-L39`）。
3. **“德国金钱”泄密与起义退潮**（`ch03#L40-L47`）：两项外部因素迫使起义流产：第一，北方战线受孟什维克与社革党控制的军队委员会开始向首都调遣混合部队；第二，司法部长佩列韦尔泽夫未经内阁批准，授权彼得格勒军区反间谍部门向中立团代表出示指控列宁为德国间谍的材料，并交由阿列克辛斯基和潘克拉托夫于 `1917-07-04 [O.S.] / 1917-07-17 [N.S.]` 晚发布声明（拉比诺维奇明确指出，德国在战时确实拨款支持颠覆活动，但毫无证据表明列宁在七月按德国指令策划起义，`ch03#L42`）。受此冲击，原中立团于 `1917-07-05 [O.S.] / 1917-07-18 [N.S.]` 凌晨进驻塔夫利宫保卫中执委，布尔什维克中央于凌晨2–3时决定撤退（`ch03#L45-L47`）。

### 第2章：在炮火下的布尔什维克（`ch04`，核心时段：`1917-07-05 [O.S.] / 1917-07-18 [N.S.]` 至 `1917-08` 中旬）

1. **媒体围剿与苏维埃向联合妥协退却**（`ch04#L7-L35`）：`1917-07-05 [O.S.] / 1917-07-18 [N.S.]` 晨，《活生生的词语》报刊出“列宁、加涅茨基、科佐洛夫斯基——德国间谍”通栏标题，右翼与温和派报刊齐声讨伐（唯高尔基《新生活报》例外）。`1917-07-07 [O.S.] / 1917-07-20 [N.S.]` 李沃夫因拒绝社会党人《原则宣言》（次日 `1917-07-08 [O.S.] / 1917-07-21 [N.S.]` 公布）而辞职，克伦斯基继任总理。面临西南战线第11军溃败，孟什维克费奥多尔·丹于 `1917-07-09 [O.S.] / 1917-07-22 [N.S.]` 深夜推动苏维埃执委会宣布临时政府为“拯救革命的政府”并授予全权，唯有马尔托夫（孟什维克国际派）与左翼社革党拒绝支持并要求全社会主义苏维埃政府（`ch04#L28-L33`）。至 `1917-07-21 [O.S.] / 1917-08-03 [N.S.]` 至 `1917-07-22 [O.S.] / 1917-08-04 [N.S.]`，克伦斯基以辞职要挟，组成“不对政党与苏维埃负责”的8名社会党人与7名自由派第二届联合政府（`ch04#L34-L35`）。
2. **搜捕、死刑恢复与地下逃亡争论**（`ch04#L36-L67`）：`1917-07-05 [O.S.] / 1917-07-18 [N.S.]` 士官生捣毁《真理报》；`1917-07-06 [O.S.] / 1917-07-19 [N.S.]` 政府军夺回克舍辛斯卡娅宅邸与彼得保罗要塞，印刷工沃伊诺夫遇害（唯一死亡的布尔什维克）；`1917-07-12 [O.S.] / 1917-07-25 [N.S.]` 前线恢复死刑。加米涅夫（`1917-07-09 [O.S.] / 1917-07-22 [N.S.]`）、科伦泰（`1917-07-13 [O.S.] / 1917-07-26 [N.S.]`）、托洛茨基与卢那察尔斯基（`1917-07-23 [O.S.] / 1917-08-05 [N.S.]`）相继入狱。列宁是否自首引发激烈分歧：加米涅夫、托洛茨基、诺金及彼得格勒基层活动家（沃洛达尔斯基、马努伊尔斯基）主张公开出庭打造“俄国德雷福斯案”；但在中执委代表阿尼西莫夫未能提供安全保证后，列宁于 `1917-07-08 [O.S.] / 1917-07-21 [N.S.]` 断然拒绝自首，次夜与季诺维也夫潜往拉兹利夫草棚（`ch04#L54-L59`）。`1917-07-13 [O.S.] / 1917-07-26 [N.S.]` 苏维埃执委会会议上，丹的谴责决议再次以压倒多数通过，克伦斯基与奇赫伊泽当众拥抱。

### 第3章：反动时期的彼得格勒（`ch05`，核心时段：`1917-07-06 [O.S.] / 1917-07-19 [N.S.]` 至 `1917-08` 中旬）

1. **舆论右转与哥萨克国葬**（`ch05#L7-L28`）：`1917-07-15 [O.S.] / 1917-07-28 [N.S.]` 政府为七月冲突中阵亡的7名哥萨克在伊萨基辅大教堂举行盛大葬礼，列强使节、克伦斯基与立宪民主党人高调宣誓“用铁与血”维持秩序。极右翼“神圣俄罗斯”等团体掀起反犹与暴力浪潮，甚至连孟什维克与苏维埃活动家（马尔克·李伯、尤里·斯捷克洛夫）也遭暴打或误捕（`ch05#L19-L23`）。`1917-07-18 [O.S.] / 1917-07-31 [N.S.]` 国家杜马临时委员会秘密会议上，普里什克维奇公然呼吁大规模绞刑与解散苏维埃，虽被米留科夫压下，却在左翼中敲响警钟（`ch05#L24-L28`）。
2. **狱中政治文化与绝食抗议**（`ch05#L29-L43`）：约130名“政治犯”关押于十字架监狱、约150人于第二区警察局、约30名军事组织骨干于第一区警察局。数周后监狱管理松弛，单人牢房化作辩论策略的“雅各宾俱乐部”（拉斯科尔尼科夫回忆激进青年指责党7月未夺权，托洛茨基亦一度闪过“或许当时该冒险”的念头但旋即回归现实力量评估，`ch05#L37`）。面对当局迟迟不起诉，第二区警察局囚犯于 `1917-08-02 [O.S.] / 1917-08-15 [N.S.]` 发动绝食，推动8月中旬起部分获释与公众同情回流（`ch05#L42-L43`）。

### 第4章：徒劳的镇压（`ch06`，核心时段：`1917-07` 中旬至 `1917-08` 中旬）

1. **镇压为何全面落空**（`ch06#L7-L20`）：拉比诺维奇逐项驳斥“临时政府系统摧毁布尔什维克”的苏联正统叙述：除第1机枪团、第180步兵团和掷弹兵团外，收缴武器遭工人抵制而迅速停止；驻军遣返因前线拒收与军区指挥混乱而半途而废；地方搜查多系中下级旧官僚越权所为（`1917-07-13 [O.S.] / 1917-07-26 [N.S.]` 军区司令波洛夫采夫因纵容过激行为被中执委逼迫去职）；司法机构（检察官卡林斯基）因阁员频繁更迭与无力证明德国间谍案而迟迟无法起诉，反令未受审的囚犯在工兵眼中沦为英雄（`ch06#L8-L20`）。
2. **党中央、彼得堡委员会与军事组织的真实裂痕**（`ch06#L21-L74`）：

### 第9章：新政权问题（`ch11`，核心时段：`1917-08-28 [O.S.] / 1917-09-10 [N.S.]` 至 `1917-09` 上旬）

### 第10章：“一切权力归苏维埃！”（`ch12`，核心时段：`1917-08-30 [O.S.] / 1917-09-12 [N.S.]` 至 `1917-09-30 [O.S.] / 1917-10-13 [N.S.]`）

1. **列宁的九月“和平妥协插曲”**（`ch12#L6-L30`）：身处赫尔辛基（其时斯米尔加当选激进的芬兰苏维埃执行委员会主席）的列宁于 `1917-08-30 [O.S.] / 1917-09-12 [N.S.]` 写信赞同首都同志，并于 `1917-09-01 [O.S.] / 1917-09-14 [N.S.]` 撰写《论妥协》提出：若孟什维克与社革党与资产阶级决裂，布尔什维克愿退回“一切权力归苏维埃”口号，不入阁而在苏维埃内和平竞争。尽管 `1917-09-03 [O.S.] / 1917-09-16 [N.S.]` 附言一度悲观，但直至 `1917-09-09 [O.S.] / 1917-09-22 [N.S.]` 的《革命的任务》《革命的一个根本问题》《俄国革命与国内战争》系列中列宁仍保留和平过渡可能（注：因发表与撰写时间差，长期被早期史学误读）。《工人之路》编辑部起初拒绝刊登《论妥协》，彼得堡委员会极左派（斯卢茨基、科罗明、布勃诺夫）在 `1917-09-07 [O.S.] / 1917-09-20 [N.S.]` 会议上也强烈抵制向妥协派让步（`ch12#L26-L28`）。
2. **托洛茨基接掌彼得格勒苏维埃与民主会议僵局**（`ch12#L30-L71`）：`1917-09-09 [O.S.] / 1917-09-22 [N.S.]` 彼得格勒苏维埃以 **519票对414票（67票弃权）** 通过布尔什维克关于按比例原则改组主席团的提案，迫使旧主席团退席；至 `1917-09-25 [O.S.] / 1917-10-08 [N.S.]` 改组完成（4布尔什维克、2社革党、1孟什维克），托洛茨基出任主席。在 `1917-09-14 [O.S.] / 1917-09-27 [N.S.]` 至 `1917-09-20 [O.S.] / 1917-10-03 [N.S.]` 的全俄民主会议上（布尔什维克仅占134席，远低于社革党532席与孟什维克172席），`1917-09-19 [O.S.] / 1917-10-02 [N.S.]` 表决陷入荒谬悖论：原则上通过联合（766对688），却又通过排除立宪民主党的修正案，导致整体决议以183对813惨败；次日 `1917-09-20 [O.S.] / 1917-10-03 [N.S.]` 虽以60对50票否决联合原则，却通过设立“预备议会”（共和国理事会），于 `1917-09-25 [O.S.] / 1917-10-08 [N.S.]` 催生包含4名立宪民主党人的第三次联合政府（`ch12#L60-L71`）。
3. **列宁九月中旬起义密信遭中央断然封杀，以及预备议会参会之争**（`ch12#L48-L59, L72-L84`）：列宁在 `1917-09-12 [O.S.] / 1917-09-25 [N.S.]` 至 `1917-09-14 [O.S.] / 1917-09-27 [N.S.]` 写出两封绝密信（《布尔什维克必须夺取政权》《马克思主义与起义》），路线骤变要求立刻在彼得格勒和莫斯科武装起义。`1917-09-15 [O.S.] / 1917-09-28 [N.S.]` 晚中央委员会紧急会议大为震惊（布哈林回忆“甚至一致考虑烧毁信件”），最终决定仅保留一份副本、严禁传达到基层与彼得堡/莫斯科委员会，并指派斯维尔德洛夫与布勃诺夫严防兵营和工厂发生起义鼓动，甚至故意在 `1917-09-16 [O.S.] / 1917-09-29 [N.S.]` 刊登列宁此前较为温和的《俄国革命与国内战争》以“伪装”其最新立场（`ch12#L54-L58`）。`1917-09-21 [O.S.] / 1917-10-04 [N.S.]` 中央委员会以9票对8票决定抵制预备议会，但当天联席会议上地方代表以 **77票对50票** 推翻中央决议、决定参加预备议会（托洛茨基反对、李可夫/加米涅夫赞成）。`1917-09-23 [O.S.] / 1917-10-06 [N.S.]` 决定于 `1917-10-20 [O.S.] / 1917-11-02 [N.S.]` 召开第二次全俄苏维埃代表大会，党中央随即号召“一切力量准备代表大会，绝不发动局部行动”（`ch12#L75-L84`）。

### 第11章：列宁：“立刻夺取政权！”（`ch13`，核心时段：`1917-09-22 [O.S.] / 1917-10-05 [N.S.]` 至 `1917-10-10 [O.S.] / 1917-10-23 [N.S.]`）

1. **列宁辞职威胁与悄然潜回彼得格勒**（`ch13#L7-L35`）：`1917-09-29 [O.S.] / 1917-10-12 [N.S.]` 前后列宁违反中央禁令潜回彼得格勒维堡区福法诺娃公寓，在《危机成熟了》中猛烈抨击中央“等待苏维埃代表大会是愚蠢的”，并因遭《工人之路》删稿与封锁而提出**退出中央委员会**以保留向基层和党代会鼓动的自由（中央从未讨论此辞呈，`ch13#L17-L23`）。10月初，列宁的呼吁逐渐突破封锁传至莫斯科州局（`1917-10-03 [O.S.] / 1917-10-16 [N.S.]` 洛莫夫在中央汇报但遭冷遇）与彼得堡委员会。
2. **彼得堡委员会的愤怒与10月5日大辩论**（`ch13#L35-L52`）：得知中央擅自扣压列宁信件后，彼得堡委员会一致愤怒于中央的“审查”行为。`1917-10-05 [O.S.] / 1917-10-18 [N.S.]` 彼得堡委员会召开秘密全体会议，拉希亚激进支持立即起义，而贴近基层的沃洛达尔斯基与拉舍维奇冷静指出粮食运输困境、前线疲惫与群众期待代表大会授权的现实（拉舍维奇质问“为什么必须在苏维埃代表大会之前现在就采取行动？”，`ch13#L45`）。同一天，中央委员会改变立场，以压倒多数（仅加米涅夫1票反对）决定从第一次会议起退出预备议会（`1917-10-07 [O.S.] / 1917-10-20 [N.S.]` 布尔什维克党团以微弱多数批准，托洛茨基当晚率53名代表宣读宣言退场；同日中央设立“反反革命斗争情报局”以图约束彼得堡委员会激进派）。
3. **10月10日/23日苏哈诺夫公寓会议的历史性决议与未解分歧**（`ch13#L56-L71`）：`1917-10-10 [O.S.] / 1917-10-23 [N.S.]` 晚，12名中央委员在孟什维克苏汉诺夫（其布尔什维克妻子弗拉克瑟曼安排）的公寓秘密开会。列宁历时近1小时力主立刻武装起义；加米涅夫与季诺维也夫则系统反驳，指出城市缺乏全面武装支持、农村与前线可能倒戈、欧洲革命尚未爆发、单独行动将促成反布尔什维克大联合，主张守势并依托立宪会议（`ch13#L61-L65`）。表决以 **10票对2票** 通过列宁用铅笔写在练习本上的决议，将武装起义“提上日程”。但拉比诺维奇强调：该决议并未设定起义日期，也未消除究竟“会前单独暴动”还是“依托苏维埃代表大会”的根本战略分歧（`ch13#L70-L71`）。

### 第12章：起义道路上的障碍（`ch14`，核心时段：`1917-10-11 [O.S.] / 1917-10-24 [N.S.]` 至 `1917-10-20 [O.S.] / 1917-11-02 [N.S.]`）

1. **北方地区苏维埃代表大会（`1917-10-11 [O.S.] / 1917-10-24 [N.S.]` 至 `1917-10-13 [O.S.] / 1917-10-26 [N.S.]`）未能成为起义引擎**（`ch14#L8-L30`）：尽管大会94名代表中极左翼占绝对优势（51布尔什维克、24左翼社革党、4最高纲领派），列宁于 `1917-10-08 [O.S.] / 1917-10-21 [N.S.]` 写信催促以此发动起义，但军事组织负责人涅夫斯基与波德沃伊斯基深知技术准备严重不足（赤卫队未成建制、铁路工会未争取、驻军尚未完全掌控）而力主推迟约两周；左翼社革党人（卡姆科夫、姆斯季斯拉夫斯基）也坚决反对绕过全俄代表大会发动单党冒险，最终大会仅通过把建立苏维埃政权留待全俄代表大会的克制决议（`ch14#L16-L27`）。
2. **10月15日彼得堡委员会与10月16日中央扩大会议的基层冷水**（`ch14#L36-L53`）：
   - `1917-10-15 [O.S.] / 1917-10-28 [N.S.]` 彼得堡委员会闭门会议上，军事组织代表涅夫斯基自嘲“军事组织突然变成了右翼组织”，直言外省、铁路与第5集团军均无准备，10月10日决议为时过早。19名各区代表汇报中，**仅8人称群众准备好起义，6人报告冷漠观望，5人直言群众毫无起义意愿**；莫斯科区拉维奇指出“群众会响应苏维埃号召，但很少响应党号召”（`ch14#L38-L43`）。
   - `1917-10-16 [O.S.] / 1917-10-29 [N.S.]` 在列斯诺沃-乌杰利宁区杜马召开的约25人中央扩大会议上，列宁虽雄辩说服众人，但克雷连科（军委）、沃洛达尔斯基、施密特（工会）、什利亚普尼科夫（金属工人工会）均作悲观汇报。投票中列宁确认10月10日决议的提案获 **19票赞成、2票反对、4票弃权**；季诺维也夫主张须先与代表大会布尔什维克党团磋商方可行动的提案虽以 **6票赞成、15票反对、3票弃权** 被否，但赞成与弃权合计9人（逾三分之一）显示反对立即孤立起义的势力强大，连投赞成票者（如米柳京）也仅视10月10日决议为一般方针而非即刻命令（`ch14#L47-L51`）。
   - 会后加米涅夫递交中央辞呈，并在 `1917-10-18 [O.S.] / 1917-10-31 [N.S.]` 非布尔什维克报纸《新生活报》公开反对起义，激怒列宁要求将其与季诺维也夫开除出党；但 `1917-10-20 [O.S.] / 1917-11-02 [N.S.]` 中央委员会断然拒绝开除要求，仅接受加米涅夫辞呈并禁止二人再公开发言（`ch14#L52`）。

### 第13章：卫戍部队动乱与军事革命委员会（`ch15`，核心时段：`1917-10-05 [O.S.] / 1917-10-18 [N.S.]` 至 `1917-10-24 [O.S.] / 1917-11-06 [N.S.]` 黎明）

1. **北方面军调防命令与“保卫苏维埃”防御策略的形成**（`ch15#L7-L33`）：德军攻占里加湾穆恩岛、埃泽尔岛（萨雷马岛）与达戈岛后，政府与罗江科迁都传闻四起。`1917-10-05 [O.S.] / 1917-10-18 [N.S.]` 政府下令调动彼得格勒卫戍部队赴前线（切列米索夫并于 `1917-10-09 [O.S.] / 1917-10-22 [N.S.]` 确认）。这“对布尔什维克简直是份礼物”：士兵惧怕上战壕，纷纷宣布只服从彼得格勒苏维埃。于是以托洛茨基为首的谨慎战略派形成一套“防御性伪装进攻”策略——借苏维埃而非党的名义、借“保卫代表大会与首都”之名动员群众（`ch15#L8-L10, L18-L22`）。`1917-10-17 [O.S.] / 1917-10-30 [N.S.]` 普斯科夫驻军与前线委员会谈判因彼得格勒代表拒绝签字而流产。
2. **军事革命委员会（MRC）的诞生与跨党派本质**（`ch15#L34-L50`）：驳斥《简明教程》将MRC说成10月10日中央起义决议直系产物的说法——托洛茨基早在 `1917-10-09 [O.S.] / 1917-10-22 [N.S.]`（中央会议前一天）即在苏维埃提出设立革命保卫委员会；`1917-10-16 [O.S.] / 1917-10-29 [N.S.]` 彼得格勒苏维埃全体会议正式批准，同日党中央才设立五人“军事革命中心”（斯维尔德洛夫、斯大林、布勃诺夫、乌里茨基、捷尔任斯基）隶属MRC。`1917-10-20 [O.S.] / 1917-11-02 [N.S.]` MRC首次组织会议推举左翼社革党人拉齐米尔任主席（执行局3布尔什维克+2左翼社革党），且中央在 `1917-10-20 [O.S.] / 1917-11-02 [N.S.]` 驳回军事组织独立领导起义的要求，列宁亦在 `1917-10-20 [O.S.] / 1917-11-02 [N.S.]` 至 `1917-10-22 [O.S.] / 1917-11-04 [N.S.]` 夜间秘密会晤中“打垮了军事组织推迟10–15天的最后抵抗”（`ch15#L38-L43, L48-L50`）。
3. **10月21–23日/11月3–5日的不流血夺权与23日晚的短暂妥协**（`ch15#L51-L81`）：`1917-10-21 [O.S.] / 1917-11-03 [N.S.]` 驻军会议宣誓效忠MRC；当晚拉齐米尔、萨多夫斯基、梅霍诺申赴军区司令部遭波尔科夫尼科夫拒认；`1917-10-22 [O.S.] / 1917-11-04 [N.S.]`（彼得格勒苏维埃日）托洛茨基连夜散发剥夺军区指挥权的宣言（“未经MRC副署的命令无效”），并在人民宫引发狂热宣誓；`1917-10-23 [O.S.] / 1917-11-05 [N.S.]` MRC完成全面派驻政委，且托洛茨基亲自进入彼得保罗要塞以演说赢得摩托车营与要塞驻军倒戈，控制克龙韦尔克军械库（`ch15#L56-L73`）。然而当晚在左翼社革党人与温和布尔什维克（梁赞诺夫）施压下，MRC竟一度宣布撤回10月22日宣言以求与军区妥协——此时克伦斯基却误判形势，决定 `1917-10-24 [O.S.] / 1917-11-06 [N.S.]` 黎明突袭查封《工人之路》《士兵报》并下令追捕MRC成员与重捕七月保释者（`ch15#L77-L81`）。

### 第14章：前夕（`ch16`，核心时段：`1917-10-24 [O.S.] / 1917-11-06 [N.S.]` 至 `1917-10-25 [O.S.] / 1917-11-07 [N.S.]` 清晨）

1. **克伦斯基黎明突袭与“防御性反制”**（`ch16#L7-L32`）：`1917-10-24 [O.S.] / 1917-11-06 [N.S.]` 黎明士官生查封《工人之路》印刷厂，彻底改变了形势。MRC发出《第1号指令》令驻军进入战备，托洛茨基派立陶宛团强行重开印刷厂。但当天上午的党中央会议（斯维尔德洛夫主持，列宁未到）依然采取“集中力量、等待代表大会”的谨慎路线（斯大林明确确认中央支持“集中力量”而非“立即起义”），托洛茨基下午在党团会议和晚间彼得格勒苏维埃仍强调“这是防御”，“逮捕政府并非独立日程，而是等待明日代表大会决定”（`ch16#L12-L29`）。
2. **预备议会否决克伦斯基与“桥梁争夺战”**（`ch16#L33-L58`）：下午克伦斯基在预备议会发表歇斯底里演讲要求授权镇压，却在晚8点30分遭丹与左翼派系提出的改革决议以 **123票对102票（26票弃权）** 击败（实质上的不信任投票）；当夜丹与戈茨赶赴冬宫敦促内阁立即宣布和平与土改以釜底抽薪，反被克伦斯基驱逐出门（`ch16#L34-L45`）。与此同时，政府试图升起涅瓦河桥梁封锁工人区，却在“桥梁争夺战”中败退；MRC不费一枪一弹占领中央电报局（17时）和彼得格勒通讯社，并于晚间致电赫尔辛福斯迪片科（暗语“请寄出章程”）调遣波罗的海舰队驱逐舰与水兵，而彼得格勒50万市民与多数工兵仍在各自工厂军营观望（`ch16#L50-L58`）。
3. **列宁夜赴斯莫尔尼与凌晨策略质变**（`ch16#L59-L89`）：被中央反复禁止前往斯莫尔尼的列宁焦虑到把中央否决条揉碎摔在地上，傍晚向基层区委发出《给中央委员的信》（“无论如何不能在25日之前把政权留在克伦斯基手中……进攻的拖延即是死亡”），随后戴假发缠绷带在拉希亚陪同下于午夜前潜入斯莫尔尼宫。尽管史料稀少（拉齐斯回忆列宁冲入彼得堡委员会房间施压，而波德沃伊斯基在晚上9点仍曾训斥提前设卡逮捕官员的泽尼斯），但在 `1917-10-25 [O.S.] / 1917-11-07 [N.S.]` 凌晨2时至8时之间，MRC从“纯防御等待大会”骤然转为“会前抢占要害推翻政府”：先后控制尼古拉耶夫斯基火车站、发电站（断电）、主要邮局、“阿芙乐尔”号放下尼古拉耶夫大桥、国家银行、中央电话局（7时）与华沙火车站（8时）。克伦斯基仅拼凑出约2,000名士官生、200名女兵与134名军官，哥萨克拒绝出动（`ch16#L60-L88`）。清晨中央委员会在斯莫尔尼第36号房间采纳托洛茨基提议，将新政府定名为“人民委员会”（Sovnarkom）（`ch16#L89`）。

### 第15章：布尔什维克掌握政权（`ch17`，核心时段：`1917-10-25 [O.S.] / 1917-11-07 [N.S.]` 至 `1917-10-26 [O.S.] / 1917-11-08 [N.S.]` 拂晓）

1. **上午宣言、克伦斯基出逃与冬宫漫长围困**（`ch17#L7-L73`）：`1917-10-25 [O.S.] / 1917-11-07 [N.S.]` 上午10时，列宁尚未等冬宫攻陷即发表《告俄国公民书》，宣布政权已转入MRC手中；11时克伦斯基借用美国使馆雷诺汽车与皮尔斯-阿罗轿车逃出首都赴前线求援；中午玛丽亚宫预备议会遭驱散；下午2时35分托洛茨基在彼得格勒苏维埃宣布临时政府已覆灭，列宁发表七月后首次公开演讲。然而军事行动却因协调混乱一再延误（火炮失修、找不到红灯信号、部分近卫团迟疑），冬宫内孤立无援的内阁任命立宪民主党人基什金为“独裁者”更加剧军区司令部辞职潮。晚6时30分最后通牒发出后，晚9时40分“阿芙乐尔”号发射空包弹，11时彼得保罗要塞实弹炮击；市杜马代表团高唱《马赛曲》赴冬宫“同死”半途被水兵劝返（`ch17#L38-L73, L99-L112`）。
2. **第二次全俄苏维埃代表大会的戏剧性分裂**（`ch17#L74-L98, L129-L148`）：晚10时40分大会在斯莫尔尼宫白厅开幕，670名代表中布尔什维克300人、社革党193人（半数以上为左翼社革党）、孟什维克68人、孟什维克国际派14人；问卷显示 **505名代表支持“一切权力归苏维埃”**，仅55人仍支持与立宪民主党联合（`ch17#L82-L83`）。关键转折在于：
   - 大会首先**一致通过**了马尔托夫提出的停止敌对、谈判组建全体民主联合政府的动议（连布尔什维克发言人卢那察尔斯基也表示“坚决没有任何反对意见”）；
   - 但右翼孟什维克与社革党（哈拉什、库钦、欣楚克、亨德尔曼及崩得埃利希）紧接着强烈谴责“阴谋冒险”并**示威性退出大会**；
   - 此举正中列宁与托洛茨基下怀，托洛茨基随即痛斥退席者“滚进历史的垃圾堆”，并在左翼社革党人（卡姆科夫）不安但留守的背景下推进议程（苏汉诺夫事后痛悔离席“亲手将垄断权交给了布尔什维克”，`ch17#L86-L98`）。
3. **冬宫和平接管与苏维埃合法化**（`ch17#L113-L148`）：`1917-10-26 [O.S.] / 1917-11-08 [N.S.]` 凌晨2时许，冬宫守军瓦解，安东诺夫-奥夫谢延科与丘德诺夫斯基未遇实质抵抗即进入内阁会议室逮捕剩余部长。凌晨5时大会以压倒多数（仅2票反对、12票弃权）通过列宁《告工人、士兵与农民书》，完成政权交接。

### 尾声（`ch18`，覆盖 `1917-10-25 [O.S.] / 1917-11-07 [N.S.]` 晚至 `1918-03` [N.S.] 及总反思）

- **大会立法、维克热尔谈判与清一色布尔什维克人民委员会定局**（`ch18#L7-L18`）：大会通过《和平法令》与借鉴左翼社革党纲领的《土地法令》，选出以加米涅夫为主席的新全俄中执委（62布尔什维克、29左翼社革党、6国际派孟什维克、4小左派）与清一色布尔什维克人民委员会（左翼社革党暂拒入阁以期调解）。`1917-10-29 [O.S.] / 1917-11-11 [N.S.]` 救国与革命委员会发动士官生暴动迅速失败；`1917-10-30 [O.S.] / 1917-11-12 [N.S.]` 克拉斯诺夫约千名哥萨克在普尔科夫高地被近十倍红军击退，克伦斯基逃亡。在全俄铁路工会（Vikzhel）罢工威胁下，加米涅夫、季诺维也夫等温和派一度于 `1917-10-29 [O.S.] / 1917-11-11 [N.S.]` 至 `1917-11-03 [O.S.] / 1917-11-16 [N.S.]` 推动全社会主义联合政府，却在军事危局解除后遭列宁与托洛茨基强硬回击；`1917-11-04 [O.S.] / 1917-11-17 [N.S.]` 加米涅夫等5人以辞去中央委员抗议最后通牒。数周后左翼社革党加入人民委员会，直至 `1918-03` [N.S.] 因《布列斯特和约》退出；立宪会议则于 `1917-11-12 [O.S.] / 1917-11-25 [N.S.]` 至 `1917-11-14 [O.S.] / 1917-11-27 [N.S.]` 选举并在 `1918-01-05 [O.S.] / 1918-01-18 [N.S.]` 首次会议后被解散（注：原译本注释4误作“1917年1月5日”，实为1918年1月5日旧历）。
- **总结性史学判词**（`ch18#L19-L29`）：内战彻底摧毁了1917年布尔什维克党的民主结构与苏维埃独立性；而1917年十月革命本身的胜利，既离不开战争与经济危机、极具号召力的纲领与军事工作，更决定性地取决于党相对民主分权的开放结构、以及托洛茨基等谨慎派将武装夺权与苏维埃合法性衔接的策略（`ch18#L22-L29`）。
