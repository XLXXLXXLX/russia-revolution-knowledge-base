# 深度精读札记：S. A. Smith《红色彼得格勒：工厂中的革命，1917—1918》
**聚焦主题**：1917年彼得格勒工厂委员会运动、“工人监督（Workers' Control）”的实践实质、工厂委员会与工会及布尔什维克党的张力，以及十月革命后从工人自治向国家集中管理的演变。

---

## 一、全书问题意识与彼得格勒工业无产阶级结构背景（Introduction & Ch. 1, 原书 pp. 1–13 / PDF pp. 13–25）

### 1.1 超越“经济斗争 vs. 政治斗争”的列宁主义二元论
- **核心理论介入**：史密斯指出，革命不仅是国家政权的崩溃与重构，更是社会关系的全面重组 `[p. 1 / PDF p. 13]`。在《怎么办？》（1902）中，列宁将自发的“经济斗争”（仅产生工联主义意识）与“从外部灌输”的社会民主党“政治斗争”严格对立；但1917年彼得格勒工厂的经验表明，这种僵化的二元划分必须修正 `[pp. 2, 140 / PDF pp. 14, 152]`。
- **生产领域的权力与“控制边界（Frontier of Control）”**：借用卡特·古德里奇（Carter Goodrich）的“控制边界”概念，史密斯论证生产过程中的权力分配本身就是阶级权力的核心战场 `[pp. 2–3 / PDF pp. 14–15]`。1917年国家政权陷入瘫痪后，工人们为保卫生活水平与工作岗位而发起的防御性斗争，迅速越过纯粹的工资/工时范畴，演变为夺取管理权并改造全社会权力平衡的进攻性政治斗争 `[p. 3 / PDF p. 15]`。布尔什维克的宣传固然重要，但革命意识首先是从工人解决生存危机的车间斗争及工厂委员会、工会等基层组织实践中内生出来的 `[p. 3 / PDF p. 15]`。

### 1.2 彼得格勒战时国家垄断资本主义与高度集中的工人阶级
- **国家与垄断资本的紧密纽带**：1917年彼得格勒人口达240万（欧洲第五大城市），其中68%以上出生在城市之外（1910年普查 peasants 占68.7%）`[pp. 5–6 / PDF pp. 17–18]`。彼得格勒不仅是帝国金融中心（私人商业银行资产占全俄四分之三），更是战时军工生产中心 `[pp. 6–7 / PDF pp. 18–19]`。全城及郊区拥有31家国有或国家控制大型企业（陆军炮兵总局辖管子厂 Trubochnyi 18,942人、枪弹厂 Patronnyi 约10,000人、奥赫塔火药厂 10,200人、谢斯特罗列茨克厂 6,228人等共5.3万人；海军部辖奥布霍夫厂 12,954人、伊热拉厂 8,902人、波罗的海造船厂 7,645人等共3.6万人），外加1916年被国家接管（sequestered）的普梯洛夫工厂（约3万人）和涅夫斯基造船厂（6,000余人）`[pp. 7–8 / PDF pp. 19–20]`。
- **空前的产业与规模集中度**：1914至1917年间，彼得格勒工厂工人从24.26万猛增至39.28万（含郊区达41.7万），其中国有企业雇佣134,464人（约占三分之一）`[pp. 9–10 / PDF pp. 21–22]`。按行业分布（Table 1），金属加工业独占 **60.4%**（379家企业，237,369人），纺织业占11.2%（44,115人），化工业占10.2%（40,087人），印刷造纸占6.8%（26,481人）`[pp. 10–11 / PDF pp. 22–23]`。按企业规模（Table 2），1917年高达 **67.9%**（正文中亦表述为约70%）的工人集中在1,000人以上的大厂，其中38家超过2,000人的巨型企业容纳了这批工人的三分之二；72家最大金属厂平均规模达2,923人 `[pp. 11–12 / PDF pp. 23–24]`。
- **空间邻近性与阶级两极化**：维堡区（含邻近郊区占工人总数25%）、纳尔瓦-彼得霍夫区（20%）、瓦西里岛（14%）等工业区紧邻贵族与资产阶级聚居的市中心，工人区恶劣的卫生与高死亡率（1915年维堡、纳尔瓦、科洛缅斯卡亚区千人死亡率分别为24.8、22.8、26.5，而海军部、喀山等富人区仅为8.7、11.2；普梯洛夫周边每间出租屋平均挤住4.1人）使阶级鸿沟触目惊心，直接催化了阶级意识 `[pp. 12–13 / PDF pp. 24–25]`。

## 二、“工人监督（Workers' Control）”的理论与实践实质（Ch. 6, 原书 pp. 139–163 / PDF pp. 151–175）

### 2.1 概念界定与对西方“工团主义（Syndicalism）神话”的批驳
- **概念边界**：苏联学者（如 Selitskii, Itkin）将工厂委员会的一切活动均归入“工人监督”，而史密斯赞同 Z. V. Stepanov 的界定，将“工人监督”限定于直接干预企业生产与商业运作、组织多边核算及调控生产与分配的措施（排除单纯的工资与工时斗争）`[pp. 139–140 / PDF pp. 151–152]`。
- **反驳西方主流学界（Avrich, Keep, Kaplan, Anweiler）**：
  - 保罗·阿夫里奇（Paul Avrich）将工人监督描绘为追求“无产阶级天国”的千禧年工团主义（chiliastic syndicalism），指责工厂委员会造成了“生产无政府状态”；约翰·基普（John Keep）断言代表们毫不在乎民主化对生产率和国民经济的破坏；弗雷德里克·卡普兰（Frederick Kaplan）甚至声称工人将监督视为所有权，把工厂变成了“股份制工人合作社”`[p. 141 / PDF p. 153]`。
  - **史密斯的实证证伪**：
    1. **无政府工团主义实际影响极其微弱**：连工团主义报纸《劳动之声》（*Golos Truda*）主编沃林（Volin）都承认1917年夏天彼得格勒无政府主义者“只是毫无影响力的一小撮人”`[p. 143 / PDF p. 155]`。在历次彼得格勒工厂委员会代表会议上，无政府主义提案得票极低：5月底第一次代表会议上，茹克（I. Zhuk）提案仅获45票（布尔什维克提案290票）；8月第二次代表会议上，沃林提案仅获8票（米柳亭提案213票赞成、26票反对、22票弃权）；10月全俄第一次工厂委员会代表会议上，茹克仅获5票（米柳亭获65票）`[p. 144 / PDF p. 156]`。
    2. **最初动因是挽救生产与保卫就业的实用主义（Pragmatism）**：面对1917年夏秋煤铁产量暴跌、铁路瘫痪、9月全俄工业品产量较年初下降40%的灾难性危机，工厂委员会推行“工人监督”的首要目的是**维持生产运转、防止关厂失业**，而非建立乌托邦公社 `[pp. 145–147 / PDF pp. 157–159]`。如普梯洛夫工厂委员会倡议召开第一次工厂委员会代表会议（由帕尔维艾宁厂布尔什维克委员会资助），左翼社会革命党人 V. M. Levin 在开幕词中明确指出：由于资方在供应燃料与原料上毫无作为，工人面临“饥饿沙皇”与失业威胁，因此工人组织必须联合干预工业生活 `[p. 146 / PDF p. 158]`。法俄机械厂（Franco-Russian works）与谢斯特罗列茨克兵工厂委员会均声明其首要任务是“不惜一切代价维持工厂生产”`[p. 147 / PDF p. 159]`。
    3. **燃料与原料监督的建设性实践**：早在3—4月，火神（Vulcan）与普梯洛夫厂委员会就开始搜寻燃料；从初夏起，管子厂、兵工厂、罗森克兰茨（Rozenkrantz）等委员会纷纷派“催货员（tolkachi）”赴顿巴斯和南俄找煤，普梯洛夫厂委员会甚至设立技术委员会将熔炉从矿物燃料改烧木柴 `[p. 147 / PDF p. 159]`。各厂委员会还相互调剂余缺（如三角橡胶厂工会代表委员会从罢工基金借给布伦纳厂1.5万卢布买原料，罗森克兰茨厂向巴拉诺夫斯基厂捐赠黄铜），并制止杜夫隆（Duflon）、马尔科夫（Markov）等厂资方高价倒卖金属库存、蓄意关厂的破坏行为 `[p. 148 / PDF p. 160]`。

### 2.2 二月至十月间“工人监督”演进的四个阶段
史密斯将二月至十月彼得格勒工人监督从“被动、防御、观察型（reactive, defensive and observational）”向“主动、进攻、干预型（active, offensive and interventionist）”的演变划分为四个阶段 `[p. 149 / PDF p. 161]`：
1. **第一阶段（3—4月）**：主要局限于国有企业；各厂普遍力图控制雇佣与解雇，作为工厂关系民主化的一部分，此时资方尚愿让步 `[p. 149 / PDF p. 161]`。
2. **第二阶段（5—6月）**：大多数工厂委员会开始监督原料与燃料供应并检查工厂运转效率；布尔什维克在此阶段取得运动内的政治领导权 `[p. 149 / PDF p. 161]`。
3. **第三阶段（7—8月）**：经济危机爆发，阶级斗争激化，资方转入反攻企图限制工厂委员会权力；部分委员会成立专门“监督委员会（control commissions）”全面清查订单与财务 `[p. 149 / PDF p. 161]`。
4. **第四阶段（9—10月）**：经济与政治危机空前严峻，部分雇主试图关厂，在3个案例中工厂委员会被迫接管企业经营；工人监督与车间民主化冲动结合，开始摸索“工人自我管理（workers' self-management）”，并全力投入“全部政权归苏维埃”的斗争 `[p. 149 / PDF p. 161]`。

### 2.3 围绕“经济控制”的政党政治与布尔什维克内部张力
- **孟什维克与社会革命党的“国家控制论”**：以切列瓦宁（F. A. Cherevanin）为代表的孟什维克主张由资产阶级临时政府实施强制辛迪加化、银行管制与价格配给，斥责基层“工人监督”只会加剧分散化与经济混乱 `[p. 151 / PDF p. 163]`；社会革命党官方同样反对单一阶级（工人阶级）垄断经济控制权，主张由代表生产者与消费者的国家统一调控 `[p. 152 / PDF p. 164]`。
- **列宁与布尔什维克的“国家工人监督（State Workers' Control）”**：
  - 针对西方学者（Avrich, Kaplan, Anweiler）指责布尔什维克在十月前机会主义地迎合工团主义以搞垮经济、夺权后立即背叛并镇压工厂委员会的论调 `[p. 150 / PDF p. 162]`，史密斯给出了四点有力反驳：
    1. 工厂委员会本身并非工团主义者，历次代表会议均压倒性支持集中协调的“国家工人监督”`[pp. 150, 157–158 / PDF pp. 162, 169–170]`；
    2. 在1918年初之前，列宁与布尔什维克根本没有意识到基层工厂委员会监督与国家集中经济组织之间存在内在矛盾，反而将群众自下而上的首创精神视为社会主义核算与监督（*uchet i kontrol'*）的基石 `[pp. 150, 155–156 / PDF pp. 162, 167–168]`；
    3. 工厂委员会骨干本身绝大多数就是布尔什维克党员，不能将党与委员会简单对立 `[p. 150 / PDF p. 162]`；
    4. 布尔什维克与孟什维克的分歧不在于“要不要国家集中控制”，而在于“**谁控制谁（who controls whom）**”——是官僚资产阶级国家还是苏维埃工人国家 `[pp. 153–154 / PDF pp. 165–166]`。
- **布尔什维克党内的重心差异**：
  - **中央经济学家与工会领袖派**（米柳亭 V. P. Milyutin、拉林 Yu. Larin，以及梁赞诺夫 Ryazanov、洛佐夫斯基 Lozovskii、施略普尼柯夫 Shlyapnikov、施密特 Schmidt）：强调自上而下的中央计划及苏维埃与工会的共同责任，甚至在全俄工会第三次代表会议和布尔什维克六大上几乎不提工厂委员会 `[pp. 158–159 / PDF pp. 170–171]`。
  - **工厂委员会中央理事会（CCFC）布尔什维克派**（斯克雷普尼克 N. A. Skrypnik、楚巴尔 V. Ya. Chubar'、安季波夫 N. K. Antipov、阿莫索夫 P. N. Amosov）：虽赞成国家工人监督，但高度强调基层委员会的主动性，认为经济危机主要源于资本家蓄意破坏（sabotage），相信依靠工厂委员会的果断干预即可恢复秩序 `[pp. 158–159 / PDF pp. 170–171]`。
- **车间层面的政治演进与“政治激进度≠监督激进度”悖论**：
  - 1917年春，纺织厂、鞋厂委员会多为无党派人士，金属厂委员会则由孟什维克和社会革命党占优（反映“革命护国主义”情绪）`[pp. 160–162 / PDF pp. 172–174]`。夏秋之际，工厂委员会最先反映底层左转，完成“布尔什维克化”（如长期为社会革命党堡垒的管子厂，6月初社会革命党获56%选票/21席、布尔什维克36%/14席；到10月13日改选，布尔什维克获9,388票占62%/23席，社会革命党跌至25%/16席）`[pp. 162–163 / PDF pp. 174–175]`。
  - **重要历史悖论**：一个工厂的政治激进程度与其实行工人监督的深度并无直接正相关！巴拉诺夫斯基、雷诺、诺贝尔等布尔什维克大本营的工人监督相当温和；相反，由社会革命党和孟什维克主导的伊热拉、波罗的海、新海军部、无线电报、枪弹厂、火炮厂、兵工厂、奥赫塔炸药厂等**国有军工企业**，反而推行了最系统、最激进的工人监督（源于熟练工人为保卫国防生产而接管管理的传统）`[p. 163, 256 / PDF p. 175, 268]`。

## 三、劳工运动的社会结构、工会与工厂委员会的张力及内部民主（Ch. 7 Tail, Ch. 8 & Ch. 9 Part 1, 原书 pp. 189–213 / PDF pp. 201–225）

### 3.1 骨干预备队（'Cadre' Workers）与新工人（妇女、农民工、青年）的分化
- **两类工人群体**：彼得格勒工厂工人分为两大群体：一是占总数约40%的无产阶级化、熟练、识字、男性为主的“骨干工人（cadre workers）”，他们拥有时间、薪酬、生产知识与组织资源，是工厂委员会和工会的创建者与领导层 `[pp. 190–191, 254 / PDF pp. 202–203, 266]`；二是战时涌入工业的约60%新工人（农民移民、女工、青年工人），往往被骨干工人视为缺乏纪律或盲目骚动的“落后群众（otstalye massy）”`[pp. 191–192, 254 / PDF pp. 203–204, 266]`。
- **新工人的直接行动（“独轮车推走”与暴动式集体谈判）**：
  - **女工**：占工厂劳动力三分之一（食品业66%、纺织业69%、化工业47%），虽大量加入工会，但在工会领导层（如金属、皮革、缝纫工会市理事会各仅1名女委员）和第一次工厂委员会代表会议代表（仅占4%）中极度缺乏代表性 `[pp. 193–194 / PDF pp. 205–206]`。面对资方拒不加薪，女工常采取直接行动，如6月底维堡纺纱厂和萨姆普ソ涅夫斯卡亚（Sampsionevskaya）棉纺厂女工两次将厂长（包括工厂主协会纺织部主席 L. G. Miller）塞进独轮车推到运河边或格列纳дер桥威胁扔下水 `[p. 193 / PDF p. 205]`。此外，女工在裁员时常遭男工排挤（如皮革女工 M. Tsvetkova 的控诉），而劳工领袖因忌惮“资产阶级女权主义”拒绝为女工设立专门组织 `[pp. 194–195 / PDF pp. 206–207]`。
  - **农民工与非熟练工（Chernorabochie）**：倾向于直接行动（如11月金属厂非熟练油漆工殴打金属工会代表逼签日薪12卢布命令；5月管子厂铸造车间农民工将社会革命党代表 Kapanitskii 塞进独轮车殴打并威胁扔进熔炉），但也在工资等级合同谈判和同乡会（zemlyachestva，全市约70个、会员达3万人，9月倒向布尔什维克）中逐步组织化 `[pp. 196–197 / PDF pp. 208–209]`。
  - **青年工人**：表现出比女工和农民工更强的自组织能力，建立了布尔什维克倾向强烈的“劳动青年社会主义联盟（SUWY）”，占彼得格勒布尔什维克新党员的19%、赤卫队员的28%，但在争取工厂委员会投票权时常遭遇成年男工的家长制排斥 `[pp. 197–200 / PDF pp. 209–212]`。

### 3.2 工会与工厂委员会的组织竞争、民主实践与官僚化潜流
- **工会与工厂委员会的张力（十月前夕）**：工会领袖（如布尔什维克的梁赞诺夫、施密特和孟什维克的林科夫 Lin'kov）指责工厂委员会搞“分离主义”，要求解散工厂委员会中央理事会（CCFC）并将其并入全俄工会中央理事会（ARCTU）；而无政府工团主义者（Piotrovskii）、左翼社会革命党（Levin）及 CCFC 布尔什维克领袖（斯克雷普尼克）则坚决捍卫工厂委员会的独立性 `[p. 189 / PDF p. 201]`。
- **直接民主与代议民主的结合（驳斥 Marc Ferro 早期官僚化论）**：
  - 工会按产业组建，到1917年夏彼得格勒金属工会已有近百名专职干部，权力渐向市理事会集中 `[pp. 200–203 / PDF pp. 212–215]`。
  - 相比之下，工厂委员会扎根单一企业、免费代表全体工人、在工作时间开会，远比工会贴近基层 `[p. 203 / PDF p. 215]`。工厂的最高主权机构是全体工人大会（general meeting），工厂委员会随时可被召回 `[p. 204 / PDF p. 216]`。
  - 针对马克·费罗（Marc Ferro）称十月前民众组织已从上下两端严重官僚化的观点，史密斯通过波罗的海造船厂（9月18日秘密投票改选）、谢斯特罗列茨克厂（8月投票率72%）、帕尔维艾宁厂（88%）、新莱斯纳厂（69%）、管子厂（10月投票率74%）等大量改选实证指出：十月前彼得格勒工厂委员会实现了直接民主与代议民主的惊人结合 `[pp. 204–206 / PDF pp. 216–218]`。
  - **韦伯式日常行政与理查德·海曼（Richard Hyman）式的领导依赖**：工厂委员会并非无政府状态，而是具有规章、分委会和书面记录的常设机构；同时，由于非熟练女工和农民工缺乏组织经验，高度依赖熟练男工骨干的专业知识与战略主动性，这种结构性不对称潜藏着在外部环境恶化时演变为官僚主义的危险 `[pp. 206–208 / PDF pp. 218–220]`。

### 3.3 十月革命后的《工人监督条例》与两条实施细则路线之争
- **耐人寻味的起草插曲（列宁比全俄工厂委员会理事会更重视基层监督）**：10月26日，全俄工厂委员会理事会（ARCFC）向列宁提交的法令草案竟然完全聚焦于建立中央经济调控机关（即后来的最高国民经济委员会 VSNKh），只字未提基层工人监督；反而是列宁批评了该草案，亲自起草了充满自由主义群众首创精神的《工人监督条例》（11月14日公布），赋予企业工人在生产、财务、行政上的全面监督权及对雇主具有约束力的决定权 `[pp. 209–210 / PDF pp. 221–222]`。这再次彻底击碎了“列宁一夺权就镇压工团主义工厂委员会”的西方史学迷思 `[p. 210 / PDF p. 222]`。
- **CCFC《实施细则》vs. ARCWC《实施细则》**：
  - **彼得格勒工厂委员会中央理事会（CCFC）《细则》**（12月7日刊于《消息报》）：极其激进，提出工人监督不是狭义的“简单检查（revizii）”，而是积极干预资本、库存、原料、能源与劳动力使用，作为向社会主义经济过渡及实现工人自我管理的第一步（同时纳入地方与中央国民经济委员会 sovnarkhozy / VSNKh 体系）`[pp. 211–213 / PDF pp. 223–225]`。
  - **全俄工人监督理事会（ARCWC）《细则》**（由金属工会布尔什维克主席 V. V. Schmidt 主持，工会占主导）：立场温和且强调集中制，要求将企业监督委员会置于产业工会监督分配委员会管辖之下，并规定“管理企业的行政（rasporyaditel'nye）权利仍归业主所有，监督委员会不参与企业管理，也不对其运营承担责任”`[p. 213 / PDF p. 225]`。

## 四、十月后的经济崩溃、工人阶级瓦解与向国家集中管理的演变（Ch. 10 & Conclusion, 原书 pp. 239–263 / PDF pp. 251–275）

### 4.1 “自下而上的国有化（Nationalisations from Below）”与管理体制演变
- **惩罚性与救急性的基层国有化诉求**：由于资方拒绝接受深入的工人监督并试图关厂（如火神厂 Vulcan 委员会控诉资方只接受名义监督却把责任推给监督委员会），工厂委员会纷纷请求政府查封或国有化企业，视之为避免倒闭的唯一出路 `[pp. 239–240 / PDF pp. 251–252]`。据 V. Z. Drobizhev 统计，1917年11—12月发出的836份剥夺工厂主法令中，**77%** 由地方机构发出；1917年11月至1918年3月间，全俄仅有 **5.8%** 的国有化或查封是由人民委员会（Sovnarkom）或最高国民经济委员会（VSNKh）中央直接实施的 `[p. 239 / PDF p. 251]`。在彼得格勒，据 M. N. Potekhin 统计，截至1918年4月1日，共有40家企业正式国有化，61家由工厂委员会临时接管经营，270家处于工人监督之下，402家（绝大多数为小作坊）仍由原主经营 `[p. 240 / PDF p. 252]`。
- **从工人管理到合议制（Collegial Management）再到一长制（One-Man Management）的博弈**：
  - 1918年3月列宁首次呼吁恢复一长制；在5月25日至6月4日第一次国民经济委员会（sovnarkhozy）代表大会上，委员会原草案主张国有化企业管理委员会三分之二成员由本厂工人选举，引起列宁震怒 `[p. 241 / PDF p. 253]`。
  - 最终通过的列宁-李可夫-韦恩堡（Veinberg）折中决议规定：企业管理委员会由州国民经济委员会（oblast' sovnarkhoz）提名1/3、VSNKh 或产业工会提名1/3、本厂工人选举1/3组成，并向 sovnarkhoz 负责 `[p. 241 / PDF p. 253]`。
  - 尽管中央集权不断加强，彼得格勒大厂工人对“一长制”进行了最顽强的抵制：1919年全俄仅10.8%企业实行一长制；直至1920年3月，彼得格勒200人以上工厂中仍有 **69%** 维持合议制管理委员会 `[pp. 241–242 / PDF pp. 253–254]`。

### 4.2 战时资本主义崩溃与彼得格勒工人阶级的“十室九空（Decimation）”
- **军工复员、饥荒与大逃离**：随着苏维埃政府讲和停战，高度依赖军工订单的彼得格勒经济彻底失去支柱。1918年初面包配给从1月27日的每日150克降至2月14日的100克，2月28日更跌至极度饥饿的 **50克/日**，加上德军逼近普斯科夫引发的恐慌，导致1918年上半年超过100万人逃离彼得格勒 `[pp. 242–243 / PDF pp. 254–255]`。
- **工人力量的灾难性萎缩（Table 15）**：据 Potekhin 数据，彼得格勒调查的773家企业中，到1918年4月1日已有231家倒闭（其中金属业213家中倒闭109家）；全市工厂工人总数从1917年1月1日的 **351,010人** 暴跌至1918年4月1日的 **148,710人**（仅剩约40%），其中金属工人从167,192人锐减至43,129人，橡胶业（三角橡胶厂等）从17,228人跌至756人 `[pp. 243–245 / PDF pp. 255–257]`。
- **布尔什维克骨干的流失**：离开工厂的不仅是非熟练工（占申领疏散路费者的53%），最坚定的布尔什维克熟练骨干与青年工人也成批参军（4月前约6,000名彼得格勒工人加入红军）、参加征粮队或进入新国家与党务机关。彼得格勒布尔什维克党员从1917年10月的约 **43,000人**（三分之二为工人）锐减至1918年6月的 **13,472人** `[p. 244 / PDF p. 256]`。

### 4.3 劳动纪律危机、工厂委员会并入工会与国家集中化结局
- **劳动生产率崩溃与严厉纪律措施**：斯特鲁米林（Strumilin）对27家彼得格勒工厂的调查表明，劳动生产率下降近一半源于工人身体极度饥饿衰竭，仅21%源于纪律与动机衰退 `[p. 248 / PDF p. 260]`。但在经济绝境下，施略普尼柯夫（3月20日宣布铁路集中管理与独裁全权）、全俄工会中央理事会（4月2日提议恢复计件工资、定额、奖金与劳动手册）以及基层工厂委员会自身（如普梯洛夫、涅夫卡棉纺厂委员会）均不得不将恢复劳动纪律置于首位，甚至在1918年5—6月严厉谴责普梯洛夫电工罢工、关闭怠工的奥布霍夫工厂并解散其原工厂委员会 `[pp. 247–250 / PDF pp. 259–262]`。
- **工厂委员会从属于工会与官僚化趋势**：1918年初，随着工厂倒闭与工人逃离，工厂委员会被正式并入工会成为其基层机构；劳工组织不再仅仅对工人负责，而是对布尔什维克政府负责，部分委员会（如管子厂、诺贝尔厂、老莱斯纳厂、枪弹厂）开始拒绝全体大会的改选要求以推行不受欢迎的纪律政策 `[pp. 251–252, 260 / PDF pp. 263–264, 272]`。
- **全书总结论：意识形态局限与客观物质绝境的双重塑造（Conclusion, 原书 pp. 253–263 / PDF pp. 265–275）**：
  - 史密斯一方面肯定自由意志左翼学者莫里斯·布林顿（Maurice Brinton）与毛派经济学家夏尔·贝特兰（Charles Bettelheim）的批评洞见：列宁与布尔什维克主流确实将资本主义大工业的生产组织与技术（一长制、泰罗制、计件工资）视为“社会中立（socially neutral）”的工具，认为无产阶级政权的性质取决于中央国家政权而非生产现场（point of production）的工人权力，忽视了工厂不仅是产品生产场所、更是等级社会关系再生产（reproduction）的场所 `[pp. 261–262 / PDF pp. 273–274]`。
  - 但另一方面，史密斯严厉批评贝特兰忽视生产力水平约束的“极端唯意志论（grossest voluntarism）”`[p. 263 / PDF p. 275]`。正如马克思在《德意志意识形态》中所言，没有足够的生产力发展水平，“匮乏就只是普遍化了”，争取必需品的斗争必然使一切陈腐污浊之物死灰复燃 `[p. 263 / PDF p. 275]`。1918年春战时资本主义崩溃、饥荒与工人阶级自身解体这一毁灭性的客观物质绝境，才是导致车间民主与工人自治让位于国家集中管理与官僚化的决定性结构力量 `[pp. 259–263 / PDF pp. 271–275]`。
