## 一、对读问题：同一苏联现象，两种不可通约的解释框架

| 维度 | 霍夫曼（Modernity School） | 官方《反对托洛茨基主义斗争》 |
| :--- | :--- | :--- |
| 苏联国家能力从何而来 | 泛欧洲“重塑社会”冲动 + 社会科学 + **1914–1919总体战/内战** 技术延续与极端化 | 列宁布尔什维克路线 vs 机会主义/中派/托洛茨基主义 **原则对立** 的党性史 |
| 监控、svodki、宣传 | 一战参战国普遍实践，经临时政府—契卡—OGPU **制度化**（`ch07` `pp. 112–128`） | 本书几乎不涉及；托洛茨基问题被框定为组织—路线而非治理技术 |
| 福利/卫生/人口 | 非马克思主义独创；沙皇—临时政府—苏维埃 **连续扩张**（`ch04–06`） | 不讨论；托洛茨基=“中派面纱下的孟什维克” |
| 托洛茨基 | 引1924年《文学与革命》“人类塑形”作为现代主义愿景例证（`ch05` `p. 50`）；内战期红军政治启蒙与临时政府/白军 **同质技术**（`ch07`） | 1903起**一贯敌对**；1905苏维埃=调和机会主义；1917入党=权宜之计 |
| 史学使用方法 | 比较史、技术与制度连续体 | 列宁语录 + 党的文件 + 驳“资产阶级伪造者”（多伊彻等） |

本札记的核心命题：**霍夫曼把1929年以前的苏维埃国家治理读成欧洲现代国家实践的苏联变体；官方史把同一时期的党内斗争读成真正的马克思主义与托洛茨基中派主义的永恒战争。** 二者可并置，不可互替。

## 二、霍夫曼：苏联社会主义作为欧洲现代性的特殊形态（导言，`pp. 8–16`）

### 2.1 “培养群众”悖论与双重人口政策

导言以斯大林“园丁”隐喻与1937–38处决统计并置，提出全书主轴：斯大林体制同时追求 **压制性清除** 与 **教养性培养**（卫生、福利、扫盲、高雅文化、鼓励生育）（`pp. 8–9`）。这并非简单“虚伪”，而是要把“积极/消极”人口政策一并纳入对体制的理解。

### 2.2 多元现代性 vs 意识形态特异论

霍夫曼拒绝以西欧议会—资本主义为唯一现代性尺度，援引 Eisenstadt“多元现代性”（`p. 9`）。苏联的解释路径强调：

1. **俄国革命前专业人士** 的培育主义（拉马克式环境论）与马克思主义契合，但马克思主义只是“诸多变革意识形态之一”（`pp. 9–12`）。
2. **马克思列宁主义未提供社会政策蓝图**；大量政策由非党专家制定（`p. 9`，平诺、比尔等所论）。
3. **历史偶然性**：国家形成于总体战与内战，“传统约束（议会、法院、财产权）”缺位 → 干预呈极端形态（`pp. 12–13`）。

### 2.3 至1929年的党内经济分歧（技术官僚—NEP—大转折）

导言简述：工人反对派、托洛茨基劳动军事化、列宁 NEP+技术官僚被拒；1920年代末“大转折”=取缔贸易、计划工业化、集体化、公审专家（`pp. 13–14`）。要点：**斯大林主义并非技术官僚统治**——党真理高于科学真理，但仍依赖非党专家（`pp. 14–15`）。这对读知识库中布哈林/1930年代 debates 时，应把 **国家社会福利扩张**（第一个五年计划）与 **意识形态对专家的再驯化** 看作同一“社会主义攻势”的两面。

### 2.4 五章架构（本任务截取至1929）

- **福利**（`ch04`）：官房主义—社会科学—福利与战争纽带；俄一战激化；临时政府国家救济部；苏维埃1918社会保障法令、阶级歧视福利、NEP时期“纸面福利”、1928–29 计划经济与工厂供给制。
- **公共卫生**（`ch05`）：社会医学、1916沙皇卫生总局构想、1917医学-卫生中央委员会、1918卫生人民委员部、地方自治医生转入苏维埃体系。
- **生育**（`ch06`）：一战人口损失统计、1920年代合法堕胎与国际化人口学会议；为1930年代堕胎刑事化埋伏笔（本札记下限前只取至1920年代统计官僚思维）。
- **监控与宣传**（`ch07`）：一战信件审查与“情绪”报告（霍尔奎斯特）、契卡85号令（`p. 112`）、1921后 OGPU 续存、1922年中央委员会每日/周/月 **群众情绪** 报告、1927年战争恐慌专项报告（`p. 125`）、1929年布勃诺夫教育“阶级斗争”转向（`p. 135`）。

## 三、总体战连续体：1914–1917–1929（霍夫曼 ch04–07）

### 3.1 福利：从慈善到“人力资本”义务（`ch04` `pp. 323–541`）

**欧洲共性**：十九世纪末军队体质与人口质量；一战迫使各国扩大抚恤、保险、军人家庭津贴。俄国1912年杜马保险法仅覆盖23%产业工人（`p. 34`）。

**一战俄国**：皇室慈善与国家拨款并行；1915–16难民高达500万；救济从慈善转向 **公民权利** 话语（`pp. 36–37`）。1917年5月临时政府设立国家救济部、劳工部、粮食部——与奥地利1917、英国1916养老金部同期（`pp. 37–38`）。

**苏维埃1918–1929**：

- 继承并国有化慈善资产；1918年10月《劳动者完全社会保障条例》；**阶级排斥**（1918宪法剥夺“阶级敌人”救助权）（`pp. 39–40`）。
- 内战与破坏使1917–21社会保险 largely 纸上谈兵；1921 NEP **收缩** 福利，优先工人与红军（`pp. 41–42`）。
- 1924–27社会保险支付约翻倍，但资源不足、信函投诉普遍（`p. 42`）。
- **1928–29**：第一个五年计划消灭失业→取消失业救济；工厂“封闭合作社”与工人供应处（`pp. 43–45`）；1929配给制剥夺“阶级异己”购粮权（`p. 43`）。  
→ 与 Velikanova 札记中1927战争恐慌、收购危机可并读：霍夫曼强调 **国家以人力生产效率定义福利**，非人道主义权利话语（`pp. 47–48`）。

**德国战时经济模式**：尤里·拉林推崇德国1916劳动征用；列宁、托洛茨基均参与计划机构创设（`pp. 46–47`）——**托洛茨基在霍夫曼叙事中是计划国家建设者之一**，而非路线斗争中心。

### 3.2 公共卫生：社会医学顶峰而非社会主义独有（`ch05` `pp. 50–61`）

核心论断：苏维埃医疗 = 社会医学国际趋势 + 俄地方自治医师传统 + 疫病危机下的集权。

- 1916沙皇设立国家卫生保护总局（未及实施）；1917年8月临时政府后继职业化卫生主张。
- 1918年7月卫生人民委员部；1918年12月药房国有化（`pp. 55–56`）。
- 皮罗戈夫学派医生1919年承认“苏维埃医学”与公共医学目标一致（`p. 58`）。
- **苏联特色（至1920年代）**：强调环境—社会卫生学胜过隔离主义（鲍德温论点，`pp. 59–60`）；诊疗所制度延续地方自治实践。

与韦利卡诺娃 *svodki* 研究：`ch07` 将民情简报与一战欧洲 **情绪治理** 同构，而非仅从契卡意识形态推导。

### 3.3 人口与生物政治（`ch06` 截取 `pp. 81–85`）

一战使人口成为国防核心资源（德国总参谋部1917备忘录、英国1915议论）。苏联：

- 中央统计局与卫生人民委员部战时损失委员会：把伤亡与 **劳动力/军事潜力** 统计并列（`pp. 84–85`）。
- 拒绝法西斯式种族优生竞赛表述，而以 **社会主义vs资本主义生育率** 意识形态比较（`p. 85`）。
- 1920年堕胎合法化（后文1936禁止，超出本札记下限）。

→ 生物政治在霍夫曼笔下是 **国际人口政治学** 的苏联版，突出劳动母亲与劳动力市场双重角色（导言 `p. 16` 预告）。

### 3.4 监控（svodki）与宣传：从总体战到 NEP 警惕（`ch07` `pp. 112–128`）

**一战欧洲**：法国1916起系统分析士兵来信；英国1917邮政审查扩至全民士气；俄国内政部1915年10月起省警察局月度“情绪”报告（`pp. 113–115`）。

**1917临时政府**：社会政治启蒙中央委员会彩色地图、政治委员周报表格（`pp. 115–118`）——与韦利卡诺娃所说1917年政治化情报 **谱系一致**，但霍夫曼强调 **制度模板早已存在**。

**苏维埃**：

- 列宁引用契卡 **1922年2月23日第85号令**：“国家信息工作的首要任务是掌握各阶层民众的情绪动态”（`p. 112`）。
- 监控非布尔什维克发明：继承沙皇/临时政府人员与技术，**意识形态化嫁接**（`pp. 127–128`）。
- **1921–29**：第十一次代表大会对NEP“蜕化”恐惧；1922年监视“小资产阶级元素”；中央1921年9月通告要求党支部报告工人/农民情绪（`pp. 122–123`）； **`信息指导部` 汇总** + 报纸来信呈送斯大林（`pp. 124–125`）。
- **1927**：OGPU专项报告战争危险与富农煽动（`p. 125`）——可对照 `CLM-velikanova-2013-*` 与 `RN-W8-1927-war-scare-and-grassroots-svodki.md`，霍夫曼提供 **欧洲比较—一战起源** 框架，韦利卡诺娃提供 **1927危机机制** 档案细读。
- **1929**：教育人民委员布勃诺夫号召学校参与对富农、宗教、文盲的“阶级斗争”（`p. 135`），标志政治启蒙从杜威式扩权转向动员教条。

**宣传**：列宁1902年宣传/鼓动区分；1917后电影国有化、扫盲法令（1919）、政治教育总委员会（1920）、红军政治部门预算4.5亿卢布（1919下半年）（`pp. 128–132`）；白军信息宣传局 **同质**（`p. 133`）；1928–31大转折强化技术培训与反宗教（`pp. 134–135`）。

**对读杜威**（`ch07` `p. 113` 引1928年）：霍夫曼以此说明苏联 **教养革命** 与西方进步教育话语的共振；官方托洛茨基史对此完全沉默。

## 四、官方史：反托洛茨基主义范式的结构与史学属性（`pp. 3–15`, `51–55`, `101–104`）

### 4.1 文献性质（论断卡须明示）

- 写作依据：列宁著作、党的文件、档案与“已发表资料”（`p. 9`）。
- 目的：**当下政治**——1967年苏共中央决议号召加强党史中反对“托洛茨基分子、右倾机会主义者”的叙述（`p. 9`）；1925年全会要求宣传统一解释托洛茨基主义（`p. 9`）。
- 理论框架：帝国主义时代工人运动 **两大倾向**（资产阶级机会主义 vs 无产阶级革命）；托洛茨基主义=俄国 **考茨基式中派主义**，社会基础=工贵与小资产阶级（`pp. 3–4`）。
- 对学术史立场：点名驳多伊彻、布拉姆、夏皮罗等“资产阶级伪造者”，指控其“用托洛茨基主义代替布尔什维主义”（`pp. 9–10`）。

**使用规则**：此书是研究 **苏联正统记忆政治** 与 **1920–60年代党内言说的史源**，不宜单独支撑关于1905苏维埃或1912八月联盟的 **经验结论**；应配对列宁全集、苏联史学及西方修正研究。

### 4.2 范式核心命题（1903–1917）

1. **1903**：托洛茨基在纲领表决中与阿基莫夫合流，以“党与阶级融为一体”否定无产阶级专政可行性（`pp. 12–13`）；在党章第一条上站马尔托夫，“建立西欧式改良主义政党”（`pp. 14–15`）。
2. **1905**：托洛茨基在苏维埃 **调和布尔什维克与孟什维克**，拆除分歧；反对总罢工/武装起义路线（如10月21日停止罢工）（`pp. 51–55`）；列宁提出“既要苏维埃又要党”，苏维埃=起义与民主专政萌芽——官方史坚决否定“列宁反苏维埃”的传说（`pp. 52–54`）。
3. **1910–1912**：托洛茨基=取消派财政与《维也纳真理报》；布拉格会议与 **八月联盟** 是“斯托雷平式工人党”阴谋；列宁定性：“用革命词句掩护取消派”（`pp. 101–102`）。
4. **1914–1917**：托洛茨基“不胜不败”=社会沙文主义；“中派”不相信反本国政府革命（`pp. 7–8`）；1917年入党 **未放弃孟什维克观点**（`pp. 8–10`）。

## 五、交汇与盲区

### 5.1 可合成的经验层面（至1929）

- **国家救济—卫生—邮政审查** 在1914–1918的确存在强烈连续性（霍夫曼 + 霍尔奎斯特 + Velikanova 三方可互证）。
- **1920年代OGPU/党支部情绪报告** 是治理技术，不限于“反托派”——官方史若只从路线斗争理解1920年代党内紧张，会 **低估** 对上野情绪与技术官僚信息饥渴的结构作用。

### 5.2 不可简单折中之处

- 托洛茨基1903–1917政治轨迹：官方史的一贯敌意叙事 vs 霍夫曼将其作现代国家建构参与者（计划、红军启蒙）——需回到 **`CLM-getzler-1967-martov-1903-clause-one`**、列宁一手文献等 **A/S级** 材料裁定，不能用霍夫曼全书替代。
- 苏联暴力规模：霍夫曼在导言与第5章将切除暴力置入殖民—一战集中营谱系；官方本书 **不讨论** 契卡监控的帝制—战时起源，读者若只读官方史会得到 **去技术化、纯党性** 图景。
