# 论断：1922–1929年中央书记处/政治局档案揭示斯大林通过垂直人事监督与三次“辞职最后通牒”垄断党权，并在涅姆钦诺夫商品粮统计与1928年初西伯利亚征粮危机冲击下发动“乌拉尔-西伯利亚”非常措施与1929年底全盘集体化

## 原文提炼

《斯大林 1878–1953（主要文献）》所载1922年至1929年底的中央委员会、政治局与总书记绝密通信表明，斯大林在1920年代末终结新经济政策（NEP）并转向“大转变”是由**制度集权机制**与**粮食危机统计冲击**双重驱动的：
1. **中央书记处垂直官僚机器的建立（1922.04）**：自 `1922-04-03` 出任总书记起，斯大林掌控了政治局议程制定、高级干部人事任免（组织分配部）以及705人中央机关的管理权，确立了上级对下级决议执行的垂直监督体系；
2. **以退为进的三次“辞职最后通牒”（1924–1927）**：针对列宁“政治遗嘱”引发的合法性危机，斯大林于 `1924-08-19`、`1926-12-27` 和 `1927-12-19` 三次提交辞去总书记职务的声明，利用党内对分裂的恐惧迫使政治局与中央全会（包括加米涅夫、季诺维也夫、李可夫等人）全票挽留，彻底瓦解左翼反对派；
3. **涅姆钦诺夫商品粮报告与“农民暴动”定性（1927.12–1928.01）**：经济学家В·涅姆钦诺夫的研究向斯大林揭示，由于革命消灭了提供战前70%以上商品粮的大型农场，1927年总产量虽恢复至1913年水平，商品粮却比1913年减少了整整一倍（1926年产粮6550万吨仅向国家出售740万吨；1928年农民仅出售收成的11.2%）。斯大林将农民惜售与缩减播种面积定性为“农民暴动”；
4. **1928年1月西伯利亚之行与1929年全面转轨**：`1928-01` 斯大林亲赴西伯利亚三周（从新西伯利亚与泰加站发出加密电报），动员惩罚机关推行“打击富农，让中农在我们面前站直”的“乌拉尔-西伯利亚”强制征粮法；随后在 `1929-04-23` 强推一五计划“最优方案”、`1929-06-27` 经政治局决议建立OGPU刑期三年以上囚犯强制劳改营体系，并在 `1929-11` 至 `1929-12-27` 推翻同年4月十六次代表会议的渐进指标，宣布转入“全盘集体化”与“消灭富农阶级”。

  >
  > “斯大林在西伯利亚度过了三周。这些日子主要被与地方领导人的会议和党的积极分子会面所占据。他的讲话是坚决的：‘必须这样打击富农，让中农在我们面前站直。’在斯大林的压力和惩罚机关的参与下，从西伯利亚运出粮食的极其紧张的计划被通过并执行了。……根据斯大林的观点，社会主义建设要求对富农进行‘阶级斗争尖锐化’。从1928年2月起，他开始推行‘乌拉尔-西伯利亚’的粮食收购方法。在西伯利亚试验的这套非常措施体系开始在全国推广。”（`1928-01-19` 新西伯利亚与 `1928-01-30` 泰加站密电评述，`[PDF p. 140]`）
  >

## 支撑证据

1. **`1922-04-03` 总书记任命决议原件与列宁修改笔迹**：确立总书记及两名书记（莫洛托夫、古比雪夫）架构，統管705人中央机关（`[PDF p. 101]`）。
2. **`1924-08-19`、`1926-12-27`、`1927-12-19` 三份辞职档案与全会速记**：`1927-12-19` 联共（布）十五大后中央全会由李可夫主持表决斯大林辞职提议，结果仅1人弃权、无人赞成（`[PDF pp. 119, 128–130]`）。
3. **`1928-01-19`（新西伯利亚致科西奥尔）与 `1928-01-30`（泰加站致科西奥尔、米高扬）加密电报**：直接记录斯大林在西伯利亚部署粮食征收与行政高压措施的现场指令（`[PDF pp. 139–140]`）。
4. **В·涅姆钦诺夫商品粮统计数据与农村抗暴统计**：1926年产粮6550万吨仅售740万吨；1927年商品粮较1913年减半；1928年商品率仅11.2%；与此同时，农村针对基层政权的恐怖行为从1924年的313起激增至1928年的1049起（`[PDF pp. 116, 139, 142]`）。
5. **1929年工业与农业全面加速档案**：`1929-04-23` 联共（布）十六次代表会议批准古比雪夫主持的最高国民经济委员会“最优”五年计划方案（否决克尔日扎诺夫斯基国家计划委员会的谨慎方案，`[PDF pp. 143–144]`）；`1929-08-06` 斯大林致莫洛托夫密电整肃《共青团真理报》编辑部以压制布哈林派青年支持者沙茨金与斯滕（`[PDF p. 154]`）；`1929-11` 至 `1929-12-27` 废除4月刚通过的“到1933年集体化面积17.5%”决议，发动全盘集体化（`[PDF pp. 156–157]`）。

## 反驳/批评

- 斯蒂芬·科恩（`[[CLM-cohen-1973-nep-viability]]`）等修正派学者认为1927–1928年粮食危机主要是国家价格政策失误造成的短期采购失调，新经济政策本身仍具活力；而本档案集引述的涅姆钦诺夫数据与斯大林西伯利亚密电则显示，在斯大林与布尔什维克急进工业化决策者眼中，小农经济仅11.2%的商品粮率构成了威胁政权生存与工业化资金积累的结构性死结（被斯大林视为“农民暴动”），从而促使其在1928年初即跨出用警察与行政强制替代市场的关键一步。
