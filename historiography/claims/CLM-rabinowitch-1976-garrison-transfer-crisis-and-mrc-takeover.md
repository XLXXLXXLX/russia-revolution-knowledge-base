## 核心论断命题（Thesis）

拉比诺维奇揭示，临时政府于1917年10月上旬宣布将彼得格勒卫戍部队主力调往前线的计划，成为布尔什维克与彼得格勒苏维埃动员驻军“防卫苏维埃代表大会”的政治契机；通过跨党派组建的军事革命委员会（MRC），托洛茨基等谨慎派战略家在 `1917-10-21 [O.S.] / 1917-11-03 [N.S.]` 至 `1917-10-23 [O.S.] / 1917-11-05 [N.S.]` 期间以“防御性”名义不流血地夺取了对首都卫戍部队及彼得保罗要塞的实质指挥权，在未发一枪的情况下先期解除了临时政府的武装。

## 论证链条与依据（Reasoning & Evidence）

- **调防命令引发驻军倒向苏维埃**：德军占领里加湾诸岛后，临时政府于 `1917-10-05 [O.S.] / 1917-10-18 [N.S.]` 下令（切列米索夫于 `1917-10-09 [O.S.] / 1917-10-22 [N.S.]` 确认）调遣首都驻军赴北方面军。厌战恐调的卫戍部队（如 `1917-10-12 [O.S.] / 1917-10-25 [N.S.]` 叶格尔团决议与 `1917-10-18 [O.S.] / 1917-10-31 [N.S.]` 卫戍部队会议18个团中的15个）一致宣布不再服从临时政府，但明确表示“只听从彼得格勒苏维埃或全俄代表大会的命令”（`ch15_13卫戍部队动乱与军事革命委员会.md#L10-L22, L44-L45`）。
- **军革委的起源与非傀儡属性**：军革委并非 `1917-10-10 [O.S.] / 1917-10-23 [N.S.]` 中央起义决议的产物——托洛茨基早在 `1917-10-09 [O.S.] / 1917-10-22 [N.S.]` 即在苏维埃提议设立该机构；`1917-10-16 [O.S.] / 1917-10-29 [N.S.]` 彼得格勒苏维埃全体会议正式批准，同日党中央方设立隶属于MRC的五人“军事革命中心”。`1917-10-20 [O.S.] / 1917-11-02 [N.S.]` 军革委首次组织会议推举左翼社革党人拉齐米尔任主席，执行局由3名布尔什维克与2名左翼社革党人组成；作者明确自我修正早期观点，指出MRC并非党中央或军事组织的傀儡，中央委员会记录亦极少提及MRC具体运作，而是由在场成员与托洛茨基在“保卫苏维埃”框架下机动推进（`ch15_13卫戍部队动乱与军事革命委员会.md#L34-L50`及注42）。
- **10月21–23日/11月3–5日实质夺取兵权**：`1917-10-21 [O.S.] / 1917-11-03 [N.S.]` 卫戍部队会议宣誓效忠MRC；当晚萨多夫斯基、拉齐米尔等赴军区司令部要求所有命令须经MRC政委副署遭波尔科夫尼科夫拒绝；`1917-10-22 [O.S.] / 1917-11-04 [N.S.]`（彼得格勒苏维埃日，当日人民宫万人集会高呼誓言）托洛茨基连夜散发剥夺司令部权威的宣言；`1917-10-23 [O.S.] / 1917-11-05 [N.S.]` MRC向各部队与军械库全面派驻政委并赋予否决权，且托洛茨基亲赴彼得保罗要塞演说赢得驻军及摩托车营倒戈，掌控克龙韦尔克军械库（`ch15_13卫戍部队动乱与军事革命委员会.md#L52-L73`）。
- **10月23日/11月5日晚的短暂防御回缩**：即便接管驻军已近完成，由于左翼社革党人以退出相威胁及温和布尔什维克（梁赞诺夫）施压，MRC竟在 `1917-10-23 [O.S.] / 1917-11-05 [N.S.]` 晚宣布撤销10月22日宣言以接受军区妥协——恰在此时克伦斯基却决定翌晨强硬出手（`ch15_13卫戍部队动乱与军事革命委员会.md#L75-L81`）。

## 原文核验引文（Verbatim Quotes）

> “在这种背景下，临时政府于10月中旬突然宣布计划将彼得格勒卫戍部队的大部分调往前线，这对布尔什维克来说简直是份礼物。这为开始与克伦斯基政权进行决定性斗争提供了绝佳的借口。” [ch15_13卫戍部队动乱与军事革命委员会.md#L10]

> “"在10月21日的集会上，彼得格勒革命卫戍部队围绕军事革命委员会...作为其领导机关团结起来。尽管如此，彼得格勒军区司令部在22日晚不承认军事革命委员会，拒绝与苏维埃士兵部的代表共同工作。至此，司令部与革命卫戍部队及彼得格勒工农兵代表苏维埃决裂。 ... 任何未经军事革命委员会签署的、针对卫戍部队的命令均属无效……" ... 著名的捷克俄罗斯革命专家M.雷曼恰如其分地写道："实际上，早在10月21日和22日，军事革命委员会就已经接管了驻军的领导权。其行动不仅根据实际情况，而且依据法律，在任何国家都将被视为直接叛乱和起义的行为"51。” [ch15_13卫戍部队动乱与军事革命委员会.md#L58, L60]

> “部分原因是由于布尔什维克在军事革命委员会中占据主导地位，西方历史学家倾向于将其仅仅视为一个受布尔什维克中央委员会或军事组织42严格控制的傀儡机构。这种评价是错误的。布尔什维克确实在委员会中扮演了领导角色，但他们并非其唯一成员，甚至在他们内部对委员会任务的理解也缺乏共识。” [ch15_13卫戍部队动乱与军事革命委员会.md#L50]
