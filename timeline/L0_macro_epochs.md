# L0 全景历史分期总览（1861–1929）

本卷为俄国革命知识库的最高层级鸟瞰图（**Level 0**），将从早期民粹派兴起到 1929 年斯大林击败布哈林的近七十年历史划分为 **10 个结构性阶段**。每个阶段标明核心历史张力、主要政治光谱与下钻索引方向。

---

## E01｜农奴制改革余波与早期民粹派运动（1861–1881）
- **起止锚点**：`1861-02-19 [O.S.] / 1861-03-03 [N.S.]`（废除农奴制宣言）→ `1881-03-01 [O.S.] / 1881-03-13 [N.S.]`（民意党刺杀亚历山大二世）
- **核心结构矛盾**：赎买制改革保留的村社（Община）与土地饥渴；激进平民知识分子（Разночинцы）寻找绕过西方资本主义、直接通过农村公社实现社会主义的“俄国特殊道路”。
- **关键组织与流派**：赫尔岑与车尔尼雪夫斯基思想奠基 → 柴可夫斯基小组 → 1874“到民间去（Хождение в народ）”运动 → 土地与自由社（Земля и воля, 1876）→ 1879 沃罗涅日-利佩茨克分裂为 **民意党（Народная воля，转向中央集权密谋与政治刺杀）** 与 **土地平分社（Чёрный передел，坚持农村鼓动）**。
- **核心史学公案**：民意党的集权密谋组织模式究竟是布尔什维克先锋队党的隐秘源头，还是历史语境截然不同的绝望宪政-社会抗争？

## E02｜工业化起飞、俄国马克思主义诞生与革命政党成形（1881–1904）
- **起止锚点**：`1883-09-25 [N.S.]`（劳动解放社在日内瓦成立）→ `1903-07-30 [N.S.]`（俄国社民工党二大分裂）
- **核心结构矛盾**：亚历山大三世反改革高压与维特工业化浪潮并存；新兴产业工人阶级登场；马克思主义者（普列汉诺夫、列宁、马尔托夫）与合法民粹派（米海洛夫斯基、沃龙佐夫、丹尼尔逊）围绕“俄国资本主义命运”展开大论战。
- **关键组织与分化**：
  - 社会民主主义脉络：劳动解放社 → 彼得堡工人阶级解放斗争协会（1895）→ 俄国社会民主工党一大（1898）→《火星报》与《怎么办？》（1902）→ **1903 二大布尔什维克与孟什维克分裂**。
  - 新民粹派脉络：各地民粹派小组整合为 **社会革命党（ПСР / SRs, 1901–1902，切尔诺夫提供理论，战斗队从事政治暗杀）**。
  - 自由派脉络：地方自治局立宪运动与《解放》杂志网络。

## E03｜第一场俄国革命：1905–1907 年的风暴与立宪试验
- **起止锚点**：`1905-01-09 [O.S.] / 1905-01-22 [N.S.]`（血腥星期日）→ `1907-06-03 [O.S.] / 1907-06-16 [N.S.]`（“六三政变”解散第二届杜马）
- **核心结构矛盾**：日俄战争战败引爆工农兵与边疆民族全面危机；**苏维埃（罢工代表委员会）** 作为新型群众自治机构首次在伊万诺沃-沃兹涅先斯克与圣彼得堡涌现。
- **关键政纲对决**：自由派立宪民主党（Kadets）推动君主立宪；孟什维克主张资产阶级领导民主革命；列宁提出“工农革命民主专政”；托洛茨基与帕尔乌斯基于彼得堡苏维埃经验提出 **“不断革命论”**。

## E04｜“六三体制”、斯托雷平改革与战前工运复苏（1907–1914）
- **起止锚点**：`1907-06`（选举法修改）→ `1914-07-19 [O.S.] / 1914-08-01 [N.S.]`（德国对俄宣战）
- **核心结构矛盾**：斯托雷平推行“押注强壮农民”的拆解村社土地改革与严酷军事法庭镇压；1912 年勒拿河金矿惨案后，彼得堡等大工业中心政治罢工急剧激进化，布尔什维克在城市工会与工人保险运动中迅速扩张。
- **核心史学公案**（“海姆森命题”）：假如没有第一次世界大战，沙俄帝国正稳步迈向宪政现代化，还是在 1914 年夏已濒临新一轮城市革命爆发？

## E05｜帝国的总体战危机：第一次世界大战中的俄国（1914–1917初）
- **起止锚点**：`1914-08` → `1917-02`
- **核心结构矛盾**：前线伤亡、后方铁路与城市粮食燃料供应链断裂、通胀恶化；宫廷孤立（拉斯普京丑闻与“进步同盟”对立）；社会主义阵营分裂为“护国派”与“齐美尔瓦尔德国际主义派”（列宁提出“变帝国主义战争为国内战争”）。

## E06｜1917：二月革命、双重政权与十月夺权（1917.02–1917.10）
- **起止锚点**：`1917-02-23 [O.S.] / 1917-03-08 [N.S.]`（彼得格勒女工罢工）→ `1917-10-25 [O.S.] / 1917-11-07 [N.S.]`（十月起义与全俄苏维埃二大）
- **核心结构矛盾**：临时政府与工兵代表苏维埃的“双重政权（Двоевластие）”内在瘫痪；战争延续、土地改革推迟与工厂劳资冲突推动士兵、工人、农民持续激进化；温和社会主义者（孟什维克、右翼社革党）加入联合政府后丧失基层信任。
- **高密度 L3 微观节点**：二月革命八天 → 列宁《四月提纲》 → 四月危机 → 六月攻势 → 七月事变 → 科尔尼洛夫叛乱 → 苏维埃布尔什维克化 → 十月党中央内部争论（列宁、托洛茨基 vs 加米涅夫、季诺维也夫）与十月起义。

## E07｜苏维埃政权初创、内战与战时共产主义（1917.11–1921.02）
- **起止锚点**：`1917-11`（人民委员会成立与维克热尔谈判）→ `1921-03`（喀琅施塔得起义前夜）
- **核心结构矛盾**：政权生存危机下的极端动员。解散立宪会议（1918.01）、《布列斯特-立陶夫斯克和约》引发党内 **“左翼共产主义者”（布哈林等）** 与左翼社革党决裂；红白内战与多国武装干涉；余粮收集制、国有化、契卡与红军正规化（托洛茨基军事改革）。
- **核心史学公案**：战时共产主义与一党制究竟是内战绝境强加的应急反应，还是布尔什维克意识形态内在蓝图的跃进尝试？

## E08｜1921大转折：新经济政策（NEP）确立与列宁晚年挣扎（1921.03–1924.01）
- **起止锚点**：`1921-03-08`（俄共（布）十大召开）→ `1924-01-21`（列宁逝世）
- **核心结构矛盾**：**“经济退却 + 政治收紧”的双重制度遗产**——十大以粮食税取代余粮收集制开启新经济政策，同时通过秘密条款《关于党的统一》禁止党内派别活动；苏联成立（1922.12）；列宁病重期间围绕外贸垄断、格鲁吉亚民族问题、官僚体制与继承人评估口授最后信件与文章（《论合作制》成为后来布哈林路线的核心合法性依据）。

## E09｜继任危机、工业化大论战与左翼/联合反对派的兴衰（1923–1927）
- **起止锚点**：`1923-10`（剪刀差危机与《四十六人声明》）→ `1927-12`（联共（布）十五大开除联合反对派）
- **核心结构矛盾**：在世界革命退潮背景下如何筹集工业化资金并维持工农联盟（Смычка）？
- **政治与理论重组**：
  - 第一幕（1923–1924）：季诺维也夫-加米涅夫-斯大林“三驾马车”击败托洛茨基（《十月的教训》论战）。
  - 第二幕（1925）：斯大林提出“一国建成社会主义”，与**布哈林**结成政治同盟（布哈林提出向农民让步与渐进社会主义增长），在十四大击败季诺维也夫-加米涅夫“新反对派”；理论上展开 **布哈林 vs 普列奥布拉任斯基（社会主义原始积累论）** 的经济学大论战。
  - 第三幕（1926–1927）：托洛茨基、季诺维也夫、加米涅夫组成“联合反对派”，围绕工业化速度、党内民主与中国大革命受挫挑战斯大林-布哈林多数派，于 1927 年底被彻底清洗出党。

## E10｜粮食收购危机、路线决裂与斯大林击败布哈林（1927冬–1929.11）
- **起止锚点**：`1927年冬`（国家粮食收购锐减与战争恐慌）→ `1929-11-17`（联共（布）十一月中央全会将布哈林逐出政治局）
- **核心结构矛盾**：新经济政策的价格失衡、工业高投资需求与个体小农惜售之间的结构性冲突；斯大林转向刑法与行政强制征粮（1928-01-15 至 02-06 亲赴西伯利亚推行《刑法典》第 107 条非常措施，1928 年底至 1929 年 3 月进一步定型“乌拉尔—西伯利亚方法”），与坚持市场平衡和工农结合的 **布哈林、李可夫、托姆斯基** 发生根本路线决裂。
- **决战关键节点**：1928年4月与7月全会拉锯 → 布哈林密会加米涅夫（1928-07-11） → 布哈林发表《经济学家札记》（1928-09-30） → 斯大林穿透莫斯科党委（1928-10-18/19 全会撤换柳廷等助手，11-27 莫洛托夫与鲍曼正式接管莫斯科市委） → 1929年1–2月政治局摊牌 → **1929年4月联席全会（布哈林作最后系统理论申辩但被正式定性为“右倾机会主义集团”）** → 斯大林发表《大转变的一年》（1929-11-07）并在 **1929年11月全会** 将布哈林逐出政治局，新经济政策终结，全面集体化与超高速工业化时代开启。
