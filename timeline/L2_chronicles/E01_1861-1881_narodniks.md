# E01｜改革、走向民众与政治恐怖：早期民粹派的多条道路（1861–1881）

> **层级与范围**：L2 阶段编年脉络卷；上接 [L0 分期 E01](../L0_macro_epochs.md#e01农奴制改革余波与早期民粹派运动18611881)，下接 [E02 政党形成卷](E02_1881-1904_marxism_and_parties.md)。日级锚点采用双历法；只有年份、季节的过程不补造日号。本卷是有出处的编年综合，并不代替原著整章精读或多模型终审。
> **中心问题**：废除人身依附为何没有消除土地冲突？青年知识分子为什么从书刊传播和农村定居，部分转向直接打击国家？这些变化中，哪些是共同经验，哪些只是某一组织的选择？

## [T1] 60秒定性微摘要

1861 年改革解除了地主对农奴的人身支配，却以赎买、过渡义务和具体土地划分延续了农民与地主、国家之间的矛盾。赫尔岑的村社社会主义、车尔尼雪夫斯基对理性行动与合作生活的想象，为激进知识分子提供了不同的社会主义语言；它们并非一个中央组织发布的共同纲领。涅恰耶夫案又使革命目的能否正当化欺骗和内部暴力成为尖锐问题。柴可夫斯基小组重视互信、教育和宣传，其组织伦理构成对涅恰耶夫方式的实际反拨。[V1–V3]

1874 年“到民间去”的挫折推动部分活动者转向长期定居和更可靠的地下联络。1876 年新一代土地与自由社将这些经验组织化；查苏利奇案、政治审判和镇压，则使政治暴力的对象与目的发生变化。1879 年利佩茨克预备会议与沃罗涅日全体会议没有当场完成一个整齐的二分：妥协之后，才形成民意党与土地平分社。**分歧首先是如何连接社会革命与政治斗争，不能概括成赞成暴力与反对一切暴力。**[V4–V6]

`1881-03-01 [O.S.] / 1881-03-13 [N.S.]`，民意党刺杀亚历山大二世。行动成功并未自动产生农民起义、立宪会议或社会主义革命。此后镇压与革命网络重组，通向马克思主义、新民粹主义等多种道路，而非必然通向布尔什维主义。[V7]

## [T2] 核心脉络、时效关系与史学争鸣

### 1. 1861–1864：改革打开期待，也重新分配冲突

**日级锚点：`1861-02-19 [O.S.] / 1861-03-03 [N.S.]`，废除农奴制宣言签署。** 应区分宣言签署、各地宣读、章程落实及赎买转化；全国农民并未在签署当天同时取得无条件的土地所有权。改革带来婚姻、契约等人身权利变化，但份地、割地、劳役或代役租过渡义务、赎买负担仍需逐地考察。村社既可能承担土地再分配，也承担征税、责任分摊与社会约束，不能只把它写成社会主义胚芽。[V1、V2]

赫尔岑通过伦敦的自由出版与《钟声》连接流亡者和国内读者。他对村社潜能的期待，与对欧洲革命受挫的反思相连；对改革的态度也会随现实变化。车尔尼雪夫斯基依托《现代人》等公共空间，将经济批判、人的可塑性和新生活方式结合起来；1863 年《怎么办？》的文学形象影响了青年自我训练、女性独立与合作实践。**这是车尔尼雪夫斯基的小说，不是列宁 1902 年的同名政治著作。**[V1、V2]

1860 年代前半期的第一代土地与自由社，处在改革预期、地下宣传与波兰问题交错的环境中；它与 1876 年组织同名，但不存在不间断的中央机构继承。改革失望、逮捕和流亡限制了公开政治空间，却不能由此推断所有反对派都必然选择暗杀。[V1]

### 2. 1860 年代后期—1871：涅恰耶夫案与组织伦理的破裂

涅恰耶夫以虚构的强大革命中心、严格服从和小组秘密结构来要求追随者。**`1869-11-21 [O.S.] / 1869-12-03 [N.S.]`，学生伊万诺夫被涅恰耶夫及同谋杀害**；案件暴露并进入司法程序，使“如何对待自己的同志”成为革命运动内部的问题。1871 年审判的公共影响，不应与后来涅恰耶夫本人被引渡和受审混成同一个节点。[V3]

《革命者教义问答》所代表的绝对献身与工具化伦理，必须放在涅恰耶夫与巴枯宁合作、分歧及文件归属问题中阅读。不能把它直接当作整个民粹派的党章，也不能把后来所有秘密组织都归入“涅恰耶夫主义”。柴可夫斯基网络对互信和人格完整性的强调，正说明同一革命环境中存在相反的组织答案。[V3、V4]

### 3. 约 1869–1874：柴可夫斯基小组与宣传网络的成长

这一网络由纳坦松等人的早期圈子发展而来，名称突出柴可夫斯基，并不意味着他是拥有全权的单一领袖。成员组织书籍供应、读书讨论、工人接触和跨城联系；佩罗夫斯卡娅、克鲁泡特金等人的参与，也显示教育、性别与社会出身的边界正在被重新穿越。[V4]

宣传方式的分歧同样重要：拉甫罗夫强调知识分子对人民的历史责任与长期准备；巴枯宁式起义期待更信任群众的反抗潜能；特卡乔夫则重视有组织少数与夺取政权的时机。这些是相互交错的策略语言，不宜把每名活动者终身固定为某个“学派”的执行者。[V3、V4]

文丘里指出，走向人民的浪潮兴起时，柴可夫斯基小组作为完整组织本身已遭破坏。因而，“小组培养了活动者”与“小组统一指挥了全国运动”是两种不同命题，后者不由前者推出。[V4]

### 4. 1874–1876：从“到民间去”到定居实践

1874 年春夏，青年以教师、医务人员、手工业者或流动劳动者身份进入乡村。“到民间去”不是一次有共同起止日、统一人数和统一纲领的全国行动。有些人寻求立即发动反抗，有些人从事解释、教育或长期接触；各地农民的反应也从同情、听取到戒备、告发不等。[V4]

其困难既包括农民对沙皇、土地和地方权力的具体理解，也包括外来者的语言、生活经验与警察风险。大规模逮捕破坏了网络；但用“农民愚昧”解释全部失败，会遮蔽村庄内部的利益差异和行动成本。后来的长期定居、职业掩护、农民熟人关系与工人鼓动，都是对这些失败的修正。[V4、V5]

1875–1876 年的重组，逐渐把“革命者必须生活在人民之中”的伦理要求变成联络、经费、印刷和安全制度。这里的变化是组织学习，并不等于运动已经放弃群众而一致转向恐怖活动。[V5]

### 5. 1876–1878：第二代土地与自由社与查苏利奇案

1876 年形成的新土地与自由社，试图以较稳定的核心协调农村工作、城市联系和地下基础设施。**`1876-12-06 [O.S.] / 1876-12-18 [N.S.]` 的彼得堡喀山广场示威**，显示运动也在探索城市公共政治；它不能当作该组织精确的成立日。其社会纲领仍以土地归劳动者、地方自治和对国家压迫的反抗为重心。[V5]

**`1878-01-24 [O.S.] / 1878-02-05 [N.S.]`，维拉·查苏利奇枪击彼得堡市长特雷波夫**，以报复其下令鞭打政治犯博戈柳博夫。特雷波夫受伤而未死。**`1878-03-31 [O.S.] / 1878-04-12 [N.S.]`，陪审团宣告查苏利奇无罪。** 开枪、审判和无罪裁决应分别记录，不能把公众对惩罚滥权的同情写成社会已经接受民意党后来的一整套战略。[V6]

同一时期政治案件中的长时间羁押、流放与处决，使救援同志、惩罚官吏的行动获得紧迫性。不过，**报复具体虐待者、保护地下网络与系统性刺杀沙皇，是不同层次的目标**。政治恐怖的扩展经过争论和选择，不是一次开枪就完成了策略转型。[V6]

### 6. 1879 年夏—秋：两次会议、暂时妥协与组织分立

利佩茨克会议先于沃罗涅日会议。前者是主张政治斗争者的预备集会，讨论集中执行机构与打击国家的方向；后者汇集土地与自由社不同倾向，尝试维持共同组织。普列汉诺夫反对把活动重心移向刺杀沙皇；其他与会者在继续农村工作和容纳政治行动之间作出妥协。**沃罗涅日不是两党当场宣告成立的单一“分裂日”。**[V7]

此后分歧继续发展，夏末至秋季的分产、组织与纲领调整，形成民意党和土地平分社。民意党把反专制政治斗争提升到中心位置，以执行委员会协调行动，同时保留工人、军人联系和社会革命诉求；其政治自由、人民代表机构等主张，不能从叙事中删掉。土地平分社更重视土地重新分配与群众宣传，但不宜因此称为一概反对暴力的和平主义组织。[V7]

两派分立后的个人联系并未立即消失。查苏利奇虽曾枪击官员，后来却站在反对把刺杀沙皇作为主要战略的一方，这正好说明政治立场不能由个人曾否使用暴力来推定。土地平分社部分核心成员后来转向马克思主义，是下一阶段的再选择；不能把 1879 年的组织提前称为马克思主义政党。[V7；关联两组织卡]

### 7. 1879–1881：刺杀技术、政治纲领与“三月一日”

民意党组织铁路爆破、冬宫爆炸等多次行动，发展侦察、炸药制造、掩护住所和执行分工；这些技术能力并没有相应转化为可接替国家的全国群众组织。热利亚博夫、佩罗夫斯卡娅、基巴利契奇等人的作用，须与其他投弹者、联络者和被捕者一起理解，不能只写成一个英雄的壮举。[V7]

**`1881-03-01 [O.S.] / 1881-03-13 [N.S.]`，亚历山大二世在彼得堡叶卡捷琳娜运河旁遭炸弹袭击后死亡。** 地点宜使用当时名称，并可注明今称格里博耶多夫运河。刺杀打断了洛里斯－梅利科夫主持的有限咨询改革进程，但这种咨询方案本身并不是已经确立的议会宪政。[V7]

直接结果是皇位继承、警察追捕和组织重创，未出现行动者所期待的全国性政治突破。把这写成“恐怖成功，所以革命前进”，或“恐怖失败，所以农民社会主义毫无社会基础”，都越出了事件本身能够证明的范围。E02 因而需要同时跟踪反改革国家、工人运动与新民粹主义的延续。

### 9. 史学争鸣槽：共同事实与解释分歧

**经验事实共识**：改革留下土地与义务争议；1874 活动与镇压推动组织反思；1879 分立；1881 刺杀没有立即带来预期的全国革命。这些事实并不自行裁决组织传统的长时段意义。

| 解释路径 | 关注点与本卷处理 |
| :--- | :--- |
| 文丘里的思想与运动史 [V1–V7] | 强调运动内部差异、政治自由纲领及策略转变的具体环境。本卷据此防止把“民粹派”写成单一组织。 |
| 俄国马克思主义者的事后批判 | 把农民社会主义、个人恐怖与产业工人运动相对照。这是后来论战的一部分，不能倒过来充当 1874 年所有活动者真实动机的直接证据。 |
| 政治文化连续性解释 | 追踪地下集中、献身伦理与少数人代行政治的延续；须逐项证明人员、文本或制度传递，不能只凭“都有秘密核心”断言民意党等于布尔什维克党。 |
| 社会与性别史问题 | 女性在教育、照护、联络与行动领导中的位置，以及乡村听众自身的判断，不能被领袖思想谱系替代；本批仍缺相应专门研究。 |

[主台账](../events_ledger.jsonl) 中已并入 E01 的 8 条事件（使用 `TL-W4-E01-*` 独立 ID）；精确日期可能与主账本既有 L1 事件并存。`precision=year` 的 `date_ns` 仅为年份排序键，`date_os=null` 表示没有日级锚点，不表示当时已改历。

适宜的 L3 下钻包括查苏利奇案的开枪—法庭—公众反应，以及 1879 两会与分产过程。前者须区分行动者、法官、陪审团和公众；后者先解决史料日号冲突，再排逐日表。
