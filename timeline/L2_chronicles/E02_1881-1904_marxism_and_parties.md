# E02｜资本主义争论、工人组织与政党分野（1881–1904）

> **层级与边界**：L2；承接 [E01 民粹派卷](E01_1861-1881_narodniks.md)，对应 [L0 的 E02](../L0_macro_epochs.md#e02工业化起飞俄国马克思主义诞生与革命政党成形18811904)。主体终点是 1903 年二大及其后果；1904 年仅作通向 E03 的过渡，不扩写 1905 年革命。
> **历法约定**：改历前日级日期全部双列。日内瓦、莱比锡、布鲁塞尔和伦敦事件优先辨认当地公历或俄文文献旧历；换算得到的 O.S. 只是对照，不表示当地使用俄历。精确日号均已调用 `kb.py date` 核验，命令表见 T3。

## [T1] 60秒定性微摘要

1881 年后的高压没有终结反对运动，而是改变其载体。劳动解放社把社会主义希望更多地转向资本主义发展所形成的产业工人；1887 年乌里扬诺夫案则显示政治暗杀传统仍在年轻人中延续。1891–1892 年饥荒、工业化与城市劳动冲突，为不同派别提出同一个问题：俄国资本主义是应当加速的历史阶段，还是使小生产者破产的可避免道路？双方对同一灾难可以作相反解释。[H1、W1]

1895 年彼得堡斗争协会尝试把理论圈子与工厂鼓动结合，1898 年一大宣告成立俄国社会民主工党，但警察逮捕与地区分散使全国组织远未稳固。《火星报》把编辑、通信、运输和地方联系人织成政治网络；1902 年《怎么办？》为反经济主义和职业革命家组织作系统辩护。与此同时，新民粹派在 1901–1902 年间合流为社会革命党，农民、土地和政治恐怖并未因马克思主义兴起而退出政治舞台。[H2、H3、S1]

二大从 `1903-07-17 [O.S.] / 1903-07-30 [N.S.]` 开至 `1903-08-10 [O.S.] / 1903-08-23 [N.S.]`，先后在布鲁塞尔与伦敦举行。列宁和马尔托夫关于党员资格的分歧，与代表退出、中央机构设计和《火星报》编辑人事冲突交错，产生布尔什维克、孟什维克称谓。**这是一党内派别分野及持续重组的开端，不是开幕当天两个成熟政党正式分家的瞬间。**[H4、G1、P2]

## [T2] 核心脉络、时效关系与史学争鸣

### 1. 1881–1887：反改革环境与革命传统的再选择

亚历山大三世时期的政治反改革，与司法、教育、地方社会控制相联系；不能把它等同于经济发展停止。在乡村基层，**`1889-07-12 [O.S.] / 1889-07-24 [N.S.]`** 颁布《地方行政长官条例》（[`POL-1889-land-captains-and-vyshnegradsky-fiscal-regime`](../../cards/policies/POL-1889-land-captains-and-vyshnegradsky-fiscal-regime.md)），由世袭贵族出任的地方行政长官（`земский начальник`）取代选任治安法官统揽乡村行政司法，配合赋税连环保威慑与 **`1894-06-03 [O.S.] / 1894-06-15 [N.S.]`** 《居留证条例》（法定成年未分家子女领照须经家长同意，欧俄近半数内部护照期限 ≤3 个月）催缴超额赎金与进城务工汇款（直至 **`1903-03-12 [O.S.] / 1903-03-25 [N.S.]`** 方废除欧俄 46 省财政连环保）。民意党网络遭破坏，部分土地平分社活动者流亡，地下组织与出版活动的重心因而重新分配。[H1、B1；接 E01]

**1883 年日内瓦劳动解放社**由普列汉诺夫、阿克雪里罗得、查苏利奇、捷伊奇和伊格纳托夫等建立，公开宣告锚点为日内瓦当地公历 `1883-09-25 [N.S.]`（本卷末校验表所列 `1883-09-13` 仅为 19 世纪 12 日差换算对照，西欧当地不使用俄历）。这里以《现代社会主义丛书》出版宣告关联该团体的公开出现，不把幕后筹组压缩成一天。它翻译传播马克思主义，普列汉诺夫的《社会主义与政治斗争》及后来的《我们的分歧》把反专制政治斗争、资本主义发展和工人阶级组织相连接。[H1、D1]

这一转变保留了旧革命网络的人际资源，却更换了社会分析和战略重心。土地平分社不是经一次会议原封不动地更名为马克思主义政党；流亡团体也尚未拥有能统一国内工人运动的组织力量。[H1]

**`1887-03-01 [O.S.] / 1887-03-13 [N.S.]`**，企图在亚历山大二世遇刺周年谋刺亚历山大三世的密谋被破获；**`1887-05-08 [O.S.] / 1887-05-20 [N.S.]`**，亚历山大·乌里扬诺夫等五人被处决。两位沙皇与“成功刺杀 / 未遂密谋”须明确区分。此案对弗拉基米尔·乌里扬诺夫家庭和政治成长有重要影响；但不能仅凭后来传说中的一句表态，断言列宁当时已形成完整的马克思主义路线。其思想变化还需放回读书、地方网络和此后工运经验中。[H1]

### 2. 1891–1890 年代中期：饥荒、维特工业化与资本主义命运之争

1891 年歉收继而形成 1891–1892 年饥荒和公共卫生危机。救济活动扩大了知识分子、专业人员和地方自治网络的社会实践，也使国家治理能力受到质疑。这里不设虚构的全国统一“饥荒发生日”。对灾难的解释并不一致：丹尼尔逊认为资本主义改造正在破坏农业和小生产；合法马克思主义者则把危机解释为落后生产方式的后果，要求推进资本主义发展。[W1]

在财政与贸易政策上，财政大臣维什涅格拉茨基（1887–1892 在任）为偿付金属外债并积累黄金储备，强压进口、猛推粮食出口顺差（1888 年谷物出口达 `5.313亿` 普特、顺差 `+3.979亿` 卢布），并于 **`1891-06-11 [O.S.] / 1891-06-23 [N.S.]`** 获批颁布禁止性总关税税则（`07-01 [O.S.] / 07-13 [N.S.]` 生效，使 1891、1892 年生活必需品类关税课征额占该类进口货值比重达 `64.5%` 与 `68.8%`（另据索博列夫所列 1907 年各国总体关税比重国际比较，俄国以 `31.4%` 高于表列其他国家））。维特自 1892 年起接任财政大臣，推动铁路、保护性政策、国家信用与外资相结合的工业化；1897 年金本位又增强金融制度与国际资本的联系。工业集中使劳动人口、工厂纪律和城市生活冲突更加突出，但劳动者仍与乡村家庭、季节劳动和流动就业相连，不能把“产业工人出现”写成农民社会立刻消失。[W1、A1、B1、SB1、H2]

工业化成本如何在农民、城市消费者、企业和外资之间分摊，必须依财政结构与不同税负辨析。Plaggenborg 与 Gregory / Allen 的国民收入重估（1885–1913 年农业产出翻番、小麦单产追平北美大平原，但按年度定额估算欧俄可用农业劳动力总量约为农业需求的 2.2 倍，致城乡实际工资停滞、实际地租暴涨）均对“工业化完全由绝对贫困化停滞的农民供养”这一简化概括提出再检验；本卷因此不把高间接税负、出口顺差挤压与农业总产出停滞机械画成同一条因果线。[A1、SB1、AL1]

瓦利茨基的研究还提醒：丹尼尔逊等人并非没有读过马克思；他们恰恰使用马克思关于积累与剥夺的分析来批判俄国资本主义。普列汉诺夫等人则更强调市场扩展、阶级分化与工人政治的可能。争论不仅是“接受 / 拒绝西方理论”，也是如何使用同一理论诊断俄国现实。[W1]

### 3. 1895–1898：从小圈子到斗争协会与全国建党

1895 年，列宁、马尔托夫等参与彼得堡工人阶级解放斗争协会，把原有学习圈与工厂鼓动联结起来。传单从工资、罚款、工时等具体问题切入，试图使劳资冲突与专制国家问题相连。列宁与马尔托夫后来分裂，不应抹去此时合作及对群众工作的共同重视。[H2、G1]

1895 年底至 1896 年初的一批逮捕改变了组织人员构成；后续罢工并未因领袖入狱而停止。所谓“经济主义”是在这一实践环境中发展出的倾向和论战标签，内部并不完全一致。强调工厂要求可以扩大参加者，也可能使政治目标受限；《火星报》派对其批判，不能被当作对所有基层鼓动者的中立描述。[H2]

**一大：`1898-03-01 [O.S.] / 1898-03-13 [N.S.]` 开幕，至 `1898-03-03 [O.S.] / 1898-03-15 [N.S.]` 闭幕，地点明斯克。** 与会者包括若干地区社会民主组织、崩得和《工人报》方面代表，宣告成立俄国社会民主工党，选出中央机构。斯特鲁维起草的宣言把政治自由作为工人斗争的条件；这也显示合法马克思主义、地下组织和后来自由主义之间的界线仍在形成。[H2]

一大后中央机构迅速受逮捕打击，没有立即建立持久的全国指挥体系。故“一大已经宣告建党”和“二大仍以实际统一组织为任务”可以同时成立。崩得的犹太工人组织经验、语言与代表权诉求，也不能仅作为列宁建党故事中的背景略去。[H2、P2]

### 4. 1900–1902：《火星报》与《怎么办？》的组织方案

《火星报》首号标为 **1900 年 12 月**，在莱比锡印制；此后编辑、印刷地点并不总相同。通行排印锚点为 `1900-12-11 [O.S.] / 1900-12-24 [N.S.]`，但排印、完成印刷和向俄国发运未必同日，见 T3。旧编辑部六人是普列汉诺夫、阿克雪里罗得、查苏利奇、列宁、马尔托夫和波特列索夫。它依赖国内联系人和地下运输，把全国性论战与地方经验接在一起，而不只是一本刊物的文字影响。[H3、G1、I1]

列宁 1902 年出版《怎么办？》，针对经济主义、组织业余性与政治揭露不足，区分广泛的工人组织和以革命活动为职业的核心组织。他主张把各阶层遭受的专制压迫纳入全国政治鼓动，以报纸联系和组织革命者。职业革命家也可以来自工人，不能直接译解成知识分子对工人的永久身份垄断。[P1]

该书有关自发性、社会民主主义意识和“从外部”输入的论述，需要连同所引考茨基、具体论敌与组织语境阅读。**“经济斗争本身不足以自动产生完整的社会主义政治”与“工人永远没有自主政治能力”，不是同一个命题。** 海姆森着重分析“自发性 / 意识”的观念对立；是否因而低估当时社会民主主义共同传统，仍需另作史学对勘。[H3、P1]

### 5. 1901–1902：社会革命党形成与另一种群众政治

社会革命党的形成经历地方新民粹派、流亡出版网络及不同组织之间的合并，关键阶段在 1901 年冬至 1902 年。希尔德迈尔强调格尔舒尼、布列什科－布列什科夫斯卡娅在国内的联络，以及切尔诺夫、戈茨等在海外的工作。党名宣告、实质合作与外围团体正式融合并不同步，故本卷不用一个未经核清的“成立日”替代整个过程。[S1]

切尔诺夫尝试将农民、工人和其他劳动者放在更广的劳动人民框架中，土地社会化成为核心方向。战斗组织负责政治暗杀，格尔舒尼起重要作用；但社会革命党也从事农民、工人宣传和组织活动，不能只以战斗队代表全党。1902 年南部农村骚动进一步增强该党关于农民革命能力的信心。[S1]

因此，马克思主义者与新民粹派之间是争夺革命主体、土地纲领及行动方法的竞争，并不是工业化已科学证明一派必胜，另一派只剩历史残余。两者都试图解释城市与乡村的连接，所赋予农民阶级分化的意义却不同。[W1、S1]

### 6. 1903：二大的共同纲领、党员资格与“多数 / 少数”

二大的开、闭幕双历日期见 T1。会议由布鲁塞尔迁伦敦，与警察压力有关。大会建立共同纲领和中央机构框架时，《火星报》派并未从一开始就整齐分成两营；普列汉诺夫在关键组织争论中支持列宁，后来又改变与列宁的关系，足以否定固定阵营的倒叙法。[H4、G1、P2]

党章第一条上，列宁要求党员亲自参加一个党组织；马尔托夫允许在党组织领导下经常提供个人协助者成为党员。双方都主张有组织的社会民主工党，争点在成员边界、责任和地下条件下参与的方式。马尔托夫的方案在该项表决获胜；不能因为列宁后来被称为“多数派”，就写成他赢了所有组织表决。[H4、G1]

崩得和经济派代表退出改变了后续票数结构。中央机关报编辑部从六人缩为三人、旧编辑是否保留等问题，又把规则争论转为人事与信任危机。马尔托夫拒绝按新安排进入编辑部，争执延续到会后。布尔什维克、孟什维克的“多数 / 少数”首先来自这一会议及选举局面，不是全国工人支持率的统计。[H4、G1]

1903 年秋冬，《火星报》编辑关系再次调整，普列汉诺夫与旧编辑合作，列宁退出。1904 年关于中央集权、个人独立和工人主动性的论战进一步展开。其后仍有重新联合和地方合作，**1903 的派别分野不能直接等同于后来永久的两个政党组织**。党组织争论的重要性在于它改变了政治实践的可能性，而不是已经预告 1917 年每个人的最终立场。[H4、G1]

### 7. 向 1904–1905 的接口

地方自治局立宪派和《解放》杂志网络也在形成；1904 年战争和政治危机将改变不同反对派的机会。本卷把它们作为政治光谱的第三条线，而不把自由派写成马克思主义内部的附属派。E03 应把党内争论重新放回罢工、农村、军队与帝国边疆的群众政治中，检验地下组织在革命公开化后的实际适应能力。[H4]

### 9. 史学争鸣槽

**经验共识**：资本主义和工人组织扩展；全国建党经历不稳定的多阶段过程；《火星报》派在二大后分裂；社会革命党形成与农村动员同步。对其意义则须保留区别：

| 解释路径 | 本卷采用的边界 |
| :--- | :--- |
| 苏联正统建党叙事 | 强调列宁反经济主义及组织统一。其“布尔什维克必然代表工人阶级”的事后评判，不能代替当时的地方构成与表决证据。 |
| 海姆森的思想史 [H1–H4] | 追踪知识分子传统、“意识 / 自发性”及领袖对现实的不同感受；须防止心理与观念范畴吞没组织实践。 |
| Getzler 的马尔托夫传记 [G1] | 从合作经验、政治伦理与人事冲突重建分裂；不以列宁后来的胜利排除马尔托夫当时方案的历史合理性。 |
| 瓦利茨基的概念与社会哲学史 [W1] | 民粹主义对资本主义的批判有自己的理论问题，不是等待被马克思主义取代的无知。 |
| 新制度、工运与文本语境问题 | 警察破坏、地方自主、专业网络及共同社会民主传统，需要与思想史互证；本批尚未完成 Lars Lih 等研究的独立对勘。 |

**争鸣卡接口**：`DEB-1903-party-organization`、`DEB-russian-capitalism-populism`（均待建，本槽暂存；候选账本不引用未建卡）。本卷预读马尔托夫 1-Hop 包，记录其苏联正统、托派及后苏联视角尚待补齐，故不将现有草稿当作全光谱结论。

### 2. 日历与“单日建党”的证据边界

劳动解放社公开宣告日可沿用 L0，但成立过程不止一天。《火星报》首号仅标月份，馆方介绍与编研材料对排印、实际出刊的表述有差别，因此候选记录只取年精度并在摘要保留“12 月号”。社会革命党以 1902 年为公开建党阶段排序年，摘要保留跨越 1901–1902 的合流过程，不伪装成全部成员在同一天入党。

L0 将二大开幕日同时简写为“分裂”锚点。本卷保留其索引功能，却把大会全程和会后发展展开；候选记录标题明确为“二大开幕”，摘要说明分野形成于会期及其后，合并时应审核主账本同日条目的表述。
