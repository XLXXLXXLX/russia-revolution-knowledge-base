# L3 显微时间线：1927年十周年、十五大与联合反对派败局

> W15候选编年；主体1927年9—12月，尾声延至1928-01-15的供应调拨窗口，共18个日格/窗口。全卷使用改革后的格里高利公历 [N.S.]，候选 date_os 一律为 null。对应[候选账本](_w15_candidate_events.jsonl)、[L1骨干](../L1_milestones/1861-1929_backbone.md)、[E09脉络卷](../L2_chronicles/E09_1923-1927_succession_and_left_opposition.md)与[E10购粮危机卷](../L2_chronicles/E10_1927-1929_grain_crisis_and_bukharin_defeat.md)。

## [T1] 60秒定性微摘要

1927年9月政纲被拒绝公开印行之后，联合反对派以秘密复制和联署继续动员，OGPU的印刷所案又将派别争论连接到白卫阴谋指控。10月23日托洛茨基、季诺维也夫被逐出中委，11月7日十周年庆典中的自有口号和队列遭压制，14日两人失去党籍，16日越飞去世并留下政治遗书。12月2–19日十五大扩大清除，季加由承诺服从转向承认错误、请求复籍，仍未当场获准。与此同时，秋季谷物比价和工业品供给恶化，十一至十二月国家购粮急降；12月14日大会会期内中央已发危机通函，24日再催办并公开调派收购干部。党内胜利与农村交换危机同步发生，尚不能直接等同于1928–1929年已经形成的全面强制转型。[^T][^D][^G]

## [T2] 组织排除与购粮危机的交织编年

### 处分与屈服程序速查

| 节点 [N.S.] | 当时发生的事 | 不能混同的后续 |
| :--- | :--- | :--- |
| 1927年9月 | 政纲禁印、秘密复制、印刷所案及有关人员被处分 | 不等于托季已经被开除党籍。 |
| 1927-10-23 | 托季被逐出中央委员会 | 不等于1926年的政治局罢免，也不等于11月党籍处分。 |
| 1927-11-14 | 托季被开除党籍 | 不等于1928年1月行政流放或1929年驱逐出境。 |
| 1927-12-10 | 季派接受大会决定、联合反对派分裂 | 不等于立即放弃所有观点，更非已经恢复党籍。 |
| 1927-12-18—19 | 承认错误与请求复籍；大会作出拒绝即时集体恢复的决定 | 六个月考察和个别申请是后续程序；不能写成“恢复党籍留党察看”。 |

<a id="tl-w15-l3-27-04"></a>

### 1927-09-01—1927-10-31 [N.S.]｜秋收上市与谷物相对价格转差

- **经济 / 社会线**：七八月谷物官价略升后在秋收期再降；经济作物及肉奶价格相对更有吸引力。务工收入、税负减轻、工业品短缺共同削弱立即售粮动机。
- **组织 / 政治线**：基层党政忙于大会和纪念活动可能影响收购组织；这只是Carr–Davies列出的因素，不能成为所有地区收购下降的单一解释。
- **定年与证据边界**：9–10月窗口；机器9月1日为下界，非一次统一降价令的生效日。 事件候选 `TL-W15-L3-27-04`。[^G]

<a id="tl-w15-l3-27-01"></a>

### 1927-09-03 [N.S.]｜联合反对派政纲提交的编者定年

- **经济 / 社会线**：政纲要求加快工业、改善工人地位、以累进税约束富裕农户，并强调工业品供给与工农关系。
- **组织 / 政治线**：政纲把党内民主、国际政策和经济要求联结。现库英文只收入第3、4、7章；9月3日来自中文编者题注，英文各章无同一署日。
- **定年与证据边界**：暂按编者9月3日；候选须保留date_basis=editorial-date，不能声称原件自署。 事件候选 `TL-W15-L3-27-01`。[^P]

<a id="tl-w15-l3-27-02"></a>

### 1927-09-06 [N.S.]｜要求公布政纲的申诉遭拒

- **经济 / 社会线**：经济方案能否在大会选举前供党员比较，关系到工业化与农村政策争议的可见度。
- **组织 / 政治线**：托等向政治局、中央交涉，抗议迫害及大会延期，要求按党内讨论程序印行政纲；中央拒绝刊发并禁止自行传播，推动秘密复制。
- **定年与证据边界**：9月6日系多伊彻对交涉的定年；禁印的个别决定日期仍需中央原记录复核。 事件候选 `TL-W15-L3-27-02`。[^T]

<a id="tl-w15-l3-27-03"></a>

### 1927-09-12—1927-09-13 [N.S.]｜地下印刷所案

- **经济 / 社会线**：本案直接针对政治文本的复制与散发，并非查获一套独立经济行政体系。
- **组织 / 政治线**：12–13日夜OGPU突袭秘密复制处并逮捕人员。普列奥布拉任斯基、姆拉奇科夫斯基、谢列布里亚科夫承担政治责任。官方把其中一名“弗兰格尔军官”与白卫阴谋相联系；多伊彻据交涉记录指出此人是警察线人。案件事实、官方指控与线人解释必须分栏。
- **定年与证据边界**：夜间事件用区间，不把逮捕、党籍处分和随后揭露全部压成12日。 事件候选 `TL-W15-L3-27-03`。[^T][^S23]

<a id="tl-w15-l3-27-05"></a>

### 1927-10-23 [N.S.]｜十月中央—中监委联席全会处分

- **经济 / 社会线**：反对派关于工业、农村与国际政策的争议被纳入派别活动的纪律框架。
- **组织 / 政治线**：10月21–23日联席全会最终将托洛茨基、季诺维也夫逐出中央委员会。斯大林23日演说辩护拒印政纲及对其秘密传播的处分。此时二人尚未被开除党籍，也不是1926年政治局罢免的重演。
- **定年与证据边界**：主锚为23日处分；21日开会属会议区间信息。 事件候选 `TL-W15-L3-27-05`。[^S23][^T][^D]

<a id="tl-w15-l3-27-09"></a>

### 1927-11-01—1927-12-31 [N.S.]｜十一至十二月国家购粮急降

- **经济 / 社会线**：Carr–Davies指出两个月收购均明显落后上年同期；比较对象是国家/合作社收购流量，不是粮食总产量或农民全部销售。官价、私市竞争和换购商品不足交织。
- **组织 / 政治线**：国家供应压力在反对派已失势时累积；不能把“富农罢市”作为未经检验的事实解释，更不能反推中央当时已经决定全面集体化。
- **定年与证据边界**：保留双月统计窗；不将月底汇总当成11月1日已知数据。 事件候选 `TL-W15-L3-27-09`。[^G]

<a id="tl-w15-l3-27-06"></a>

### 1927-11-07 [N.S.]｜革命十周年独立口号与游行冲突

- **经济 / 社会线**：庆典展示恢复与社会主义建设成就，同时商品供给和农村售粮问题仍在恶化。成就宣传并不等于生活矛盾已经消失。
- **组织 / 政治线**：莫斯科与列宁格勒反对派支持者在官方庆祝队伍中组织自有队列、横幅和口号，遭警察、党内积极分子等压制。这里的“独立”指政治表达，并不等于已有另一支获准上街的官方游行，更不能直接写成武装暴动。
- **定年与证据边界**：枪击、殴打、人数与具体地点主要依回忆叙述，未取得逐点警务记录，不列伤亡总数。 事件候选 `TL-W15-L3-27-06`。[^T][^V]

<a id="tl-w15-l3-27-07"></a>

### 1927-11-14 [N.S.]｜托洛茨基、季诺维也夫被开除党籍

- **经济 / 社会线**：斯大林—布哈林多数派此时仍共同击败联合反对派，尚未公开分裂为1928年的对立阵营。
- **组织 / 政治线**：中央—中监委非常会议依据派别与示威指控开除托季党籍；加米涅夫等进一步失去中央机构席位。十月逐出中委、十一月开除党籍、十二月扩大清除是连续而不同的处分。
- **定年与证据边界**：党籍处分不是国家刑事判决，不能直接等同逮捕或流放。 事件候选 `TL-W15-L3-27-07`。[^T][^D]

<a id="tl-w15-l3-27-08"></a>

### 1927-11-16 [N.S.]｜越飞逝世及遗书

- **经济 / 社会线**：越飞描述疾病、工作被剥夺及治疗争执；这些是其本人陈述，机构处理的全貌仍需档案对读。
- **组织 / 政治线**：越飞自杀，给托洛茨基的遗书把个人困境与开除反对派的抗议相连，也批评托的妥协与犹疑。遗书证明其本人如何理解处境，不能独自证明所有医疗责任与动机推断。
- **定年与证据边界**：正文按16日；不同语种编本有15日/15–16日写信题注，参T3异文说明。 事件候选 `TL-W15-L3-27-08`。[^J][^T]

<a id="tl-w15-l3-27-10"></a>

### 1927-12-02—1927-12-19 [N.S.]｜联共（布）十五大开幕

- **经济 / 社会线**：大会讨论工业发展、农业和五年规划；增长目标与当前收购缺口并行存在。
- **组织 / 政治线**：大会至19日举行，反对派代表性与申辩空间极受限制；它是大规模清除的大会，却不是托季首次被开除党籍的时间。
- **定年与证据边界**：大会区间；斯大林中央政治报告实际在3日。 事件候选 `TL-W15-L3-27-10`。[^S15][^T][^D]

<a id="tl-w15-l3-27-11"></a>

### 1927-12-03 [N.S.]｜斯大林中央政治报告

- **经济 / 社会线**：报告叙述建设成就与农村阶级状况，主张推进工业化和农业改造；这是多数派当时的政策陈述。
- **组织 / 政治线**：以党内统一和反对派失败证明路线正确，压缩反对意见的合法地位。不能将报告宣称的支持率直接当成全社会真实支持率。
- **定年与证据边界**：报告日与2日大会开幕分开。 事件候选 `TL-W15-L3-27-11`。[^S15]

<a id="tl-w15-l3-27-12"></a>

### 1927-12-10 [N.S.]｜季诺维也夫派与托洛茨基派分道

- **经济 / 社会线**：经济政策争执仍在，但留在党内的资格逐渐成为各派首先处理的问题。
- **组织 / 政治线**：季派表示接受大会决议、停止反对活动；拉科夫斯基、拉狄克、穆拉洛夫等不愿放弃继续阐述观点。多伊彻将此标为联合反对派解体节点；双方当时都仍坚持一党制。
- **定年与证据边界**：“投降”是政治描述；停止活动、承认错误、正式复籍为三个层次。 事件候选 `TL-W15-L3-27-12`。[^T][^D]

<a id="tl-w15-l3-27-13"></a>

### 1927-12-14 [N.S.]｜大会会期内第一封购粮危机通函

- **经济 / 社会线**：中央通函要求关注收购危机，表明供应紧张在大会闭幕前已进入中央紧急处置。
- **组织 / 政治线**：清除反对派与基层经济失灵同步发生；不能把中央认识危机一概推迟到十五大之后。通函本轮据Carr–Davies转引，未核原始发文簿。
- **定年与证据边界**：内部通函日期；不同于24日《真理报》公开消息。 事件候选 `TL-W15-L3-27-13`。[^G]

<a id="tl-w15-l3-27-14"></a>

### 1927-12-18 [N.S.]｜十五大批准扩大开除反对派

- **经济 / 社会线**：经济路线讨论以清除政治异议为背景继续展开。
- **组织 / 政治线**：大会批准此前开除托季的决定，并清除包括加米涅夫、拉科夫斯基等在内的75名联合反对派骨干；萨普罗诺夫等民主集中派另案处理。75人和另案名单不能混算成同一范围。
- **定年与证据边界**：按18日反对派决议；19日另有对请求复籍声明的答复。 事件候选 `TL-W15-L3-27-14`。[^D][^T][^DW]

<a id="tl-w15-l3-27-15"></a>

### 1927-12-18—1927-12-19 [N.S.]｜季加承认观点错误并请求复籍

- **经济 / 社会线**：高层经济争论的合法发言资格越来越依赖政治认错，而非单纯承诺服从多数。
- **组织 / 政治线**：多伊彻把季诺维也夫、加米涅夫进一步承认反列宁主义观点定于18日；同时代19日决议称收到当日提交的复籍申请。可理解为政治屈服与书面递交的相邻程序，不能抹去日期差。
- **定年与证据边界**：保留18–19日双锚；不把请求复籍写成大会立即恢复党籍。 事件候选 `TL-W15-L3-27-15`。[^T][^DW]

<a id="tl-w15-l3-27-16"></a>

### 1927-12-19 [N.S.]｜大会拒绝集体复籍要求并闭幕

- **经济 / 社会线**：中央经济政策开始在被清除异议后的领导格局中实施，但1928年的具体转向尚未完全定型。
- **组织 / 政治线**：大会对季、加等23人的申请不作即时集体恢复，要求经个别审查与后续考察程序处理。政治服从没有换来当日复籍；“留党察看”也不适合描述已经无党籍者的法律状态。
- **定年与证据边界**：以同时代报刊所刊19日决议为锚；六个月后个别申请与当前党籍分开。 事件候选 `TL-W15-L3-27-16`。[^DW][^T]

<a id="tl-w15-l3-27-17"></a>

### 1927-12-24 [N.S.]｜第二封购粮通函与公开示警

- **经济 / 社会线**：中央再次催办；《真理报》小栏消息称米高扬派高级贸易干部赴主要收购区。加强供应和组织施压此时尚同时使用。
- **组织 / 政治线**：报刊公开示警不同于党内处分叙事的胜利口吻。Carr–Davies认为这是公开警报的一次早期表现，但不能据此断言此前所有地方报刊都未报道困难。
- **定年与证据边界**：内部通函与公开报刊消息为同日两种材料，本卷按一格并列。 事件候选 `TL-W15-L3-27-17`。[^G]

<a id="tl-w15-l3-27-18"></a>

### 1927-12-27—1928-01-15 [N.S.]｜增加重点收购区工业品供应

- **经济 / 社会线**：12月27日至1928年1月15日，列宁格勒向西伯利亚、乌拉尔、伏尔加、乌克兰及北高加索增发棉纺品；Carr–Davies称超过通常数量两倍。此为指定线路和时段，非全苏全部商品。
- **组织 / 政治线**：这些经济诱因与1928年1月6日紧急指令相衔接，说明从市场补救到行政强制有过程，不宜把全部变化归于单日大转弯。
- **定年与证据边界**：供应区间为尾声，跨入次年；不是1927年12月已有全面集体化法令。 事件候选 `TL-W15-L3-27-18`。[^G]

### 史学争鸣槽：共同事实与解释光谱

**经验事实共识**：政纲流通受到禁止，警察突袭复制处，托季分两阶段失去中委与党籍，十五大扩大清除并拒绝立即恢复季加党籍；国家购粮显著低于上年同期。各材料对人群支持程度、挑衅细节、中央动机及购粮根因的解释并不相同。

| 解释取向 | 代表来源 | 本卷的并置办法 |
| :--- | :--- | :--- |
| 左翼传记、失败与一党制悖论 | Deutscher | 强调警察挑衅、群众退潮与反对派不肯突破一党制；同情立场不能代替对具体示威的独立证据。 |

## [T3] 深度考证、出处与证据缺口

### 一、印刷所案的三个证据层次

**可确认的组织事件**是9月12–13日夜突袭、文本被扣和人员遭捕；“地下印刷所”在多伊彻描述中主要是打字复制网络，不宜按名称想象成设备完备的大型地下印刷厂。**官方指控**将反对派与前白军军官联系；**反对派及多伊彻解释**则指出此人是OGPU安排的线人。斯大林10月23日对借用非党员/线人查缉秘密活动的辩护，为比较双方解释提供同时代接口，却不等于本轮取得了线人卷宗、逮捕令和全部审讯记录。[^T][^S23]

政纲9月3日的定日来自中文编者；英文New Park译本只明确九月上旬提交。9月6日的交涉和中央禁印属于传播/程序事件，不能倒过来当成政纲的原件署定日。现库政纲只收入第3、4、7章，不能声称本轮按全12章逐字校订。[^P]

### 二、十周年街头冲突与越飞材料

反对派以自己的横幅和口号参加官方纪念动员。多数派将其解释为反党乃至反革命行动；托氏一方强调自我表达与和平抗议。此卷采用“独立口号/队列的示威遭压制”这一级事实，不把任一方的动机指控直接写入无主语叙事。枪击、暴力人数、城市各处先后仍主要出自回忆与传记，未给出一份看似精确的全市逐时伤亡表。[^T]

越飞遗书在英文转录署1927-11-16，并有后出法、葡文本以15日或15—16日之夜标写作时间；逝世日按16日。其关于医疗、政治剥夺、托洛茨基优劣的陈述均具有见证和政治评价双重属性。这里既不抹去政治抗议，也不把单一遗书视为医疗行政过程的全证。[^J][^T]

### 三、十五大清除、季加投降与复籍：日期分歧不强行焊合

- **12月10日**：按多伊彻，季派接受大会决定与托派分手，仍区分纪律服从与承认观点错误。
- **12月18日**：多伊彻叙述季加进一步认错；Daniels记大会批准清除75名联合反对派骨干，并把民主集中派另列。不同名单不能简单相加后不标口径。
- **12月19日**：同时代《Daily Worker》12月22日第3版检索摘录转刊的大会决议，称收到季加等23人的当日申请，并提及18日已有反对派决议。这提供“政治表态—正式递交—大会答复”的相邻程序链，但整份扫描PDF本轮因文件过大未取全，19日申请人数及逐字措辞暂保留待核标记。

季加的屈服并未即时换回党籍。多伊彻所谓等候六个月是后续申请条件，不能转成有党籍者的纪律术语“留党察看”。本卷也不把后来的复籍、再次开除或1930年代审判提前写到十五大。[^T][^D][^DW]

### 四、购粮统计、当时知识与后来解释

| 时间窗口 | 能够支持的观察 | 不应推出的结论 |
| :--- | :--- | :--- |
| 1927年9—10月 | 谷物收购相对价格下降，其他农产收益、现金与商品荒改变售粮动机。 | 所有不售粮者都是富农，或全国所有地区行为相同。 |
| 1927年11—12月 | Carr–Davies所述国家收购流量不足上年同期的一半。 | 粮食总产量也下降一半，或中央在11月1日已掌握完整两月统计。 |
| 12月14、24日 | 中央相继发催办通函，24日有公开派员消息。 | 中央到十五大后才第一次察觉危机。 |
| 12月27日—1928年1月15日 | 指定地区增发工业消费品，与组织督促并行。 | 1927年底仅有警察征粮一项政策，或已经实施1929年的乌拉尔—西伯利亚制度。 |

农业并非全无增长，但商品粮、国家渠道份额与国家工业化目标可能脱节。战争恐慌、国家/私人收购价格、技术作物选择、务工收入、税负和基层行政各有作用；不同地区及月份权重仍需继续比对。以上是后来的经济史重建，不能把作者掌握的年终统计全部塞进9月中央领导者的当时知识。[^G]
