## 4. 关联时间线锚点 (共 14 条)
- **1917-03-01 [O.S.] / 1917-03-14 [N.S.]** (`TL-W15-L1-E06-03`, L1): **苏维埃《第一号命令》** — 士兵委员会和政治服从安排改变军官权威；适用与传播须区分。
- **1917-03-21 [O.S.] / 1917-04-03 [N.S.]** (`TL-W32-1917-04-03-01`, L3): **策烈铁里自伊尔库茨克返抵彼得格勒并在执委会确立“革命护国主义”** — “西伯利亚齐美尔瓦尔德派”核心策烈铁里于1917-03-21 [O.S.] / 04-03 [N.S.]抵京，当晚在苏维埃执委会面对苏汉诺夫、拉林反战施压草案发表决定性演说，要求苏维埃“放弃不负责任的反对派政策”，把保卫革命俄国与国内进步资产阶级合作定为实现和平的前提，催生主宰苏维埃直至十月的孟什维克—社革党革命护国派联盟。
- **1917-03-25 [O.S.] / 1917-04-07 [N.S.]** (`TL-W32-1917-04-07-01`, L3): **临时政府颁布《粮食国家专卖法》；米留科夫兼并言论激化外交摩擦** — 在苏维埃经济部格罗曼等压力下，农业部长辛加廖夫于3月25日 [O.S.] / 4月7日 [N.S.]签署《粮食国家专卖法》，但随后向地主粮商倾斜并大幅提价；此前3月23日外长米留科夫公开发表夺取君士坦丁堡与奥匈领土言论，已引发苏维埃执委会抗议与联络委员会紧急施压。
- **1917-03-27 [O.S.] / 1917-04-09 [N.S.]** (`TL-W32-1917-04-09-01`, L3): **临时政府发表《对俄国人民宣言》妥协文本** — 在策烈铁里率联络委员会交涉下，临时政府于1917-03-27 [O.S.] / 04-09 [N.S.]发表声明，纳入“自由俄国的目标不是强行占领外国领土”，同时保留“完全恪守对盟国承担的义务”。加米涅夫—斯大林主导的《真理报》发表社论表示欢迎。
- **1917-03-29 [O.S.] / 1917-04-11 [N.S.]** (`TL-W32-1917-04-11-01`, L3): **第一次全俄苏维埃代表会议与全俄布尔什维克会议揭幕；斯大林作“分工固色”报告** — 82个地方苏维埃代表在彼得格勒召开第一次全俄苏维埃代表会议（3月29日–4月3日 [O.S.]）。同城布尔什维克会议上，斯大林将双重政权界定为苏维埃（发动与监督）与临时政府（“固色剂”）的分工，主张不可提前疏远资产阶级，并提议“一定限度内”支持临时政府；翌日更支持按齐美尔瓦尔德—昆塔尔路线与孟什维克探讨合并。
- **1917-04-04 [O.S.] / 1917-04-17 [N.S.]** (`TL-W32-1917-04-17-01`, L3): **列宁在塔夫利达宫两度宣读《四月提纲》，引发孟什维克与党内剧烈震动** — 1917-04-04 [O.S.] / 04-17 [N.S.]下午，列宁在塔夫利达宫先后于布尔什维克代表会及布尔什维克—孟什维克联席会上缓慢宣读《四月提纲》：明确第2条“从第一阶段向无产阶级和贫苦农民掌权的第二阶段过渡”、第3条“不给临时政府任何支持”，及第8条“不是把‘实施’社会主义作为直接任务，而只是立刻过渡到由工人代表苏维埃监督社会产品生产和分配”。博格达诺夫斥为“疯子胡言”，戈尔登贝格称其“竖起内战旗帜”，斯捷克洛夫亦驳斥，几仅柯伦泰一人公开声援；苏汉诺夫ch15末“April 14th”系4月4日印误。
- **1917-04-19 [O.S.] / 1917-05-02 [N.S.]** (`TL-W32-1917-05-02-01`, L3): **苏维埃执委会连夜召开紧急会议审查米留科夫照会却陷于瘫痪** — 1917-04-19 [O.S.] / 05-02 [N.S.]夜至次日黎明，苏维埃执委会紧急开会研读米留科夫照会，全体深感背叛；但因整个内阁包括克伦斯基皆为照会背书，策烈铁里与斯科别列夫极力淡化文本以保全联合局面，直至清晨未果而散，预定次日晚约见内阁。
- **1917-04-20 [O.S.] / 1917-05-03 [N.S.]** (`TL-W32-1917-05-03-02`, L3): **苏维埃晚间紧急全会与斯坦克维奇“差五分钟七点”名言暴露内阁空虚** — 1917-04-20 [O.S.] / 05-03 [N.S.]约19:00苏维埃全会上，布尔什维克费多罗夫直呼“现在已是内战”；劳动派斯坦克维奇指着挂钟惊呼“差五分钟七点，我们只需打个电话，五分钟后政府就会交权”，反倒触发全场欢呼并暴露临时政府毫无人力屏障。随后执委会在马林斯基宫与内阁通宵交涉。

- **1917-04-28 [O.S.] / 1917-05-11 [N.S.]** (`TL-W32-1917-05-11-01`, L3): **齐赫泽在“星室法庭”痛陈入阁代价并再次否决联合；彼得格勒工人筹组赤卫队** — 1917-04-28 [O.S.] / 05-11 [N.S.]晨在斯科别列夫公寓“星室法庭”会议上，社革党戈茨力劝入阁遭除沃伊京斯基外全部孟什维克核心拒绝；苏维埃主席齐赫泽痛陈入阁将在群众心中激发无法兑现的幻想。同日派普斯年表记布尔什维克及维堡工人开始筹建赤卫队。
