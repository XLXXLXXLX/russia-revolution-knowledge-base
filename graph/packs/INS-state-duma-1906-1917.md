1905年革命迫使君主制接受立法性国家杜马，但1906年基本法仍保障皇帝任免政府、解散杜马与紧急立法等重要权力。头两届在土地和政治责任问题上与王朝激烈冲突而短命；1907年选举法改变后，第三、四届更加保守。1915年进步同盟试图以议会压力改变政府，1917年二月杜马临时委员会参与接管政权，但须与彼得格勒苏维埃及革命中的街头力量共同分析。

### 2.1 核心历史脉络
- **制度与选举**：国家杜马和国务会议共同参与立法，并非对内阁拥有完整责任制的议会。主要选举路径按地主、城市、农民和工人等等级团分组，多级间接产生选举人，财产、性别、族群和地域限制造成代表权高度不均；城市团内部和边疆规则还有细分。1907年法进一步提高地主及有产阶层权重并压缩部分边疆代表，不能把四个等级团理解为每人一票的四个等额选区。
- **第一届**：`1906-04-27 [O.S.] / 1906-05-10 [N.S.]` 开幕，通常以 `1906-07-08 [O.S.] / 1906-07-21 [N.S.]` 标为最后会期；解散诏令与公布亦有 `1906-07-09 [O.S.] / 1906-07-22 [N.S.]` 的记载，须核原件区分日期。立宪民主党为最大党团，劳动派与农民代表推动强制征收地主土地等方案；土地、政治犯赦免及内阁责任制冲突使宫廷与杜马破裂。部分代表赴维堡发表不合作宣言，不能把这次解散归为单一法案的直接结果。

- **第三、四届**：第三届于 `1907-11-01 [O.S.] / 1907-11-14 [N.S.]` 开幕，1912年届满；其间十月党与民族主义及温和右翼形成不同组合，支持斯托雷平政府的议案，仍有议会内部竞争。第四届于 `1912-11-15 [O.S.] / 1912-11-28 [N.S.]` 开幕。1915年战时危机催生跨党派进步同盟，要求能获公众信任的内阁；这与明确要求对杜马负责的内阁并不完全相同（Gaida，pp. 134–175）。
- **二月与终结**：`1917-02-27 [O.S.] / 1917-03-12 [N.S.]` 杜马领导人面对停会诏令、起义军人与群众成立临时委员会，随后参与建立临时政府；这不等于杜马正式复会掌握了全部权力。临时政府后来正式解散第四届杜马；常见日期为 `1917-09-23 [O.S.] / 1917-10-06 [N.S.]`，原始法令及日期口径仍待核。

## [T1] 核心问题定义
一战前俄国工业增长与有限政治改革能否导向持久稳定，还是1912—1914年的城市冲突暴露了难以调和的危机？争论涉及对罢工、政治制度及社会变化的解释，也涉及无法直接验证的无战争反事实。

## [T2] 各学派立场对照矩阵
