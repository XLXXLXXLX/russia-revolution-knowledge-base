### 2.1 分期语义裂变脉络

- **裂变 0｜1879–1881年：民意党纲领诉求——民粹主义向政治立宪的转向**
  - **持有者**：民意党执行委员会（`ORG-narodnaya-volya`，`1879-08-15 [O.S.] / 1879-08-27 [N.S.]` 成立）。
  - **内涵**：突破早期“土地与自由社”反政治的无政府教条，在1879年秋《民意党执行委员会纲领》中庄严宣告：推翻沙皇专制后，国家与社会制度须移交由**自由普选产生、受选民委托书约束的立宪会议**决定，认为90%议席将归农民代表，从而和平确立土地归人民所有与村社自治（`1879_programma-IK-narodnoi-voli_ru.md` L29–32, L68；`CLM-venturi-1960-narodnaya-volya-constitutionalism`, `[pp. 674–678]`）。`1881-03-01 [O.S.] / 1881-03-13 [N.S.]` 刺杀亚历山大二世后，执委会于 `1881-03-10 [O.S.] / 1881-03-22 [N.S.]` 致信亚历山大三世，开出若沙皇大赦并按普遍选举权召集全俄国民代表大会即无条件停止恐怖袭击的政治契约。

- **裂变 1｜1903–1906年：俄社民工党最低纲领、1905共同口号与“革命最高法则”裂痕**
  - **持有者**：俄国社会民主工党（`MTG-1903-rsdlp-2nd-congress`，布鲁塞尔—伦敦，`1903-07-30` 至 `08-23 [N.S.]`）、社会革命党（`ORG-psr`）、解放联盟/立宪民主党（`ORG-kadets`）及1905年工农运动。
  - **内涵**：1903年俄社民工党二大通过的党纲（最低纲领）将推翻沙皇专制、由普遍平等直接秘密投票选举产生的立宪会议建立民主共和国列为首要政治目标；`1905-01-09 [O.S.] / 1905-01-22 [N.S.]` 加邦《致沙皇请愿书》与同年四大反对派阵营均将“四尾普选立宪会议”奉为革命总口号（Treadgold `RN-W12` L58–90）。
  - **早期理论裂痕**：就在1903年二大上，普列汉诺夫（`PER-plekhanov`）已提出著名的雅各宾式命题——**“革命的安危是最高法律”（*salus revolutionis suprema lex*）**：若人民在革命热情推动下选出“好议会”自应延长之，若选出“坏议会”则应在两周内驱散之（Getzler `RN-W1B`, `[pp. 83–84]`；列宁1918年解散立宪会议时曾当面反唇援引普列汉诺夫此语）。

- **裂变 2｜`1917-03` 至 `1917-10 [O.S.]`：临时政府的一再推迟与布尔什维克的策略性反用**
  - **持有者**：临时政府（`ORG-provisional-government`）、温和社会主义者与布尔什维克（`PER-lenin`）。
  - **内涵**：`1917-03-02 [O.S.] / 1917-03-15 [N.S.]` 临时政府成立宣言将“尽速按四尾原则筹备立宪会议”定为自身唯一合法过渡使命，并把土地改革、国家政体与民族自治等一切根本问题悉数挂起留待立宪会议裁决（Figes `ch16` L110）。然而因前线战事、选举法起草缓慢及立宪民主党畏惧过早普选惨败，政府迟至6月才将选举日定于 `1917-09-17 [O.S.] / 1917-09-30 [N.S.]`，8月又再度推迟至 `1917-11-12 [O.S.] / 1917-11-25 [N.S.]`（会议召集定于 `11-28 [O.S.] / 12-11 [N.S.]`）。
  - **双重话语运作**：列宁在 `1917-04-04 [O.S.] / 1917-04-17 [N.S.]`《四月提纲》第5条已判定议会制共和国较苏维埃是“倒退一步”，却在同篇党纲修订建议中猛烈抨击临时政府甚至不敢公布召集日期（`april-theses.md` L64, L112–114）；直至 `1917-10-25/26 [O.S.] / 1917-11-07/08 [N.S.]` 十月夺权当夜，苏维埃二大与《土地法令》仍公开承诺“确保按期召开立宪会议”，并将土地处置明文限定为“在立宪会议最终解决之前”（`1917-10-26_decrees-on-peace-and-land.md` L140, L148）。

- **裂变 3｜`1917-11-12` 至 `1918-01-06 [O.S.]`（`1917-11-25` 至 `1918-01-19 [N.S.]`）：全俄普选、党内争执与塔夫利达宫一夜解散**
  - **普选结构与城乡/战线撕裂**：自 `1917-11-12 [O.S.] / 1917-11-25 [N.S.]` 起举行的俄国史上首次多党民主普选（早期统计约3600万–3750万票，Oliver Radkey 1989 扩编后期的70余选区修订口径达**约4170万选票**，参 `DATA-01`、Figes `ch18` L254–257、Rabinowitch 2007 `[p. 69]`）：
    - **社会革命党（含民族社革派）**：俄国本土社革党获约 **38%–40%**（约1600万票，若叠加乌克兰社革党约12%等泛社革阵营则逾半数、在约703席中占约380席），选票集中于中央黑土农业区与西伯利亚；但因选票名单印制于左翼社革党（`ORG-left-srs`）正式分裂前，**未区分反布尔什维克的右中派社革党与拥护十月政权及《土地法令》的左翼社革党**（结果社革党议员团中右中派控制绝大多数席位，左翼社革党仅获约40席）。
    - **布尔什维克**：全国获约 **24%**（约1000万票，约175席），虽输掉乡村普选，却在政治军事心脏取得压倒优势——彼得格勒获 **45.2%**（424,027票，卫戍部队高达75%，立宪民主党26.3%、社革党16.2%、孟什维克约3.1%–5%，Rabinowitch `[p. 69]` 引 Radkey p. 36），莫斯科亦占绝对多数，并在距两京最近的**北方战线、西方战线及波罗的海舰队**赢得决定性士兵多数；立宪民主党全国仅约 **4.7%–5%**，孟什维克塌缩至约 **3%**（主要靠格鲁吉亚选票支撑）。
  - **布尔什维克党内决裂与高压筹备**：`1917-11-21 [O.S.] / 1917-12-04 [N.S.]` 全俄中执委通过列宁起草的《罢免权法令》；`1917-11-28 [O.S.] / 1917-12-11 [N.S.]` 借口塔夫利达宫游行宣布立宪民主党为“人民公敌”党并逮捕其当选代表（Figes `ch18` L257–263）。12月中旬，列宁以《关于立宪会议的提纲》整肃由加米涅夫、李可夫、米柳京、梁赞诺夫主导、主张“苏维埃+立宪会议结合”的布尔什维克立宪会议党团临时局（`CLM-rabinowitch-2007-constituent-assembly`, `[pp. 89–91]`），并于 `1918-01-03 [O.S.] / 1918-01-16 [N.S.]` 抛出《被剥削劳动人民权利宣言》，强令立宪会议无条件承认苏维埃政权，把自身任务严格限于制定改造旧基础的总原则（`declaration-of-rights...md` L161–165）。
  - **召开与驱散**：`1918-01-05 [O.S.] / 1918-01-18 [N.S.]` 白昼，红赤卫队与士兵在利捷伊内大街（Liteinyi Prospekt）等路口向“保卫立宪会议同盟”和平游行队伍开火，造成约15–21人死亡（Rabinowitch `[pp. 106–109]`）；下午塔夫利达宫内，右中派社革党领袖切尔诺夫（`PER-chernov`）以 **244 票对 153 票**击败布尔什维克与左翼社革党联合推举的斯皮里多诺娃（`PER-spiridonova`）当选主席，并以 **237 票对 146 票**拒绝先行讨论苏维埃《权利宣言》；布尔什维克与左翼社革党先后退场，切尔诺夫等赶在闭会前夜宣读土地法、和平呼吁与俄国民主联邦共和国决议；至 `1918-01-06 [O.S.] / 1918-01-19 [N.S.]` 凌晨4时许，无政府主义水兵警卫队长热列兹尼亚科夫以**“警卫累了”**中断会议，当夜全俄中执委正式颁令解散立宪会议（`EVT-1918-01-constituent-assembly-dispersal`）。

- **裂变 4｜1918年6–11月：萨马拉立宪会议委员委员会（`Комуч`）与“民主反革命”溃败**
  - **持有者**：以沃尔斯基等5名社革党当选代表于 `1918-06-08`（公历，改历后）借捷克斯洛伐克军团攻占萨马拉成立的“立宪会议委员委员会”（`ORG-komuch-and-democratic-counterrevolution`）。
  - **内涵与终局**：`Комуч`高举恢复全俄立宪会议主权与废除一党专政的红旗，保留八小时工作制与土地归农承诺；但因强行征兵重启对德与对红军战争，遭伏尔加农民冷遇甚至暴动，城市资产阶级亦敌视其社会主义色彩（Radkey 1963, `[pp. 454, 467]`）。`1918-09-08` 至 `09-23` 乌法国务会议被迫向西伯利亚保守派妥协成立五人执政府（Directory），最终在 `1918-11-18` 高尔察克（`PER-kolchak`）鄂木斯克军事政变与叶卡捷琳堡军官屠杀社革党代表中彻底覆灭（Mawdsley 1987, `[pp. 138–140]`）。

### 2.3 多流派争鸣光谱
- **经验共识**：自 `1917-11-12 [O.S.] / 1917-11-25 [N.S.]` 起举行的全俄普选中，布尔什维克仅获约24%选票（但在两京及北/西战线占优），社革党系获绝对多数；`1918-01-05/06 [O.S.] / 1918-01-18/19 [N.S.]` 会议仅开一夜即被布尔什维克—左翼社革党政府武力解散，且全俄农村并未因此爆发保卫议会的大规模起义。争鸣焦点在于**解散立宪会议究竟是蓄谋已久的极权政变还是政治极化互动的结果**，以及**为何四十年革命梦想在毁灭时几乎无人流血捍卫**。
- **[列宁主义苏维埃高级民主论 / V. I. Lenin, L. D. Trotsky]**（`1918-01-03_declaration-of-rights...md`; Figes `ch18` L253–258）：主张阶级苏维埃代表制在革命巨变期远高于形式主义资产阶级议会民主；且1917年10月中旬拟定的统一社革党候选名单未能反映左翼社革党分裂与十月革命后的阶级重组，若向立宪会议交权无异于将政权奉还资产阶级反革命。
- **[自由—宪政极权起源派 / Richard Pipes, Leonard Schapiro]**（`DEB-1918-constituent-assembly-and-soviet-democracy`; `RN-W4B`）：将武力解散全俄唯一一次合法民主普选议会及 `1918-01-05 [O.S.]` 向手无寸铁的红旗游行者开枪，定性为布尔什维克摧毁现代法治、将少数派政变固化为极权独裁并直接引爆全面内战的原罪节点。
- **[温和社会主义选举与政党病理派 / Oliver H. Radkey]**（*The Sickle under the Hammer*, 1963 `[pp. 385–467]`; *Russia Goes to the Polls*, 1989）：一方面以详尽选票统计证明布尔什维克绝无全国多数授权；另一方面冷峻解剖社革党自身的致命弱点——在1917年因迁就自由派盟友拖延土地与和平改革而透支声望，1918年1月5日切尔诺夫等人因恐惧重演流血而自缚手脚解除亲立宪会议部队武装，夏秋萨马拉`Комуч`又因强征农民当兵抗德抗红而自毁群众根基（`RN-W20` L186, L197）。
