## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络
- **斯米尔诺夫造词与1920年战时通胀税的早期借用（1919–1920）**：该概念并非普列奥布拉任斯基首创。1919–1920年间苏联经济学家 V. M. 斯米尔诺夫比照马克思“原始积累”术语提出 **“社会主义原始积累”**；普列奥布拉任斯基1920年《纸币》一书借用并归于斯米尔诺夫，当时主要指战时向小生产者征收通胀税的分析工具，而非宣称历史必然走向某终点（Erlich pp. 43n, 50n）。
- **1924–1926年《新经济学》经济学定律化与四大结构约束诊断（1924.08–1926）**：1924年夏秋，普列奥布拉任斯基在共产主义科学院宣读并发表《社会主义积累的基本规律》（后作为核心第2章收入1926年出版的《新经济学》 *Новая экономика*），放弃了战时滥发纸币导致卢布崩溃的旧主张，将“社会主义原始积累”正式升华为新经济政策（NEP）过渡时期的客观经济学基本规律（Erlich pp. 31–32, 43–50 / PDF pp. 48–49, 60–67）。其严密的经济学推导建立在对四大结构性约束的发现之上（`CLM-erlich-1960-preobrazhensky-dilemma`）：
  1. **固定资本集中更新欠账（Bunched Replacement）与高资本产出比**：战时与恢复期耗尽了闲置产能储备，多年未重置的折旧设备必须集中更新并采用更高资本密集度技术；为使轻工业消费品年产增加1亿卢布，前期生产资料（第I部类）产量须增加4亿至5亿卢布（边际资本产出比4:1至5:1），且新厂建设周期长达3至4年（Erlich pp. 32–34, 40–41 / PDF pp. 49–51, 57–58）；
  2. **十月革命废除农民“强制销售（Forced Sales）”引发的结构性商品荒**：沙俄时代高额地租与重税迫使农民进行不求工业品回报的“强制销售”；十月革命消灭地租并将1924–1925年农业税降至战前负担的不足1/3，结果不仅使农村对城市工业品的有效需求暴增（引发1925年抑制性通胀“商品荒”），更赋予农民“选择何时、按何种条件出售余粮的更大自由（the peasants are nowadays in no hurry to sell grain）” `[pp. 34–36 / PDF pp. 51–53]`；
  3. **国营工业初期效率劣势与无法剥削本国工人**：国营大工业相对西方资本主义和国内小生产暂处成本劣势，且工人国家不能靠压低本国工人实际工资与健康来积累 `[pp. 44–49 / PDF pp. 61–66]`；
  4. **压制“价值规律”的两大非等价交换杠杆**：因此，在国营工业完成技术改造、实现自我积累（真正的社会主义积累）之前的过渡阶段，“社会主义原始积累规律”必须同市场“价值规律”展开对抗，通过**“社会主义保护主义（外贸垄断，严禁进口消费品、用农业出口外汇集中进口机器）”**与**“国营工业垄断定价（把工业品垄断高价作为无需专门税务机构的隐蔽‘价格税’）”**，实现“以社会主义体系较少劳动量换取非社会主义（小农）体系较多劳动量”的不等价交换 `[pp. 44, 46–50 / PDF pp. 61, 63–67]`。
- **农经学派、布哈林与国家计委专家的结构性反驳（1924–1928）**：除布哈林外，**恰亚诺夫（Chayanov）** 劳动—农户平衡理论与 **康德拉季耶夫（Kondratiev）** 等农业人民委员部/财政人民委员部实证研究指出：压低粮价、抬高工业品垄断价会诱使小农缩减商品粮与退回自给自足，反而窒息原料与出口基础；小农家庭劳动不存在资本主义式剩余弹性，使普氏“价格税”模式在统计上难以持续。国家计委前孟什维克专家 **格罗曼、巴扎罗夫** 亦警告超速投资周期失衡。布哈林政治经济学反击称普氏方案有撕裂工农结合、重演1923年剪刀差危机之虞（`CLM-erlich-1960-bukharin-balanced-growth`, `CLM-cohen-1973-nep-viability`, `CLM-carr-davies-1969-nemchinov-table-critique`）。
- **1924–1927年布哈林的猛烈论战批判与“内部殖民地”指控（1924.12–1927）**：布哈林从政治与宏观再生产双重视角批驳垄断价抽血，主张以降价周转与合作社储蓄换取更长程积累（Cohen pp. 179–184; Erlich pp. 11–23）。
- **1928–1929年与斯大林“贡赋论”及强制全盘集体化的异同分野（1928.01–1931）**：1928年1月粮食收购危机爆发后，斯大林在1928年7月中央全会上突然宣称：由于苏联没有外部殖民地和外债，农民除了缴纳普通直接税和间接税外，还必须在工业品高价与农产品低价的剪刀差中缴纳某种类似 **“贡赋（дань / tribute）”** 的超额税以资助工业化（`CLM-cohen-1973-july-1928-plenum-and-kamenev`, p. 290）。布哈林震惊地指控斯大林全盘抄袭了普列奥布拉任斯基的“军事封建剥削”理论，普列奥布拉任斯基本人也在1928–1929年一度以为斯大林的一五计划正在实践自己的《新经济学》而率先向斯大林归顺（`PER-preobrazhensky`）。然而，现代经济史家（Alexander Erlich、Moshe Lewin）深刻揭示了**普列奥布拉任斯基“社会主义原始积累”与斯大林1929年底“自上而下革命（全盘集体化）”的根本制度鸿沟**（`CLM-erlich-1960-preobrazhensky-dilemma`, `CLM-erlich-1960-stalin-overkill-turn`）：
  - **普氏模型始终预设在 NEP 市场与个体小农存续数十年的框架内运作**：他明确反对对小农使用暴力剥夺，之所以偏爱“价格税”恰恰是因为他认为直接强征重税会导致同农民决裂，且其价格杠杆严格受制于有效需求上限与农民“退回自然经济/拒绝售粮”的硬约束（1928年春他甚至警告不可对中农采取强制非常措施以免中农“在经济上感到厌倦”而缩减播种） `[Erlich pp. 44, 50, 170–171 / PDF pp. 61, 67, 185–186]`；
  - **斯大林则直接用极权国家暴力砸碎了整个 NEP 市场博弈棋盘**：通过剥夺工会独立性（压低工人实际工资）与强制全盘集体化（剥夺农民支配余粮的自由，将指令性低价义务交售变成无需工业品对价的直接行政搜括），斯大林消除了普列奥布拉任斯基在市场框架内无法自解的“既要靠高价向农民抽血、又要靠廉价工业品诱导农民售粮”的二律背反。正如普列奥布拉任斯基后来在自我检讨中惊呼：“集体化——这才是问题的症结所在！我有过关于集体化的这一预测吗？我没有。” `[Erlich pp. 176–177 / PDF pp. 191–192]`

### 2.3 史学争鸣光谱（Historiographical Spectrum）
- **经验共识**：该术语由斯米尔诺夫首创，经普列奥布拉任斯基1924–1926年发展为左翼反对派的核心经济学理论；它敏锐抓住了十月革命消除地租后农民自用增加、市场商品率下降与工业固定资本集中更新之间的结构性鸿沟；1928年斯大林“贡赋论”在修辞上借用了这一逻辑，但1929年底的全盘集体化以直接行政暴力取代了普氏的价格与税收杠杆。
- **主要解释分歧**（详参 `DEB-1928-bukharin-alternative`）：
  - **[发展经济学模型重构与“内在两难”论 / Alexander Erlich]** (`CLM-erlich-1960-preobrazhensky-dilemma`, `CLM-erlich-1960-bukharin-balanced-growth`, `CLM-erlich-1960-stalin-overkill-turn`): 高度评价普列奥布拉任斯基对革命后农村有效需求膨胀（废除“强制销售”）、农村隐性失业、4:1至5:1高边际资本产出比及3–4年建设周期的穿透性诊断，认为其预演了战后西方发展经济学的核心命题 `[pp. xx, 34–42 / PDF pp. 13, 51–59]`。但 Erlich 同时证明：（1）普氏既未主张对小农施暴，也反对压低工人工资，且高度重视利用国际贸易进口机器以加速积累 `[pp. 44–49 / PDF pp. 61–66]`；（2）由于普氏默认保留NEP个体小农的市场销售自由，其“价格税”必然撞上农民减少售粮、退回家庭手工业的硬墙，陷入无法在市场内自解的逻辑死结 `[pp. 50, 170–171 / PDF pp. 67, 185–186]`；（3）斯大林靠全盘集体化与剥夺工会独立性强行破局，凭的不是更高的经济学智慧，而是“完全无视惊人人类代价的冷酷极权决心”，且普氏本人在1931年未刊稿中已警告超高速重工业投资将导致“过度积累危机” `[pp. 176–180 / PDF pp. 191–195]`。
  - **[新经济政策多元共识与政治决裂论 / Stephen F. Cohen]** (`CLM-cohen-1973-nep-viability`, `CLM-cohen-1973-july-1928-plenum-and-kamenev`): 强调普列奥布拉任斯基的“社会主义原始积累”构想虽然激进，但本质上仍是NEP左翼方案（预设在市场与个体农业框架内通过经济杠杆调节），因此“认为左派强烈反NEP的通行观点是错误的” `[p. 276]`；而布哈林在1926–1927年也吸收了对固定资本投资的重视，真正用警察国家“贡赋”和国内战争终结NEP的是斯大林 `[pp. 290, 317–320]`。
  - **[农村社会史与中期危机预言论 / Moshe Lewin, E. H. Carr]** (`CLM-lewin-peasants-1968-grain-procurement-crisis`, `PER-preobrazhensky`): 莱文指出普氏对结构性商品荒与投资断崖的警告包含深刻诊断，但不等于认定集体化暴力为唯一出路（Lewin 1968, PDF p. 12）。
  - **[农经统计实证派 / A. V. Chayanov, N. D. Kondratiev]**：以农户劳动力均衡与1920年代工农产品比价实证，质疑剪刀差式积累能否在个体农业长期存续；斯大林1930年代官方虽将“原始积累”词条打入冷宫，实践中却以更强硬的超经济征敛实现类似汲取（意识形态反讽）。

### `DEB-1924-socialism-in-one-country`：一国建成社会主义与不断革命论
## [T1] 核心问题定义
欧洲革命迟滞后，苏联能否凭国内资源建成社会主义，还是其完成须依赖国际革命？1924—1927年的论战同时涉及农民联盟、经济发展、国际安全与党内权力，不能把不同意义的“胜利”等同起来。

## [T2] 各学派立场对照矩阵

**经验共识**：斯大林与布哈林在反对左翼反对派时形成理论和政治联盟；季诺维也夫在1925年前后转而批评斯大林，1926年与托洛茨基等结成联合反对派。各方均以国际环境为问题，并非一方支持革命、另一方完全放弃国际事务。

| 立场或研究 | 核心论点及依据 | 争议和限制 |
| :--- | :--- | :--- |
| 斯大林、布哈林 | 苏联可以依靠工农联盟及国内建设发展社会主义；1925年党内文件区分国内建设的胜利与免受资本主义复辟和外部干预的最终保障。 | 两人论述及政策侧重点不完全相同，不能把1928年之后的分歧倒投到整个联盟时期。 |
| 托洛茨基及联合反对派 | 不断革命论强调革命发展跨越民主与社会主义任务、国内阶级关系与世界经济的相互依赖；孤立国家的社会主义完成依赖国际革命。 | 不等于主张等待外国革命而停止苏联经济建设；季诺维也夫的立场有自身演变。 |
| E. H. Carr, *Socialism in One Country*；Isaac Deutscher, *The Prophet Unarmed* | Carr把理论置于制度和国际关系发展的综合叙事中；Deutscher重视托洛茨基及党内政治斗争与国际革命前景。 | 各自叙事规模与政治解释不同，不应合并为统一学派；其具体论证仍需按章节细读。 |
| Stephen Kotkin, *Stalin*, vol. 1；萨哈罗夫（Sakharov）的相关研究待核 | Kotkin利用党内文本与档案追踪理论措辞及权力联盟；本地 Sakharov 文献可供核查党内权力机制。 | 不将萨哈罗夫预先归入任何确定立场：其本地著作的准确书目信息及与本争论的直接关系须核实。 |
