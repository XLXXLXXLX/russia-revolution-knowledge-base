## [T1] 60秒定性微摘要
萌芽于1905年苏维埃；1917-03-02[O.S.]/03-15[N.S.]至七月事件，临时政府名义主权与彼得格勒苏维埃工兵实力、“有条件支持”并存。列宁四月称两类阶级专政交织，七月宣布终结，九月再提苏维埃夺权；修正史学强调多中心失序与双方虚弱。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

> [!IMPORTANT]
> **第五铁律警示**：“双重政权”（`Двоевластие`）在1905–1930年间经历了**四重语义与评价翻转**：(1) **苏维埃温和派（策烈铁里、苏汉诺夫、丹，1917年3–4月）**眼中的**权宜监督宪制**——因社会主义物质条件未熟，由资产阶级执掌行政、民主派苏维埃握有“有条件支持”（`постольку-поскольку`）的否决权；(2) **自由派与军方（古契柯夫、米留可夫，1917年春）**口中的**毁灭性病理指控**——苏维埃篡夺兵权导致“有责任而无权力”的无政府瘫痪；(3) **列宁（1917年4月—9月）与托洛茨基（1930）**笔下的**不稳定的阶级过渡范畴**——资产阶级专政与工农革命民主专政无法共存的短暂均势，但在四月导向“和平争取苏维埃多数”，七月被判“终结”，九月则转变为“武装起义机关”；(4) **当代修正与文化史学（长谷川毅、Rabinowitch、Wade、Kolonitskii）**的**去二元化重构**——并非两个强力中心的对称博弈，而是临时政府自断杜马法统后的“双向虚弱”“多中心权威”（`многовластие`）乃至基层“无政权状态”（`безвластие`）。

### 2.1 分期语义裂变脉络

- **裂变 0｜1905年10–12月：圣彼得堡苏维埃——尚未命名的“革命政府胚胎”**
  - **持有者**：圣彼得堡工人代表苏维埃（`1905-10-13 [O.S.] / 1905-10-26 [N.S.]` 至 `1905-12-03 [O.S.] / 1905-12-16 [N.S.]`，存续52个日历日，峰值代表562人）与维特沙皇内阁。
  - **内涵**：全城总罢工委员会迅速越出劳资谈判边界，接管邮电铁路罢工调度、宣布废除书报检查并夺取印刷厂出版《消息报》（`Известия`），在沙皇政府旁形成事实上的平行权威。
  - **在场与回溯的区分**：1905年现场并无`двоевластие`这一固定术语，当时工人与反动报刊均直呼苏维埃为“无产阶级政府”；将其定性为“革命政府的胚胎”并纳入双重政权谱系，是托洛茨基在《1905》（1908–1909初版、1922莫斯科增订版）中的**事后理论提炼**（`CLM-trotsky-1905-petersburg-soviet-embryo-government`，书页 `·248·`）。

- **裂变 1｜`1917-03-01` 至 `1917-05-05 [O.S.]`（`03-14` 至 `05-18 [N.S.]`）：“有条件支持”契约与“有政权无实力 vs 有实力无政权”**
  - **持有者**：国家杜马临时委员会衍生出的临时政府（`ORG-provisional-government`）与彼得格勒工兵代表苏维埃执委会（`ORG-petrograd-soviet`）。
  - **制度生成**：`1917-03-01 [O.S.] / 1917-03-14 [N.S.]` 苏维埃颁布《第一号命令》，第4条规定杜马军事委员会命令仅在不违背苏维埃命令与决议时方得执行；`1917-03-01/02 [O.S.] / 1917-03-14/15 [N.S.]` 午夜苏汉诺夫、索科洛夫、斯捷克洛夫与米留可夫等达成协议，苏维埃不入阁，但以“在临时政府履行承诺的限度内”（`постольку-поскольку`）予以有条件支持，并设联络委员会监督（Sukhanov `RN-W6`, `[pp. 121–125]`）；`1917-03-03 [O.S.] / 1917-03-16 [N.S.]` 米留可夫在首次内阁会议上主导抛弃国家杜马，自断唯一民选法统（Hasegawa 2018, `[pp. 626–638]`）。
  - **政治功能**：对孟什维克—社革党温和派而言，该格局符合“资产阶级民主革命阶段”教义，既避免过早承担执政责任吓退自由派，又以驻军与铁路控制权锁住反革命复辟；对陆海军大臣古契柯夫而言，则是临时政府“没有真实权力，只在苏维埃允许的限度内存在”的致命枷锁（`1917-03-09 [O.S.] / 1917-03-22 [N.S.]` 致阿列克谢耶夫信，Galili p. 126）。

- **裂变 2｜`1917-04-04` 至 `1917-04-09 [O.S.]`（`04-17` 至 `04-22 [N.S.]`）：列宁《四月提纲》与《论两个政权》的阶级重定性**
  - **持有者**：列宁（`PER-lenin`），《四月提纲》（`1917-04-04 [O.S.] / 1917-04-17 [N.S.]` 宣读，`04-07 [O.S.] / 04-20 [N.S.]` 刊于《真理报》）与《论两个政权》（`О двоевластии`，`1917-04-09 [O.S.] / 1917-04-22 [N.S.]` 刊于《真理报》第28号）及《论策略书》。
  - **内涵**：列宁将当时报刊流行的描述性词汇`двоевластие`铸造为严格的阶级专政分析概念——临时政府是**资产阶级专政**的机关，而工兵苏维埃则是类似1871年巴黎公社型国家的萌芽、即已经实现的**无产阶级和农民的革命民主专政**；二者交织源于小资产阶级群众将政权自愿让渡给资产阶级。
  - **对立面与策略边界**：一方面批判加米涅夫（`PER-kamenev`）“继续监督资产阶级政府、等待民主革命走完”的“老布尔什维克”公式已经过时（彼得格勒委员会曾以 **2:13:1** 否决四月提纲，Loginov `ch08` L554–611）；另一方面严厉禁止当时立即喊“打倒临时政府”的布朗基主义冒险，主张在苏维埃内部通过“耐心解释”和平争取多数，实现“全部政权归苏维埃”（`1917-04-04_april-theses.md` L52–72）。

- **裂变 3｜`1917-05-05` 至 `1917-07-10 [O.S.]`（`05-18` 至 `07-23 [N.S.]`）：联合政府陷阱与七月事件后列宁宣布“两个政权终结”**
  - **持有者**：第一届联合政府（`1917-05-05 [O.S.] / 1917-05-18 [N.S.]` 策烈铁里、切尔诺夫等6名社会主义者入阁）及七月事件后的列宁。
  - **内涵**：四月危机（`1917-04-18–21 [O.S.] / 1917-05-01–04 [N.S.]`）后，温和社会主义者违背三月“不入阁”初衷进入联合政府，从外部监督者变为与资产阶级捆绑的共同执政者（`CLM-galili-1989-coalition-government-trap`）。七月流血事件（`1917-07-03–05 [O.S.] / 1917-07-16–18 [N.S.]`）后，全俄中执委于 `1917-07-09 [O.S.] / 1917-07-22 [N.S.]` 赋予克伦斯基“拯救革命政府”无限权力；列宁遂于 `1917-07-10 [O.S.] / 1917-07-23 [N.S.]`《政治形势》提纲中宣布：**两个政权并存局面已经结束**，政权已决定性地转入反革命与军事独裁手中，“全部政权归苏维埃”的和平发展口号已经失效，妥协派苏维埃沦为遮羞的无花果叶（Loginov `ch16` L12–95；尽管7月13–14日中央扩大会议上10人投票未予支持，俄社民工党〔布〕六大仍暂时撤下该口号）。

- **裂变 4｜`1917-08-31` 至 `1917-10-25 [O.S.]`（`09-13` 至 `11-07 [N.S.]`）：科尔尼洛夫事件后的口号复活与起义掩体化**
  - **持有者**：列宁、托洛茨基（`PER-trotsky`）与布尔什维克化后的两京苏维埃。
  - **内涵**：科尔尼洛夫叛乱（`1917-08-27–30 [O.S.] / 1917-09-09–12 [N.S.]`）粉碎了右翼军事独裁企图，布尔什维克先后于 `1917-08-31 [O.S.] / 1917-09-13 [N.S.]` 和 `1917-09-05 [O.S.] / 1917-09-18 [N.S.]` 赢得彼得格勒与莫斯科苏维埃多数。9月上旬列宁短暂试探与孟什维克、社革党达成“对苏维埃负责政府”的最后和平妥协未果后，自 `1917-09-12–14 [O.S.] / 1917-09-25–27 [N.S.]` 起重新赋予“全部政权归苏维埃”以**武装起义推翻临时政府**的全新内涵；托洛茨基则在十月利用彼得格勒苏维埃军事革命委员会（MRC）与驻军围绕调兵签署权的“双重政权残余惯例”，在“保卫苏维埃二大”的合法防御姿态下完成夺权（Rabinowitch 1976 `RN-W17`; Trotsky 1930 `RN-W7` L149; Pipes `RN-W4B` L90）。

- **后世史学重构（1930—2018）：从托洛茨基“历史类型学”到“多中心失序/双向虚弱”论**
  - 托洛茨基在《俄国革命史》（1930，第11章《两个政权并存》）中将`двоевластие`升格为一切大革命（17世纪英国国会与新模范军、1789–1792法国制宪议会/公社与王权）的普遍规律，预示内战不可避免（`CLM-trotsky-1930-dual-power-instability`）。而自1970年代社会史学派至2017–2018年百年反思，学者们指出首都上层的二元图景遮蔽了工厂委员会、士兵委员会、区苏维埃、城市杜马、乡土地委员会与民族拉达各自为政的**“多中心政权”（`многовластие`）**及行政失灵的**“无政权状态”（`безвластие`）**。

### 2.3 多流派争鸣光谱
- **经验共识**：`1917-02-27 [O.S.] / 1917-03-12 [N.S.]` 同日在塔夫利达宫两翼成立的国家杜马临时委员会与彼得格勒苏维埃执委会，于 `1917-03-01` 至 `03-03 [O.S.]`（`03-14` 至 `03-16 [N.S.]`）形成政府掌名义行政、苏维埃握工兵否决权的制度安排；该格局历经四月危机、五月联合内阁、七月流血冲突与科尔尼洛夫事件，最终以十月临时政府覆灭告终。核心分歧在于**这一格局究竟源于苏维埃主动让权还是双方同样虚弱**，以及**“二元对立”能否概括1917年全俄真实的权力生态**。
- **[列宁—托洛茨基阶级专政过渡论 / V. I. Lenin, Leon Trotsky]**（`1917-04-04_april-theses.md`; `CLM-trotsky-1930-dual-power-instability`, `RN-W7`）：将双重政权视为社会平衡破裂后两个敌对阶级（资产阶级与无产阶级—贫苦农民）分裂国家上层建筑的过渡形态；温和社会主义者因小资产阶级妥协性拒绝接掌本来握在手中的政权，注定只能导向资产阶级军事独裁或无产阶级专政。
- **[当事温和社会主义者亲历论 / N. N. Sukhanov, I. G. Tsereteli]**（`RN-W6`, Carmichael ed. `[pp. 104–125]`; `RN-W5` Galili `[pp. 126–169]`）：**须区分在场行动记录与事后辩护**——苏汉诺夫在场记录证实3月1–2日执委会内部并无接管国家机器的行政准备，他本人当场对米留可夫称真实权力“要么在我们手里，要么谁也没有”（`[p. 124]`）；而其1922年回忆录中系统化的“资产阶级民主阶段必然论”与策烈铁里“全民族生命力量联合”说，则旨在论证唯有民主监督与联合才能避免内战。
- **[自我修正的制度—精英博弈论 / Tsuyoshi Hasegawa 2018]**（`CLM-hasegawa-2018-dual-power-origins`, `[pp. 626–638, 660]`）：正面驳斥托洛茨基“政权让渡论”，指出3月1–2日苏维埃内部混乱分裂、对骚乱士兵控制极弱，**“根本不存在可供让渡的现成政权”**（`[p. 633]`）；双重政权的真正悖论在于，米留可夫于 `1917-03-03 [O.S.] / 1917-03-16 [N.S.]` 为排挤罗将柯而蓄意废弃国家杜马，亲手砍掉唯一能与苏维埃抗衡的民选法统，迫使原本实力远强于苏维埃的临时政府沦为依赖苏维埃充当合法性中介的孤悬政权。
- **[西方社会史与地方多中心修正派 / Alexander Rabinowitch, Diane Koenker, Donald Raleigh, S. A. Smith, Rex Wade]**（`RN-W8B`, `RN-W15`, `RN-W17`, `RN-W20`, `DEB-1917-dual-power-and-february-origins`）：挑战首都高层“二元中心”模型。Rabinowitch（1968/1976）与 Koenker（1981）、Smith（1983）揭示工厂委员会、区苏维埃、工会、士兵委员会乃至布尔什维克党内（中央、彼得堡委员会、军事组织）均高度自主分权；Rex Wade 等学者强调1917年实为遍布全俄城乡与边疆民族的**“多中心扩散型权威”（multiple/diffused power，`многовластие`）**，临时政府与苏维埃温和派面对经济崩溃与士兵厌战均呈**“双向虚弱”**。
- **[政治文化、话语符号与情绪史派 / Boris Kolonitskii, Orlando Figes, Mark Steinberg]**（`sources/monographs/steinberg_2017_russian_rev/ch09` `[pp. 80–88 / PDF pp. 92–100]`; `RN-W5`; `RN-W32`）：通过街头小报、士兵来信与政治符号（红旗、马赛曲、“资产者`буржуй`”“人民公敌”话语）证明，双重政权的瓦解不仅是制度博弈，更是二月“准宗教式狂喜”迅速塌陷为恐慌、阶级仇恨与普遍“无政府状态”（`анархия / безвластие`）焦虑的情绪与话语极化过程。

## 2. 一跳邻域全量微摘要目录 (去重后共 15 个节点，0 截断)

- **`ORG-petrograd-soviet`**（彼得格勒工兵代表苏维埃）: 二月革命后诞生于塔夫利达宫的工兵政权，颁布《第一号命令》。执委会主席为齐赫伊泽，策烈铁里是常务局核心并主导革命护国路线。1917-08-31[O.S.]/09-13[N.S.]首次通过布尔什维克决议，托洛茨基随后任主席；十月军事革命委员会成为推翻临时政府的枢纽。 ‖ `←CON-dual-power`[de-facto-veto-pole|1917-03-12–1917-11-07 [N.S.]]: 凭《第一号命令》掌握驻军与铁路通讯，从外部“有条件支持”演变为布尔什维克夺权载体
- **`ORG-provisional-government`**（1917年俄国临时政府）: 1917年3月至11月俄国最高行政机关：由自由主义杜马派在李沃夫公爵主持下组成，宣称继承沙皇“全部政权”，却在工兵苏维埃与前线《第一号命令》制约下陷入土地、军队与和平三重困局；经四届内阁（李沃夫首届、五月至九月三次资产阶级—社会主义联立内阁及九月短期五人执政内阁）未能稳住宪政民主，终为十月起义推翻。 ‖ `←CON-dual-power`[de-jure-executive-pole|1917-03-15–1917-11-07 [N.S.]]: 承接形式国家主权但自断杜马法统，丧失强制工具而仰赖苏维埃合法性中介
