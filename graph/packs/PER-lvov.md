### 2.1 核心历史脉络
- **波波夫卡庄园实践、地方自治与战时“泽姆戈尔”（Земгор）主席（1861–1917.02）**：`1861-11-02 [N.S.]` 生于萨克森王国德累斯顿，幼年随家返图拉省阿列克辛县波波夫卡庄园，1885年毕业于莫斯科大学法律系，深受斯拉夫派与托尔斯泰主义的平民伦理熏陶。曾投身1891–1892年饥荒赈济，1902–1905年任图拉省地方自治局执行局主席（1905–1906年冬因贵族保守反扑落选，保守派姻兄博布林斯基伯爵斥其为“危险的自由派”，Figes 1996，`ch12_5`），日俄战争期间赴满洲前线组织地方自治联合医疗队，1906年当选第一届国家杜马议员（接近立宪民主党与进步派，但始终厌恶党派门户）。一战爆发后，于 `1914-07-30 [O.S.] / 1914-08-12 [N.S.]` 当选全俄地方自治联合会（ВЗС）总代表，并于 `1915-07-10 [O.S.] / 1915-07-23 [N.S.]` 起兼领**全俄地方自治与城市联合会供应军队总委员会（Земгор / Zemgor）**主席，动员数十万公共人员承担伤兵救护、难民安置与军需生产，赢得跨党派声望；1916年底对沙皇宫廷彻底绝望，曾在进步同盟场合断言现政府已无可合作，并与总参谋长阿列克谢耶夫密商宫廷易位与“信任内阁”方案（Figes 1996，`ch14_7`）。
- **首届临时政府与“民粹式自由主义”国家试验（1917.03–04）**：二月起义胜利后，国家杜马临时委员会与彼得格勒苏维埃执委会于 `1917-03-02 [O.S.] / 1917-03-15 [N.S.]` 推举无鲜明党籍、能平衡米留科夫与克伦斯基的李沃夫出任临时政府总理（部长会议主席）兼内务部长。`1917-03-03 [O.S.] / 1917-03-16 [N.S.]` 李沃夫主持首次正式内阁会议，采纳米留科夫主张，宣布原属君主的“全部完满权力”移交临时政府而非国家杜马，从而切断了与罗将柯杜马机构的法统纽带，使政府合法性实际悬系于彼得格勒苏维埃的“有条件支持”（Hasegawa，`ch40`，`pp. 626–631`）。执政首月，李沃夫签署一系列划时代自由法令（政治大赦、言论出版结社自由、废除等级宗教民族歧视、包含妇女选举权的普选制、废除死刑），并于 `1917-03-05 [O.S.] / 1917-03-18 [N.S.]` 通令罢免旧省长、改由省地方自治局主席任政府专员、以地方民兵取代沙皇警察，使俄国一夜号称“世界上最自由的国家”；但他把国家视为超阶级中立看守人、盲目笃信民众会耐心守法静候立宪会议的“民粹式自由主义”信念，在基层行政解体面前迅速失灵（Figes 1996，`ch16_9`）。
- **四月危机、首届联合政府与三重结构困局（1917.04–07）**：`1917-04-18 [O.S.] / 1917-05-01 [N.S.]` 米留科夫照会引发首都反战风暴与陆海军部长古契科夫辞职后，李沃夫联手涅克拉索夫并力劝孟什维克领袖策烈铁里，以挤走米留科夫及以自身辞职相要挟，促成苏维埃温和派入阁，于 `1917-05-05 [O.S.] / 1917-05-18 [N.S.]` 组建**第一届联合临时政府**（李沃夫续任总理兼内务部长，并与克伦斯基、捷列先科、涅克拉索夫、科诺瓦洛夫及策烈铁里形成核心决策圈，Figes 1996，`ch16_9`）。然而5至7月间，乡村农民借基层委员会大举夺占贵族庄园，前线士兵在《第一号命令》与厌战情绪下瓦解了六月攻势，乌克兰中央拉达于 `1917-06-10 [O.S.] / 1917-06-23 [N.S.]` 颁布《第一号通谕》更引发立宪民主党阁员于 `1917-07-02 [O.S.] / 1917-07-15 [N.S.]` 集体退阁抗议（李沃夫私下痛斥立宪民主党右翼在乌克兰问题上表现得“如同最恶劣的黑百人团”）。

N. Lvov，非本卡亲王）。十月革命后隐居秋明，1918年初被布尔什维克逮捕押往叶卡捷琳堡，获准保释后潜逃鄂木斯克，于 `1918年秋 [N.S.]` 赴美游说援助白军，继赴巴黎主持1919年巴黎和会期间的白卫外交协调机构“俄国政治会议”。白军败亡后淡出高层政争，在巴黎重操“泽姆戈尔”旧业救济俄国饥民与流亡难民，1923年致巴赫梅捷夫信中承认新经济政策已满足农民土地愿望、苏维埃政权因吸纳平民干部而被民众视为“自己的政权”；`1925-03-07 [N.S.]` 在巴黎近郊塞纳河畔布洛涅寓所睡梦中心脏病突发逝世（Figes 1996，`ch24_conclusion`）。

### 2.3 史学争鸣光谱
- **经验事实**：李沃夫长期领导地方自治与战时“泽姆戈尔”体系，于 `1917-03-02 [O.S.] / 1917-03-15 [N.S.]` 至 `1917-07-07/08 [O.S.] / 1917-07-20/21 [N.S.]` 任临时政府总理兼内务部长，主持废除旧省长警察体制与组建首届联合政府，并在七月危机后辞职流亡巴黎，均具完整档案与回忆录支撑。
- **主要解释分歧**（详参 `DEB-1917-dual-power-and-february-origins`）：
  - **[“民粹式自由主义”与宪政错位悲剧论 / Orlando Figes]**（Figes 1996，`ch16_9`、`ch17_10`、`ch24_conclusion`）：菲格斯反驳了霍尔爵士（Samuel Hoare）或纳博科夫将李沃夫单纯贬为“消极无能老好人”的成见，指出李沃夫具备卓越的地方自治实干才干（策烈铁里与高尔基均予高度评价），其真正悲剧在于思想结构错位——他怀着斯拉夫派与托尔斯泰式的“人民善良智慧”信仰，误将1789年西欧宪政法治模板套用于渴望“农奴复仇”与即时分地的俄国社会，主动拆毁省级强制机器并无限期推迟土地改革以等待完美立宪会议，结果合法性呼吁反而加速了乡村夺地与军队解体。
  - **[双重政权制度起源与自断杜马根基论 / Tsuyoshi Hasegawa & A. B. Nikolaev]**（Hasegawa，`ch40`，`pp. 621–631`）：长谷川毅与俄国学者尼古拉耶夫聚焦 `1917-03-03 [O.S.] / 1917-03-16 [N.S.]` 李沃夫主持的首次内阁会议，指出李沃夫内阁为摆脱罗将柯及反民主选举法产生的第四届杜马束缚，宣布继承君主“全部完满权力”并视旧《基本法》失效；这一看似激进的“独裁寡头”宣示实则亲手砍断了唯一现成的代议机构支点，使缺乏武装忠诚的李沃夫政府彻底沦为仰赖彼得格勒苏维埃背书的“权力象征与胚胎”（佩舍霍诺夫语）。
  - **[俄国自由派困境与“叹着气的革命者”视角 / Fedor Gaida & William Rosenberg]**（参 `CLM-gaida-2003-liberals-in-february-1917`）：盖达与罗森伯格等自由主义政治史研究者强调，以李沃夫和立宪民主党人为代表的温和派本欲通过战时公共动员换取有序宪政改良，二月哗变迫使其在毫无党派组织下沉能力与国家财政崩溃的绝境中仓促接盘；五月至七月的联合政府试验并非李沃夫个人性格软弱所致，而是战时帝国总危机下自由派“国家本位（*gosudarstvennost'*）”与工农士兵激进社会革命诉求之间结构性断裂的必然产物。

## 3. 关联史学争鸣与学者论断索引 (主卡外关联争鸣 1 项)
### `DEB-1917-dual-power-and-february-origins`：二月革命起源与“双重政权”宪制形成之争（1917）
## [T1] 核心问题定义
二月革命是无领导的群众爆发，还是工厂与兵营中分散的积极分子推动的起义？沙皇退位后，杜马临时委员会、苏维埃与临时政府如何谈判并形成彼此制约的权力格局？群众压力、精英选择和战时危机的因果权重仍有争议，不能以宫廷阴谋代替街头革命。

## [T2] 各学派立场对照矩阵
**经验基准**：1917-02-23 [O.S.] / 1917-03-08 [N.S.] 国际妇女节罢工扩大；27日 [O.S.] / 3月12日 [N.S.] 首都预备营哗变，国家杜马临时委员会与彼得格勒工兵代表苏维埃在塔夫利达宫东西两翼同日成立；3月1日 [O.S.] / 3月14日 [N.S.] 苏维埃发布《第一号命令》；3月2日 [O.S.] / 3月15日 [N.S.] 尼古拉二世在普斯科夫退位并传位米哈伊尔大公；3月3日 [O.S.] / 3月16日 [N.S.] 米哈伊尔大公签署《拒绝即位宣言》（将最高政权形制交由普选立宪会议决定并呼吁服从临时政府），同日临时政府举行首次内阁会议。各机构的正式法统主张与实际暴力和行政控制力并不重合。
