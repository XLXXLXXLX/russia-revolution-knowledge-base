### 2.1 核心历史脉络
- **克里米亚战败与1861年废除农奴制宣言（1818–1861）**：生于莫斯科克里姆林宫 `1818-04-17 [O.S.] / 1818-04-29 [N.S.]`，尼古拉一世长子，早年由诗人茹科夫斯基等担任导师。`1855-02-18 [O.S.] / 1855-03-02 [N.S.]` 在克里米亚战争败局中继位；面对军事与财政危机，他于1856年向莫斯科贵族警告与其等待农奴自下而上解放，不如自上而下废除农奴制。经编辑委员会与改革派官僚（尼古拉·米留京、康斯坦丁·尼古拉耶维奇大公等）同保守领主反复博弈，亚历山大二世于 `1861-02-19 [O.S.] / 1861-03-03 [N.S.]` 正式签署《废除农奴制宣言》及《脱离农奴依附关系农民总法令》（`E01_1861-1881_narodniks`）。改革在法律上废除了地主对农奴的人身占有，却保留了地主对优质土地的“割地（отрезки）”、高出市价的49年高额赎买金与临时义务农阶段，并将份地产权捆绑于法定的“乡村公社（сельское общество）”及赋税赎金**连环保（круговая порука）**之下（`CON-peasant-commune-obshchina`）。这一妥协既引发别兹纳（Bezdna）等农村抗议，也使激进知识分子痛斥改革为骗局，埋下早期民粹派运动与长期农村土地革命的结构性根源（`RN-W2-zemlya-to-march-first`）。
- **地方自治局、司法与军事“大改革”及专制红线（1863–1874）**：1863年平定波兰起义后，亚历山大二世推进一系列现代制度建设：1863年颁布大学章程扩大高校自治；`1864-01-01 [O.S.] / 1864-01-13 [N.S.]` 颁布《省县地方自治局条例》，在省、县两级设立由各等级选举产生的**地方自治局（Земство）**，负责地方教育、医疗、道路与农艺统计，但将其严格限定于地方社会经济事务，拒不在帝国中央设立代议机构（“大厦未加顶”）；`1864-11-20 [O.S.] / 1864-12-02 [N.S.]` 颁布司法改革章程，引入公开审判、独立法官、辩护律师与陪审团制度（后来1878年查苏利奇案即借陪审团获判无罪）；`1874-01-01 [O.S.] / 1874-01-13 [N.S.]` 批准陆军大臣德米特里·米留京主持的普遍兵役制改革，以按教育程度减免服役年限取代旧式农奴终身兵役。然而，每当贵族或自由派人士请求召集全俄代议议会，亚历山大二世均坚决回绝，力图在维护绝对君主专制的前提下实现军事与行政现代化（`CLM-pipes-1990-patrimonial-state-and-intelligentsia`）。
- **1866年卡拉科佐夫行刺、保守转向与1870年代镇压循环（1866–1879）**：`1866-04-04 [O.S.] / 1866-04-16 [N.S.]`，前莫斯科大学生德米特里·卡拉科佐夫（伊舒京小组）在圣彼得堡夏园门前向亚历山大二世开枪未遂。此次遇刺成为其执政路线的关键转折点：沙皇旋即罢免圣彼得堡自由派总督列夫·佩罗夫斯基（索菲娅·佩罗夫斯卡娅之父，参 `PER-perovskaya`），起用彼得·舒瓦洛夫掌管第三厅、德米特里·托尔斯泰任教育大臣，强化书报检查与古典中学教育控制。高压政策非但未能扑灭反对运动，反而在1870年代激起青年一代“到民间去”（1874）、“50人案”与“193人案”（1877–1878）的对抗升级；`1878-01-24 [O.S.] / 1878-02-05 [N.S.]` 查苏利奇枪击彼得堡市长特列波夫并获陪审团无罪释放，以及同年8月克拉夫钦斯基刺杀第三厅厅长梅津采夫后，亚历山大二世下令将袭警与政治暴力案件移交军事法庭审理（`RN-W2-zemlya-to-march-first`, `pp. 585–617`）。`1879-04-02 [O.S.] / 1879-04-14 [N.S.]` 索洛维约夫在冬宫广场连开五枪行刺未遂后，沙皇于 `1879-04-05 [O.S.] / 1879-04-17 [N.S.]` 颁诏设立六大临时军事总督区实施全面戒严与绞刑镇压，直接促使土地与自由社内部的革新派于 `1879-06` 利佩茨克会议及 `1879-08-26 [O.S.] / 1879-09-07 [N.S.]` 组成民意党执委会并正式判处亚历山大二世死刑（`CLM-venturi-1960-lipetsk-voronezh-split`, `pp. 630–656`）。
- **洛里斯-梅利科夫咨询改革方案与“三月一日”遇刺（1880–1881.03）**：经历1879年11月铁路专列爆破未遂与 `1880-02-05 [O.S.] / 1880-02-17 [N.S.]` 哈尔图林冬宫餐厅大爆炸后，亚历山大二世于 `1880-02-12 [O.S.] / 1880-02-24 [N.S.]` 设立最高管理委员会，任命洛里斯-梅利科夫集军警与行政大权于一身（时称“心灵与理智的专政”），在严厉搜捕民意党的同时撤销第三厅（并入内务部警察司）、撤换教育大臣托尔斯泰以争取自由派社会支持（`RN-W2-zemlya-to-march-first`, `pp. 682–693`）。`1881-03-01 [O.S.] / 1881-03-13 [N.S.]` 清晨，亚历山大二世批准洛里斯-梅利科夫提交的设立“咨询性地方自治局与市政代表两委员会”草案，定于 `1881-03-04 [O.S.] / 1881-03-16 [N.S.]` 交部长委员会审议（须严格区分这一无立法权的官僚咨询机构与现代立宪议会宪政，且因宫廷绝对保密，民意党对此毫不知情）。同日下午约14:15，沙皇自米哈伊尔骑兵校场阅兵返程，虽听从第二任妻子尤里耶夫斯卡娅公主劝告改道避开小花园街爆破地道，却在行经**叶卡捷琳娜运河**（今格里博耶多夫运河）畔时遭佩罗夫斯卡娅指挥的投弹手伏击：雷萨科夫投出第一枚炸弹炸毁雪橇后，沙皇执意下车查看伤员，被伊格纳季·格里涅维茨基近身投掷的第二枚炸弹炸碎双腿，抬回冬宫后于约15:30失血身亡（`EVT-1881-03-assassination-of-alexander-ii`；`1881-03_march_first_assassination.md`）。弑君惨剧随后被波别多诺斯采夫用来在 `1881-03-08 [O.S.] / 1881-03-20 [N.S.]` 御前会议上促成亚历山大三世搁置咨询草案，并于 `1881-04-29 [O.S.] / 1881-05-11 [N.S.]` 颁布《不可动摇之专制宣言》。

### 2.3 史学争鸣光谱（Historiographical Spectrum）
- **经验共识**：亚历山大二世主持了1861年废除农奴制及地方自治局、司法、兵役等重大改革，但始终拒绝设立全国性立宪议会；1870年代末专制镇压与革命恐怖陷入螺旋升级；`1881-03-01 [O.S.] / 1881-03-13 [N.S.]` 他在签署洛里斯-梅利科夫咨询草案数小时后遇刺身亡，继任者亚历山大三世旋即转向全面反改革。
- **主要解释分歧**（关联争鸣：`DEB-1879-narodnaya-volya-to-bolshevism`）：
  - **[文图里政治与运动史解释 / Franco Venturi]**（`CLM-venturi-1960-lipetsk-voronezh-split`, `CLM-venturi-1960-narodnaya-volya-constitutionalism`, `RN-W2-zemlya-to-march-first`）：强调1861年改革对农民份地的苛刻限制与1870年代司法高压（如“193人案”长期羁押与1879年军事总督区绞刑）封死了和平改良渠道；针对1881年3月1日事件，文图里明确指出洛里斯-梅利科夫方案仅是吸收部分地方自治局与市政代表参与立法的**纯咨询性委员会（consultative commissions）**，绝非现代立宪制度，而真正扼杀渐进转机的是3月8日波别多诺斯采夫与亚历山大三世的专制反动（`RN-W2-zemlya-to-march-first`, `pp. 687–716`；`1881-03_march_first_assassination.md`）。

### `DEB-1879-narodnaya-volya-to-bolshevism`：民意党与布尔什维主义：密谋传统的连续性与异质性
## [T1] 核心问题定义
民意党的秘密纪律、职业革命与政治暴力，同后来的布尔什维克组织之间有何关系？争论必须分别考察组织手段、革命目标、道德论证和具体传承链条：相似的地下技术本身不能证明永久党专政或思想一脉相承。
