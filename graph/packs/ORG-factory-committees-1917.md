## [T1] 60秒定性微摘要
二月革命后兴起的企业工人自治与监督组织，先在彼得格勒国有军工大厂成形。十月前开四次市级及一次全俄代表会议，至1918年初市级共六次；从保生产、防失业转向政治激进。1918年初经济瓦解与政党生产主义推动其并入产业工会，管理趋于国家集中，但合议制与自主诉求仍存。

### 2.1 核心历史脉络
> 历法提示：`1918-02-14` 苏俄改历前日期均标 `[O.S.] / [N.S.]` 双历；`1918-02-14` 起为公历 `[N.S.]`。

- **二月革命后的诞生与国有军工厂接管（`1917-03` 至 `1917-04`）**：承袭1905年长老代表（*старосты*）传统，二月革命后军官与旧管理层撤离彼得格勒炮兵总局和海军部下属官办军工厂（*казённые заводы*），各厂工人大会民主选举**工厂委员会**（Фабзавкомы）接管日常运转；私营企业工厂委员会初期则代行集体谈判并重点监督雇佣、解雇与车间尊严（“信息性控制”）。
- **四次彼得格勒代表会议与“防御性工人监督”（`1917-05` 至 `1917-10`）**：面对燃料断供与运输瘫痪，工厂委员会连开代表会议建立**彼得格勒工厂委员会中央理事会（CCFC）**：
  - 第一次彼得格勒代表会议（`1917-05-30 [O.S.] / 1917-06-12 [N.S.]` 至 `06-03 [O.S.] / 06-16 [N.S.]`）：布尔什维克压倒孟什维克与无政府工团主义夺得主导权（Smith 分别记录布尔什维克方案 290 票对无政府主义者茹克 45 票，以及季诺维也夫提出的列宁经济危机与国家工人监督决议获 **297 票赞成、21 票反对、44 票弃权** 通过，英文版 `pp. 144, 156`）；
  - 第二次（`1917-08-07 [O.S.] / 08-20 [N.S.]` 至 `08-12 [O.S.] / 08-25 [N.S.]`，米柳亭决议获 213 票赞成、26 票反对、22 票弃权，无政府工团派沃林案仅 8 票）、第三次（`1917-09-05 [O.S.] / 09-18 [N.S.]` 至 `09-10 [O.S.] / 09-23 [N.S.]`）与第四次（`1917-10-10 [O.S.] / 10-23 [N.S.]`）彼得格勒代表会议及第一次全俄工厂委员会代表会议（`1917-10-17 [O.S.] / 10-30 [N.S.]` 至 `10-22 [O.S.] / 11-04 [N.S.]`）：派“催货员”（*толкачи*）找煤找铁、清查财务订单、抵制资方关厂与投机，推动工人监督从“被动防御”演变为“主动干预”，并在十月起义前夕倒向“全部政权归苏维埃”。
- **《工人监督条例》、VSNKh 创立与“自下而上的国有化”（`1917-10` 至 `1918-02`）**：`1917-10-26 [O.S.] / 11-08 [N.S.]` 至 `10-27 [O.S.] / 11-09 [N.S.]` CCFC 主动提议设立全国经济调控机关（促成 `1917-12-01 [O.S.] / 12-14 [N.S.]` 成立**最高国民经济委员会 VSNKh**）；`1917-11-14 [O.S.] / 11-27 [N.S.]` 公布列宁亲自起草的《工人监督条例》（第五届彼得格勒代表会议仅1票反对通过），随后在“激进 CCFC 细则”（`12-07 [O.S.] / 12-20 [N.S.]`）与“温和全俄工人监督理事会细则”之间展开实施路线拉锯。因雇主关厂与劳资冲突，1917年11月至1918年6月全俄有案可查的836份企业没收/接管令中约 **77%** 出自地方苏维埃、工会与工厂委员会基层（1917年11月至1918年3月由中央人民委员会与 VSNKh 直接颁布者仅占约 **5.8%**）。
- **并入工会、劳动纪律危机与向集中管理退却（`1918-01` 至 `1918-06`）**：`1918-01-07 [O.S.] / 01-20 [N.S.]` 至 `01-14 [O.S.] / 01-27 [N.S.]` 第一次全俄工会大会宣布工会转向“组织生产”并呼吁工厂委员会并入工会基层；第六届（末届）彼得格勒代表会议（`1918-01-22 [O.S.] / 02-04 [N.S.]` 至 `01-27 [O.S.] / 02-09 [N.S.]`）迫于大势接受合并但坚持保留监督职能。前期彼得格勒五金工人代表理事会先以 **159 票对 59 票** 批准改组让步方案（Smith 英文版 `p. 222` 记为2月1日，处改历过渡期，原历制待核），随后于 **`1918-04-01`** 完成五金工会与工厂委员会机构的最终合并（CCFC 亦于1918年2月并入北部区国民经济委员会）。随着1918年春军工复员、日面包配给跌至50克、大批工人离城及布尔什维克车间骨干流失，列宁自3月起大力倡导“一长制”，政府于 `1918-06-28` 颁布大工业全面国有化法令。
