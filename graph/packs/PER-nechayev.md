## [T1] 60秒定性微摘要
19世纪60年代末俄国极端密谋革命家、“涅恰耶夫主义”（*нечаевщина*）代名词。出身纺织中心伊万诺沃平民家庭，1868–1869年介入圣彼得堡学潮；1869年赴日内瓦结识巴枯宁并携回《革命者教义问答》（*Катехизис революционера*），返莫斯科组建“人民惩治社”（*Народная расправа*），于 `1869-11-21 [O.S.] / 1869-12-03 [N.S.]` 伙同社员谋杀异议学生伊万诺夫。1871年其追随者公开受审，反向激发柴可夫斯基小组的伦理自净与“到民间去”运动；1872年自瑞士引渡回俄，遭亚历山大二世法外敕令终身秘密幽禁，1882年死于彼得保罗要塞。

### 2.1 核心历史脉络
- **伊万诺沃底层出身与圣彼得堡学潮激进化（1847–1869初）**：`1847-09-20 [O.S.] / 1847-10-02 [N.S.]` 生于弗拉基米尔省纺织工业重镇伊万诺沃，父为描金匠兼杂役，母系农奴出身。9岁入工厂当信差，靠自学于1866年春赴圣彼得堡任教员，深受 `1866-04-04 [O.S.] / 1866-04-16 [N.S.]` 卡拉科佐夫行刺案震撼。1868年秋成为圣彼得堡大学旁听生，在1868–1869年彼得堡学潮中结交拉利（Z. K. Ralli）及特卡乔夫，研读邦纳罗蒂《为平等而密谋》，合拟《革命行动纲领》。涅恰耶夫断定农奴制改革九周年期满日（`1870-02-19 [O.S.] / 1870-03-03 [N.S.]`）必爆发全俄农民总起义，主张将学生抗议转化为地下密谋核心，但遭到那坦松、涅格列斯库尔等主张长期社会研究与宣传的青年强烈抵制（Venturi 1960，`pp. 356–363`）。
- **日内瓦结识巴枯宁与《革命者教义问答》（1869春–夏）**：`1869-03-04 [O.S.] / 1869-03-16 [N.S.]`（离境俄历）越境赴瑞士，捏造“自彼得保罗要塞越狱”及“全俄革命委员会代表”身份。`1869-04 [N.S.]` 在日内瓦赢得巴枯宁与奥加辽夫狂热推崇（巴枯宁于 `1869-04-13 [N.S.]` 致吉约姆信中盛赞其为无畏“青年狂热者”，并向其颁发虚构“世界革命同盟”俄国支部第2771号委任状）。二人在日内瓦合作编印密码拉丁字母小册《革命者教义问答》（*Катехизис революционера*，具体执笔分工历有争论，文图里考证巴枯宁赋予其冷酷凝练的表述形式，涅恰耶夫注入伊舒金“地狱”组式的马基雅维利操控术）及《人民惩治》第1期（`1869年夏 [N.S.]`），宣称革命者是断绝一切世俗情感与道德的“注定毁灭之人”，一切促进革命胜利的手段皆合乎道德，并主张联合俄国“强盗世界”摧毁国家秩序（Venturi 1960，`pp. 363–373`）。
- **莫斯科“人民惩治社”与伊万诺夫谋杀案（1869秋–1870）**：1869年8月底至9月初经罗马尼亚潜返莫斯科，以乌斯宾斯基（P. G. Uspensky）、民俗学者普里若夫（I. G. Pryzhov）、库兹涅佐夫、尼古拉耶夫等为骨干建立按“五人小组”层级运作的秘密组织“人民惩治社”（*Народная расправа*，印章饰斧头并铭刻1870年2月19日），渗入彼得罗夫农学院。因农学院学生社员伊万·伊万诺维奇·伊万诺夫（I. I. Ivanov）质疑其虚构“中央委员会”指令，涅恰耶夫以防告密为由，于 `1869-11-21 [O.S.] / 1869-12-03 [N.S.]` 晚以挖取卡拉科佐夫案遗留印刷机为饵，诱骗伊万诺夫至农学院花园洞穴，伙同乌斯宾斯基之外的库兹涅佐夫、普里若夫、尼古拉耶夫将其殴打扼毙并枪击沉尸池塘（Venturi 1960，`pp. 374–380`）。案发后全俄逾百名青年受牵连被捕，涅恰耶夫于12月中旬潜逃西欧；`1870-04-02 [N.S.]` 至 `1870-05-09 [N.S.]` 在日内瓦短暂接办新《钟声》6期，旋因讹诈、窃取手稿及凶案真相曝光，于 `1870年中 [N.S.]` 遭巴枯宁痛斥决裂，并在伦敦刊印《公社》（*Община*）转向原始强制共产主义（Venturi 1960，`pp. 381–386`）。
- **1871年公开审判的道德反拨、1872年引渡与要塞终局（1871–1882）**：1871年夏秋（`1871-07-01 [O.S.] / 1871-07-13 [N.S.]` 起），沙皇当局在圣彼得堡审判院公开审理“涅恰耶夫派案”（八十七人案）并全文披露《革命者教义问答》，企图借此败坏整个青年运动声誉；此举反而促成那坦松、柴可夫斯基等组建的“柴可夫斯基小组”彻底唾弃欺骗同志与精英密谋的“涅恰耶夫主义”，确立以个人良知、同志互信与深入民众宣传为基石的1870年代民粹派主流风格（Venturi 1960，`pp. 389, 469–472`）。`1872-08-14 [N.S.]` 涅恰耶夫在苏黎世遭沙俄密探出卖被瑞士警方逮捕，以普通杀人犯名义引渡回俄，`1872-10-19 [O.S.] / 1872-10-31 [N.S.]` 押入彼得保罗要塞；`1873-01-08 [O.S.] / 1873-01-20 [N.S.]` 莫斯科地方法院判处其20年苦役，但亚历山大二世阅毕其 `1873-01-25 [O.S.] / 1873-02-06 [N.S.]` “公民死刑”现场高呼反沙皇口号的报告后，亲批将其“永远监禁于要塞”，自 `1873-01-29 [O.S.] / 1873-02-10 [N.S.]` 起秘密单独囚禁于彼得保罗要塞阿列克谢耶夫半月堡5号囚室。他在绝境中策反数十名要塞卫兵，于1879–1881年间与民意党执行委员会建立密信联络，主动要求推迟营救自身以优先行刺亚历山大二世；1881年底越狱计划败露（69名士兵被捕），待遇急剧恶化，于 `1882-11-21 [O.S.] / 1882-12-03 [N.S.]` 因坏血病死于狱中（Venturi 1960，`pp. 386–388`）。

### 2.3 史学争鸣光谱
- **经验事实**：涅恰耶夫参与1868–1869年彼得堡学潮、1869年携《革命者教义问答》返俄组建“人民惩治社”、`1869-11-21 [O.S.] / 1869-12-03 [N.S.]` 主导杀害学生伊万诺夫、1870年与巴枯宁决裂及1872–1882年囚死彼得保罗要塞，均有审讯卷宗、往来书信与要塞档案交叉印证；陀思妥耶夫斯基长篇小说《群魔》（*Бесы*，1871–1872）以该案为原型塑造彼得·韦尔霍文斯基，但文学夸张不可替代历史实证。
- **主要解释分歧**（详参 `DEB-1879-narodnaya-volya-to-bolshevism`、`DEB-1903-bolshevik-menshevik-split`）：
  - **[冷战“列宁主义鼻祖论”与极权主义谱系]**（以普劳丁 Michael Prawdin、庞珀 Philip Pomper、派普斯 Richard Pipes、贝桑松 Alain Besançon 等西方论者及1903年后孟什维克论战话语为代表）：这些研究者与论敌将《革命者教义问答》的“唯革命功利道德观”、层级密谋铁律与工具化同志手段视为俄国本土极权先锋队的源头，并结合苏联早期邦奇-布鲁耶维奇（V. D. Bonch-Bruevich）追记列宁私下肯定涅恰耶夫组织才干与传单通俗性的孤证，主张“涅恰耶夫—特卡乔夫—列宁”构成一脉相承的本土职业革命家谱系。
  - **[文图里运动史与民粹派主流唾弃论 / Franco Venturi]**（Venturi 1960，`pp. 359–360, 385–386, 389, 469–472`）：文图里通过档案重建证明，涅恰耶夫并非民粹主义正统代表，恰恰相反，他在1869年学潮中即遭彼得堡进步青年抵制，巴枯宁本人在目睹其“肉体施暴、灵魂施骗”的“耶稣会制度”后深感震惊厌恶并与之决裂；1871年公开审判更引起整代青年的道德义愤，直接催生柴可夫斯基小组以个人良知、“对人民负债”伦理与同志绝对互信彻底清算“涅恰耶夫主义”，奠定了1870年代“到民间去”运动的反马基雅维利基调。伯林（Isaiah Berlin）在导论中同样强调古典民粹派坚持道德人文主义，绝不认同为目的不择手段（`CLM-berlin-1960-populism-moral-core`）。
  - **[第一国际与早期马克思主义的正统排斥 / 马克思、恩格斯与解放劳动社]**：马克思与恩格斯在1872年海牙代表大会及1873年报告《社会主义民主同盟和国际工人协会》中公开揭露涅恰耶夫案件，痛斥《人民惩治》第2期描绘的强制社会蓝图为“兵营共产主义”（*казарменный коммунизм*）；普列汉诺夫、查苏利奇、阿克雪里罗德创立俄国马克思主义传统时，亦始终把“涅恰耶夫主义”当作脱离工人阶级自觉运动的反面警戒。
  - **[梅耶概念史解构 / Robert Mayer]**（`CLM-mayer-1999-lenin-jacobin-metaphor-vs-blanquism`，`pp. 132–133, 145–146, 149 n.26`）：梅耶考证，涅恰耶夫本人著作中从未自称“雅各宾派”，巴枯宁决裂后亦未称其为雅各宾派；所谓“俄国雅各宾主义/涅恰耶夫主义”是论敌事后发明的污名标签。1903–1905年俄国社会民主工党分裂时，孟什维克用“雅各宾主义”暗指“布朗基主义或涅恰耶夫主义”以攻击列宁，而列宁自诩“雅各宾派”实则承袭普列汉诺夫1901年借自法国大革命“山岳派对抗吉伦特派”的正统马克思主义阶级斗争隐喻，不能据此倒推出布尔什维克在思想渊源上认祖涅恰耶夫。

### `DEB-1903-bolshevik-menshevik-split`：《怎么办？》与1903年布尔什维克—孟什维克分裂实质之争
## [T1] 核心问题定义
《怎么办？》中的组织与意识理论是否预示了列宁式精英统治，1903年党内分裂是否由此必然产生？争论涉及文本语境、代表大会的具体冲突与后来派别政治的连续性，不能把它们当成同一个问题。
