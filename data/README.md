# 社会经济与政治定量微序列库（`data/`）

本目录用于存放支撑或检验史学论断的定量时间序列（Markdown 表格或 CSV/JSON，必须附精确出处与统计口径说明），例如：
- 1905–1917 彼得堡/彼得格勒罢工人次、实际工资与面包配给量变化；
- 1917年11月全俄立宪会议选举各党派分省/分军区得票统计（Oliver Radkey / 普罗塔索夫修正数据）；
- 1922–1924 工农业产品价格“剪刀差”月度指数；
- 1926–1929 国家粮食收购量、市场粮价与苏联官方“涅姆奇诺夫表”争议对比数据；
- 1917–1929 俄共（布）/联共（布）党员数量、阶级出身与中央委员会构成变化。
