# 俄国革命知识库：核心架构与社会科学方法论设计

本文档详细阐述本工作区针对俄国革命史（1860s 早期民粹派 — 1929 斯大林击败布哈林）所定制的四项核心架构设计：**多尺度双历法时间线**、**反 N+1 上下文偏斜知识图谱**、**史学争鸣与论断溯源层**，以及**延迟向量化路线图**。

---

## 一、四级可缩放双历法时间线架构（Multi-Scale Dual-Calendar Timeline）

### 1.1 核心痛点
1. **粒度鸿沟**：跨度近七十年（1861–1929），平时按年/月推进（如 1870年代民粹派秘密小组演化、1922–1925 新经济政策恢复期），但在革命风暴眼（1905年1月、1917年2月23–28日、1917年10月24–26日、1921年3月、1929年4月中央全会）需要精确到**逐日乃至逐小时**。单文件无法兼顾鸟瞰与显微。
2. **历法陷阱**：苏俄于 1918 年 2 月改用公历（俄历 1918-01-31 次日直接变为公历 1918-02-14）。在此之前，**19世纪俄历慢 12 天，20世纪俄历慢 13 天**；且流亡西欧的革命者书信多用公历，俄国本土档案多用俄历，极易造成因果倒置。

### 1.2 解决方案：底层原子台账 + 四级视图（L0–L3）
- **单一排序事实源 `timeline/events_ledger.jsonl`**：
  每行一条结构化事件记录，强制以公历 `date_ns` 为排序主键，并保留 `date_os`（改历前必填）、`precision`（`decade|year|season|month|day|hour`）及 `level`（`0|1|2|3`）。
- **四级缩放叙事层**：
  - **L0 全景历史分期（`timeline/L0_macro_epochs.md`）**：10 个宏观阶段，提炼结构性矛盾、核心行动者阵营与关键分岔口。
  - **L1 骨干大事记（`timeline/L1_milestones/`）**：全周期 150–300 个决定性转折点，供全局快速定位。
  - **L2 时期与月度脉络（`timeline/L2_chronicles/`）**：按年度/专题展开政治、经济、工农运动与党内路线演化。
  - **L3 逐日/逐时显微镜卷（`timeline/L3_daily/`）**：专门承载高密度危机时刻的按日/按小时演进，记录电报往来、街头态势、兵营倒戈与政治局表决。

## 二、破解“N+1 结构”与防上下文信息偏斜机制（Anti-Skew Graph Design）

### 2.1 什么是知识库中的“N+1 偏斜”？
在传统双链笔记（如裸 `[[链接]]`）中，当 Agent 读取 1 张中心卡（如 `PER-bukharin`）时，面临 N（如 30+）个关联节点：
- **欠读取偏斜（Selection Skew）**：Agent 随机点开其中 2–3 张邻居卡（如只点了斯大林和新经济政策），其余 28 条关键历史关系（如 1918 年布哈林作为“左翼共产主义者”反对列宁布列斯特和约、与普列奥布拉任斯基从合著战友变为工业化论战对手、与加米涅夫 1928 年7月秘密谈话）彻底从当前上下文中消失。
- **过读取与体量偏斜（Verbosity & Coverage Skew）**：若把 N 张邻居全卡塞入上下文，已经写了 1000 行的成熟人物卡会彻底淹没只有 30 行的关键制度卡，导致大卡话语权无限膨胀。
- **流派先入为主偏斜（Historiographical Skew）**：先入库哪本专著，卡片就被哪派叙事定调。

### 2.2 四重工程解法
1. **卡片内部三层定长协议（`[T1] / [T2] / [T3]`）**：
   - `[T1] 60秒定性微摘要（≤150字）`：纯事实坐标与身份边界，专供邻居抽取。
   - `[T2] 核心脉络 + 时效关系摘要边表 + 史学争鸣光谱槽`：只读本卡 `[T2]` 即可掌握其与所有一跳邻居在**具体年份区间**内的关系实质，无需盲开 N 个文件！
   - `[T3] 深度考证与原文引证库`：仅在专门深挖该对象时按需读取。
2. **时效有向边账本（`graph/edges.jsonl`）**：
   在俄国革命史中，“盟友/政敌”高度依赖时间窗口（如季诺维也夫与斯大林：1923–1924 结成三驾马车 → 1925 分裂 → 1926–1927 联合反对派决裂 → 1928 屈服复归）。因此每条边强制包含 `period`（有效时段）与 `digest`（一句话关系实质）。
3. **认知完备度与视角仪表盘（Epistemic Frontmatter）**：
   每张卡片头部显式声明 `coverage_status` 以及 `perspectives_present` / `perspectives_missing`。Agent 读取时立即获知当前卡片缺失哪些学派视角，从元认知上阻断盲信。
4. **1-Hop 平衡上下文包编译器（`python scripts/kb.py pack <ID>`）**：
   一键将“1 张主卡（T1+T2）+ 全部 N 张邻居的等权重微摘要（仅 T1 + 边摘要）+ 关联争鸣卡 + 时间线切片 + 偏斜告警”编译为单文件简报（`graph/packs/<ID>.md`），把失控的 `1 + N` 次随机读取转化为 **1 次等权重全景读取**。

## 三、史学史论断、一手/二手分野与拓展维度

1. **三层史学结构（`historiography/`）**：
   - `scholars/`：学者学术背景、档案基础与方法论特征。
   - `debates/`：**史学公案/争鸣母题卡（`DEB-*`）**——将同一历史问题下正统派、托派、自由/极权主义学派、社会史修正派、新制度/地缘学派、后苏联档案派的核心分歧并置在同一张地图上。
   - `claims/`：**原子论断卡（`CLM-*`）**——记录单条具体论断、推理证据链、一字不差的原文引文及精确页码 `[p. xx]`。
2. **亲历者双重身份标注**：
   托洛茨基、苏汉诺夫、米留科夫、克伦斯基、切尔诺夫、布哈林、斯大林等人的文本，在引用其当时电报/演说或现场目击细节时归为 `S/B级在场史料`，在引用其对革命因果规律的宏观解释时归为 `当事人史学论断`，严禁不加批判地照搬。
3. **三大高价值拓展模块**：
   - **概念系谱卡（`cards/concepts/CON-*`）**：专门追踪核心社会科学概念（如“民粹主义”“人民”“工农结合 Смычка”“国家资本主义”“富农”“党内民主”“一国建成社会主义”）在 1860s–1929 不同历史节点与不同派别口中的词义漂移。
   - **关键会议与派别投票卡（`cards/meetings/MTG-*`）**：以代表大会、代表会议、中央全会为经纬，记录决议草案、各派政纲与表决结构。
   - **定量微序列库（`data/`）**：沉淀罢工人次、实际工资、立宪会议选票、粮食收购月度数据、工农剪刀差指数、党员社会成分等硬指标（保留不同学者的口径对比）。

## 四、关于向量化工具的审慎路线图（Deferred Vectorization Policy）

### 4.1 为什么初期坚决不引入向量检索（Dense Embeddings / Naive RAG）？
社会科学与历史文献具有四个令常规语义向量失效的特征：
1. **历时概念漂移（Diachronic Drift）**：1905 年的“苏维埃”、1917 年春的“苏维埃”与 1928 年的“苏维埃”词面完全相同，政治实质截然不同，余弦相似度会将其混为一谈。
2. **论战引述反噬（Polemical Inversion）**：俄国革命文献充斥着大段摘引政敌原话再加以痛斥或反讽的写法。切片向量检索极易把“被批判的靶子”当作作者本人的论断召回。
3. **秘密化名与历法盲区**：地下时期的化名、缩写与俄历/公历混排，必须靠受控词表（`graph/aliases.yaml`）与精确换算解决，模糊语义向量反而制造张冠李戴。
4. **马太效应偏斜**：Top-K 向量召回天然偏爱修辞流畅的二手通史总结，压制枯燥但决定性的统计表、法令条文与速记原件。

### 4.2 未来考虑引入的触发阈值与严苛护栏
仅当工作区满足以下全部条件时，编排者才会向用户提议引入混合检索索引：
- **体量阈值**：`sources/` 入库原文突破 **30 本以上专著/档案集（或 >3,000 万字）**，仅靠目录树与图谱已难以跨书发现隐蔽关联；
- **定位护栏（严禁 Chunk-RAG 直接喂给生成端）**：即便届时引入向量或 BM25 混合索引，也**只允许作为“候选章节雷达（Chapter Locator）”**——索引只负责返回“哪本书哪一章可能讨论了该问题”，随后依然必须指派 `close-reader` 调取该章完整上下文连续顺读！
