# 1912年勒拿金矿惨案与战前工运高涨

## [T1] 60秒定性微摘要
`1912-04-04 [O.S.] / 04-17 [N.S.]` 博代博勒拿金矿宪兵向和平请愿矿工排枪齐射，死伤数百。`1912-04-11 [O.S.] / 1912-04-24 [N.S.]` 马卡罗夫杜马狂言“过去如此，今后亦如此”引爆全俄罢工，《真理报》 `1912-04-22 [O.S.] / 1912-05-05 [N.S.]` 创刊与五一工潮开启战前城市“双重极化”。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络（严守1912年闰2月后俄历 `+13` 天换算）
- **阶段一：博代博和平经济罢工与4月4日排枪屠杀（1912.02.29–04.04 [O.S.] / 03.13–04.17 [N.S.]）**：`1912-02-29 [O.S.] / 1912-03-13 [N.S.]` 勒拿金矿公司（Lenzoto）因公司商店强制配发腐肉引发自发罢工，至3月9日蔓延至全区近7,000名矿工，提出八小时工作制、废除罚款、撤换26名监工及第16条“礼貌称呼（*vezhlivoe obrashchenie*）”等18项要求。尽管地方视察官图尔钦斯基与伊尔库茨克省长班特什证实矿工“零酗酒零破坏”并力阻动武，公司彼得堡董事会仍借内政与工商业大臣越级电令宪兵队长特列先科于 `1912-04-04 [O.S.] / 1912-04-17 [N.S.]` 凌晨逮捕约10名罢工委员会领袖。`04-04 [O.S.] / 04-17 [N.S.]` `17:30`，约3,000名手无寸铁的请愿矿工行进至纳杰日金斯基管理处时遭官兵射击；Haimson所述官方报告称兵力约380人，Kotkin叙述约90人为开枪士兵，两者统计对象不同（军方零伤亡），死伤多口径统计并存（PTA初报107死83伤、马卡罗夫认163死、参议员马努欣调查团170死372伤、部分苏联史学通行270死250伤（所据报纸期号与原件待核））。
- **阶段二：马卡罗夫杜马挑衅与资本/工人阶级“分流”抗议（1912.04.06–04.18 [O.S.] / 04.19–05.01 [N.S.]）**：`1912-04-06 [O.S.] / 1912-04-19 [N.S.]` 彼得堡报刊首次披露惨案；`04-11 [O.S.] / 04-24 [N.S.]` 第三届国家杜马质询辩论中，内务大臣亚·亚·马卡罗夫竟公开宣称“**过去如此，今后也将如此（Так было, так и будет впредь!）**”，立遭社民党工人代表库兹涅佐夫反唇相讥并引爆全俄愤慨。`04-15 [O.S.] / 04-28 [N.S.]`，喀山大教堂千名学生示威与维堡工人独自在旗帜广场集会形成“两路分流”；次日（`1912-04-16 [O.S.] / 1912-04-29 [N.S.]`）彼得堡冶金厂（4,000人）与罗森克兰茨厂在本厂“觉悟工人”带领下率先停工，至 `04-18 [O.S.] / 05-01 [N.S.]` 首都罢工者已破 **10万人**（Haimson估计4月全俄同情罢工约20万–21.5万人次，地域和人次口径不可与独立人数直接等同）。
- **阶段三：《真理报》创刊与“五一”全俄工潮复活（1912.04.22–05.01 [O.S.] / 05.05–05.14 [N.S.]）**：`04-22 [O.S.] / 05-05 [N.S.]`《星报》同日被查封，布尔什维克合法工人日报**《真理报》（*Pravda*）**在彼得堡创刊接力（莫洛托夫任秘书、斯大林执笔社论，峰值发行4万–6万份）；`1912-04-23–25 [O.S.] / 1912-05-06–08 [N.S.]` 莫斯科跟进三天抗议罢工；`05-01 [O.S.] / 05-14 [N.S.]` 全俄爆发数十万政治大罢工（海姆森保守估25万–30万人，苏联口径约40万人），首都工人高唱《马赛曲》《华沙革命歌》列队护厂游行却坚守工业区边界不入市中心——1907年“六三政变”以来的沉寂宣告终结。

### 2.3 史学争鸣光谱（Historiographical Spectrum）
- **经验共识**：`1912-04-04 [O.S.] / 1912-04-17 [N.S.]`博代博屠杀、`1912-04-11 [O.S.] / 1912-04-24 [N.S.]`马卡罗夫杜马发言、《真理报》`1912-04-22 [O.S.] / 1912-05-05 [N.S.]`创刊以及`1912-05-01 [O.S.] / 1912-05-14 [N.S.]`五一罢工构成连续震荡；Haimson估计4月全俄同情罢工约20万余人次，一举扭转了1907–1911年工运低潮。
- **主要解释分歧**（详参 `DEB-1914-haimson-thesis-stability`）：
  - **“双重极化”与人格尊严危机论（Leopold H. Haimson, 1964/2005）**：海姆森在《1905–1917年城市俄国的社会稳定问题》及2005年专著第9–13章指出，勒拿惨案揭示的不仅是“劳工 vs 专制/雇主”冲突，更是**“城市激进工人 vs 有产/自由派社会”**之间的深刻决裂（如4月15日维堡工人拒入喀山广场、5月1日拒过涅瓦桥）；工人对“以您相称”等基本人格尊严（*lichnost'*）的诉求在沙皇家长制体制下自动转化为爆炸性政治对抗，证明1912–1914年危机并非大战强加的外源事故。
  - **工人—知识分子反监护与自主接管论（Reginald E. Zelnik / Steve A. Smith, 1996/1999）**：解答“何以地下党残破且无外来煽动仍能瞬间动员十万大军”——经过1907–1910年知识分子大规模脱党造成“精神孤儿化”之后，金属与印刷业“觉悟工人（worker-intelligentsia）”已借助合法俱乐部、工会与工人报刊网络独立主持罢工大会，并在1912–1914年间实质接管彼得堡党委（至1913年PK 36名委员中工人占24人）（参见 `CLM-zelnik-1999-worker-intelligentsia-tutelage-tension`）。
  - **非宗派《真理报》与“意外共识”修正（Eric Blanc, 2021 / Michael Melancon, 2006）**：布朗对照20世纪20–30年代党史教科书指出，1912年4月刚创刊的《真理报》并不排斥与党性孟什维克携手高喊“不惜一切代价团结”，直到8月右翼孟什维克另立妥协派《光线报》（*Luch*）后，《真理报》方凭借在厂矿日常对抗中的不妥协阶级立场赢得多数工人支持（参见 `CLM-blanc-2021-revolutionary-kautskyanism-in-empire`；`blanc_2021_rev_sd/ch13`）。梅兰孔亦补充指出，1912年4月谴责勒拿暴行曾罕见形成涵盖保守派、自由派、社革党与社民党的“意外共识”，不可将四月怒潮简约为布尔什维克单一政党动员。
  - **经济现代化与反事实慎思（Gerschenkron / Pipes）**：自由派与经济史学者（参 `DEB-1914-haimson-thesis-stability`）提醒，1912–1914年工业强劲增长与城市工潮并行，且城市罢工材料不能直接等同农村与边疆稳定度，若无1914年世界大战冲击，仅凭勒拿后工潮是否必然导致革命仍有争论。

据Haimson转述，马卡罗夫以军队不能丢弃武器、遭人群冲击便只能开枪为枪击辩护，并称“过去如此，今后亦如此”。这是当时官方的正当化言说，不能当作已证实的现场事实（Haimson ch10，印刷pp. 141–142）。

After the failure of the May Day demonstration, a worker told an SD meeting: '...We need neither good nor bad tsars, we just want to run our own party.'" `[pp. 20–21, 27]`

3. **Blanc (2021) 论早期《真理报》“不惜一切代价维护统一”至八月分化的转变（`ch13`, `pp. 270–271` / PDF `pp. 284–285`）**：
