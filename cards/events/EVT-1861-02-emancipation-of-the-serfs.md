## [T1] 60秒定性微摘要

1861年2月19日[O.S.]/3月3日[N.S.]亚历山大二世签署废奴宣言，3月5日[O.S.]公布。改革废除农奴人身依附，却设临时义务、高额赎买与割地并保留村社连环保，引爆别兹德纳等抗争与民粹派批判，奠定帝俄晚期土地矛盾格局。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络

- **克里米亚战败危机与编辑委员会博弈（1855–1861）**：克里米亚战败暴露了农奴制军役与财政体系的深重危机；据 Orlando Figes 统计，至1859年全国约三分之一贵族庄园与三分之二农奴已被抵押给国家信贷机构（`figes_1996_peoples_tragedy/ch09_2_unstable_pillars.md`）。亚历山大二世（`PER-alexander-ii`）继位后警告莫斯科贵族“与其等待农奴自下而上自我解放，不如自上而下废除”，随后由尼古拉·米留京等“彼得堡进步派”改革官僚主持编辑委员会，在贵族委员会与国务会议保守派的反复掣肘下，对土地划分与赎买条款作出大幅向地主倾斜的妥协。
- **二一九签署与三五延迟公布（`1861-02-19 [O.S.] / 1861-03-03 [N.S.]` 至 `1861-03-05 [O.S.] / 1861-03-17 [N.S.]`）**：`1861-02-19 [O.S.] / 1861-03-03 [N.S.]`，亚历山大二世正式签署《废除农奴制宣言》与《脱离农奴依附关系农民总法令》；因担心即刻引发农村骚乱并部署驻军警备，当局延迟至两周后的 **`1861-03-05 [O.S.] / 1861-03-17 [N.S.]`** 才在全俄教堂宣读公布并举行感恩祈祷（`loginov_lenin_bio_zh/ch02_第一部_如何成为领袖.md`）。法令在法理上废除了地主对私产农奴的人身占有，赋予农民婚姻、立约、购置动产与提起诉讼等民事权利（国有农奴与皇族农奴的改造另有后续法令，不应与1861年二一九地主农奴法令直接混为一谈）。
- **临时义务农、割地（*otrezki*）、赎买金与村社连环保制度结构**：改革未无条件授予农民份地所有权，而是设定三重制约：（1）**临时义务农（временнообязанные）**：在签订“法定地契”（уставная грамота，规定两年期至 `1863-02-19 [O.S.] / 1863-03-03 [N.S.]`）与赎买协议之前，农民仍须向地主缴纳代役租或服劳役；（2）**割地（отрезки）与“乞丐份地”**：地主从原由农民耕种的土地中割去大量草场、林地与良田（Manning 指出核心农业区割地比例约达三分之一，且约百万农户选择免赎金的极小“乞丐份地”陷入无地/缺地困境，`manning_1982_crisis_old_order_zh/ch13_8_自由的日子.md`）；（3）**高额赎买与村社连环保**：国家向地主垫付约八成赎金后，由农民分49年加息6%偿还，并将份地产权与赋税连带责任（круговая порука）捆绑于法定“乡村公社”（`CON-peasant-commune-obshchina`）及调解员（мировые посредники）体制之中。连环保直至 `1903-03-12 [O.S.] / 1903-03-25 [N.S.]` 方被废除，剩余赎买金直至 `1905-11-03 [O.S.] / 1905-11-16 [N.S.]` 才在革命冲击下诏令停征。
- **别兹德纳惨案（Bezdna）与农村抗争潮（1861春）**：法令条文晦涩难懂且多处违背农民“土地归耕种者”的道德预期，引发多地农民拒交地租与传言“地主隐匿了沙皇的真正自由诏书（期待1863年2月19日两年期满后迎来彻底解放）”。`1861-04-12 [O.S.] / 1861-04-24 [N.S.]`，喀山省斯帕斯克县别兹德纳村农民在识字老农安东·彼得罗夫宣讲“真正自由”的号召下聚集抗命，遭到奉命镇压的阿普拉克辛少将部队开枪驱散，官方报告称51人死亡、77人受伤（民间估计更高）；`1861-04-19 [O.S.] / 1861-05-01 [N.S.]` 彼得罗夫遭就地枪决（Venturi `ch08_pages_241-270.md`）。`1861-04-16 [O.S.] / 1861-04-28 [N.S.]`，喀山大学生与神学院士卒为别兹德纳死者举行追思祈祷，历史学者阿·普·夏波夫公开演说呼吁民主与地方自治，成为知识分子与农民反抗合流的关键象征。Venturi 转引 Ignatovich 统计指出，1861年仅正式动用军队或引发流血的较大规模农民抗争即达数百起，随后在1862–1863年逐渐转入围绕“法定地契”签字与等待1863年期满的抵制。
- **赫尔岑、车尔尼雪夫斯基与早期民粹派的诞生（1861–1864）**：改革的落差彻底击碎了自由派和温和民主派对“解放者沙皇”的幻想。流亡伦敦的赫尔岑（`PER-herzen`）在《钟声》（*Kolokol*）上先寄望和平改革，继而在别兹德纳惨案与波兰问题后痛斥“旧农奴制已死，新农奴制诞生”，并联合奥加廖夫提出“土地与自由”（Земля и воля）口号；国内的尼古拉·车尔尼雪夫斯基（`PER-chernyshevsky`）则在《现代人》撰文尖锐抨击赎买制度在经济上掠夺农民、在村社保存问题上早先已撰写《对关于土地公社所有制的哲学偏见的批判》（1859）并呈送致康斯坦丁大公备忘录与《土地赎买很难吗？》等文（Venturi `ch06_pages_181-210.md`）。对1861年改革的普遍幻灭直接催生了1861–1864年第一代秘密组织“土地与自由社”（`ORG-zemlya-i-volya`）及“青年俄国”等激进传单运动，并开启了跨越至1874年“到民间去”（`EVT-1874-going-to-the-people`）与1905–1917年土地革命的长周期。

### 2.3 经验共识与史学争鸣

- **经验共识**：1861年废奴并非一次性授予农民完整自由土地的解放；“割地”、49年赎买金、临时义务期与村社连环保把传统依附转化为长期财政与土地矛盾；别兹德纳流血事件与两年过渡期期待的破灭推动了激进知识分子与专制国家的决裂；随后至1900年贵族土地大面积流失（据 Figes 统计，1861–1900年间逾四成贵族土地转售农民或流转市场）亦说明改革既未令农民满意，也未能保住传统地主经济体面。
- **运动史与革命起源派（Franco Venturi, 1960 / `RN-W2-zemlya-to-march-first`）**：将1861年改革及别兹德纳惨案置于俄国民粹主义运动的起点位置，详考赫尔岑、车尔尼雪夫斯基与1861年“大俄国人”“青年俄国”等地下团体的联动，强调知识分子并非凭空制造乌托邦，而是对农奴制废除之“欺骗性结局”作出的道德与政治回应。
- **历史社会学农业官僚制派（Barrington Moore, 1966 / `CLM-moore-1966-agrarian-bureaucracy-and-peasant-revolution`）**：从比较现代化视角指出，俄国皇室农业官僚制既压制了独立资产阶级兴起，又在1861年后把地主剥离出地方治安与司法互惠职能，只留下寄生的赎买金索取；而被强行保留的米尔村社则把农民贫困转化为一致反地主的“激进性团结”。
- **文化悲剧与国家—社会断裂派（Orlando Figes, 1996 / Richard Pipes, 1990）**：Figes 在 `ch09` 中着重剖析改革令“自由”与“土地”脱节：农民按习惯法坚信土地归劳动者，而沙皇官僚却用法律将大部分良田保留在贵族手中；Pipes（`CLM-pipes-1990-patrimonial-state-and-intelligentsia`）则将1861年连同后续“大改革”置于帝俄家产制结构下，认为村社强化反而在法律上隔绝了农民与现代公民产权，延迟了农村现代法制发育。
- **马克思主义与士绅危机制约派（Andrzej Walicki / Roberta Manning / 列宁传统）**：列宁后来在革命史评述中将1861年定性为“农奴主对农民的第一次洗劫”，同时指出改革以极其痛苦的“普鲁士式/地主式”道路打开了俄国资本主义渗透闸门；Walicki（`CLM-walicki-1969-narodnichestvo-definition`）辨析车尔尼雪夫斯基与民粹派如何在改革现场即已敏锐洞察资本主义分化威胁；Manning（`CLM-manning-1982-gentry-fronde-to-reaction`、`ch13`）则补入改革后四十年土地贵族不断衰落并在1905年被1861年遗留的土地冲突反噬的阶级轨迹。
