## [T1] 150字定性微摘要
1914年7月德国宣战至1916年末帝俄总体战危机演化。1915年大撤退与弹药短缺催生战时工业委员会及杜马进步同盟；沙皇亲征并放任内阁“部长走马灯”，军工扩招、里季希粮食摊派受挫与恶性通胀加剧精英离心和城市工潮，将政权推向1917年二月危机门槛。

## [T2] 核心脉络、关系网络与史学争鸣

### 2.1 核心历史脉络（严守20世纪初俄历 +13 天换算）
- **宣战、“神圣同盟”与社会主义阵营分裂（1914.07–1915.04）**：`1914-07-19 [O.S.] / 1914-08-01 [N.S.]` 德国向俄国宣战，尼古拉二世次日在冬宫召开“沙皇与人民合一”的爱国集会，除布尔什维克与孟什维克杜马党团（于 `1914-07-26 [O.S.] / 1914-08-08 [N.S.]` 发表联合声明拒投战争拨款并退场）及劳动派外，第四届杜马绝大多数党团投票批准战争预算；五名布尔什维克杜马议员于1914年11月遭逮捕并于次年流放西伯利亚。第二国际护国主义浪潮下，俄国社会主义阵营撕裂为三派：以 格奥尔基·普列汉诺夫（`PER-plekhanov`）（及国内波特列索夫、格沃兹杰夫《自卫》派）为代表的护国派、以 尤利·马尔托夫（`PER-martov-l`） 与 维克托·切尔诺夫（`PER-chernov`） 为代表的反战国际主义派（于1915年9月齐美尔瓦尔德与1916年4月昆塔尔会议聚合），以及 弗拉基米尔·列宁（`PER-lenin`） 提出“变帝国主义战争为国内战争”的革命失败主义（`CON-revolutionary-defensism-and-defeatism`）。
- **1915年大撤退、“炮弹荒”与社会总动员组织（1915.04–11 [O.S.]）**：继1914年坦能堡惨败后，1915年春夏德奥联军自 `1915-04-15 [O.S.] / 1915-04-28 [N.S.]` 突破戈尔利采—塔尔努夫防线，俄军被迫放弃波兰王国、立陶宛与加利西亚（“大撤退”），前线严重炮弹与步枪短缺引发举国震怒（陆军大臣苏霍姆利诺夫于 `1915-06-11 [O.S.] / 1915-06-24 [N.S.]` 被免职）。政府被迫于5月起设立吸收杜马与社会代表的国防、运输、粮食、燃料四大特别会议（大臣保留否决权）；地方自治局联合会（主席 `PER-lvov`）与城市联合会亦于1915年夏合并组建“全俄地方自治与城市联合会总委员会（Zemgor）”。与此同时，莫斯科工商业界在 `1915-05-26`–`05-28 [O.S.] / 1915-06-08`–`06-10 [N.S.]` 第九届全俄工商业代表大会上通过里亚布申斯基提出的“动员工业”并组建战时工业委员会决议，继而在 `1915-07-25`–`07-27 [O.S.] / 1915-08-07`–`08-09 [N.S.]` 第一次全俄战时工业委员会代表大会上正式建成“中央战时工业委员会（ЦВПК）”，选举 亚历山大·古契科夫（`PER-guchkov`） 任主席、科诺瓦洛夫任副主席（长谷川毅 `ch08` L98–108 将倡议与选出主席合并叙于5月大会下，盖达 `ch04` L71–122 则分梳了5月倡议与7月一全大会选举两阶段）。据长谷川毅（`ch08` L116–119）与盖达（`ch04` L104–106）考订，中央战时工业委员会政治声势浩大但经济权重有限：**开战前两年政府机构下达给中央战时工业委员会的军需订货仅占政府军需总订货额的 3%–5%，实际履约交付比例更低**（非占帝国总军工产值 3%–5%）。在工人动员上，历经 `1915-09-27 [O.S.]` 首轮选举被布尔什维克抵制挫败后，`1915-11-29 [O.S.] / 1915-12-12 [N.S.]` 第二次选举人会议在布尔什维克与社革党代表退场抗议下，选出以孟什维克护国派金属工格沃兹杰夫（K. A. Gvozdev）为首的中央战时工业委员会“工人小组”（`hasegawa_february_1917/ch12` L500–560）。
- **沙皇亲征、杜马“进步同盟”与“部长走马灯”（1915.08–1916.12）**：军事危机顶峰之际，尼古拉二世拒绝多数大臣联名劝谏，于 `1915-08-22 [O.S.] / 1915-09-04 [N.S.]`（尼古拉二世 另以大本营发布手谕日并记 `1915-08-23 [O.S.] / 1915-09-05 [N.S.]`）罢免尼古拉·尼古拉耶维奇大公、亲自赴莫吉廖夫大本营兼任最高统帅，把首都政务交由皇后亚历山德拉与拉斯普京信任的保守派影响。同月，第四届国家杜马与国务会议中的温和自由派及中右党团——包括 立宪民主党（`ORG-kadets`）（`PER-milyukov`）、进步党、左翼十月党/地方自治十月党及进步民族主义者（注：`PER-guchkov` 因在1912年第四届杜马选举落选且十月党于1913年底后分裂，此时主要在杜马院外依托中央战时工业委员会及军政人脉活动，据 Gaida `ch04` L122–128）——于 `1915-08-25 [O.S.] / 1915-09-07 [N.S.]` 结成拥有杜马过半议席的“进步同盟”（Progressive Bloc）。据盖达（`ch05` L244–260）考辨，为避免在战时危机中直接承担执政风险并压制进步党竞争对手，米留可夫主导立宪民主党撤回了激进的**“责任内阁”**（对议会负法定责任）要求，折中提出由沙皇任命、享有社会信任的**“信任内阁”**（Ministry of Public Confidence）口号（`ORG-octobrists-and-progressive-bloc`, `CLM-gaida-2003-progressive-bloc-dilemma`），仍于 `1915-09-03 [O.S.] / 1915-09-16 [N.S.]` 遭首相戈列梅金强行休会。1915年秋至1916年末宫廷陷入高频更迭的“部长走马灯”（相继更换戈列梅金→施蒂尔默→特列波夫→戈利岑四任首相，并于1916年9月起用倒向宫廷的前杜马副主席普罗托波波夫掌管内务部）。`1916-11-01 [O.S.] / 1916-11-14 [N.S.]` 米留可夫在杜马发表“这是愚蠢，还是叛国？”演说；`1916-12-17 [O.S.] / 1916-12-30 [N.S.]` 尤苏波夫亲王、普里什凯维奇与德米特里大公刺杀拉斯普京企图“清君侧”，反使尼古拉二世与皇室宗亲及贵族社会彻底决裂。
- **战时经济失衡、中亚起义与1916年末的领域分化危机（1916）**：1916年间帝俄并非全线崩溃——随着国防工业投产，1916年炮弹与步枪产量大幅回升，`1916-05-22 [O.S.] / 1916-06-04 [N.S.]` 打响的西南方面军布鲁西洛夫攻势更重创奥匈军，前线统帅部与协约国外交尚未瓦解。然而总体战的结构代价集中在后方民生与政治合法性领域：帝俄累计征召逾1,500万兵员；首都彼得格勒因军工扩招使市内工厂工人由1914年初约24.26万人增至1917年初约39.28万人（增幅约61.9%，若含伊若拉、谢斯特罗列茨克等近郊军工大厂共达41.7万人，据 `hasegawa_february_1917/ch11` L49–55 及 `RN-W3-factory-committees-and-workers-control`）；铁路运力被军运挤压、通货膨胀导致实际工资下跌，引发首都面粉与燃料短缺。农业大臣里季希于 `1916-11-29 [O.S.] / 1916-12-12 [N.S.]` 颁行战时**粮食摊派采购制（*razverstka*）**，试图按固定价格经由省—县地方自治局向农村摊派采购配额，但因缺乏工业品交换与强制征集手段而迅速落空。帝国边疆亦在1916年夏因征召中亚及哈萨克穆斯林从事后方劳役爆发全境起义并遭血腥镇压。至1916年末，后方粮荒、首都工潮复燃与上层宫廷孤立形成高危叠加，为 `1917-01`–`02` 街头危机与驻军哗变的偶发合流埋下伏笔（`EVT-1917-02-february-revolution`）。

### 2.3 主要史学争鸣与多流派解释
- **“外源总体战打断演进”论 vs “内生双重极化重燃”论（Richard Pipes vs Leopold Haimson / Tsuyoshi Hasegawa）**：自由—保守派代表 Pipes 主张第一次世界大战这场超负荷的现代消耗战与尼古拉二世亲征的政治失策从外部打断了帝俄战前原本有望演进的轨道；Haimson、S. A. Smith 与 Hasegawa 则揭示，战前城市“双重极化”在1914年7月爱国停火后仅暂伏一年（1915年1月9日[O.S.]彼得格勒血腥星期日纪念罢工仅2,600人），随着1915年夏军事败退、伊万诺沃-沃兹涅先斯克枪杀案（`1915-08-10 [O.S.] / 1915-08-23 [N.S.]`）及首都军工人口暴涨、通胀恶化而迅速复燃——彼得格勒于1915年8月中旬爆发2.25万人抗议罢工、9月2–5日[O.S.]更爆发70厂8.27万人全市总罢工并重提选举工人代表苏维埃（据 `hasegawa_february_1917/ch11` L640–755；学界通引工厂视察官全俄年度口径常记1915年约53.9万人次、1916年约95.1万人次，惟长谷川指出工厂视察官未计入陆海军部直属兵工厂且存在重复计次，站内 `DATA-01-1905-1917-strikes-and-petrograd-elections` 亦未收录1915–1916年度总表），并在1916年秋至1917年1月把经济罢工与反体制政治示威合流推向高潮（`DEB-1914-haimson-thesis-stability`, `RN-W1C-february-insurrection-and-dual-power`）。
- **总体战国家干预“连续体”论及其制度边界（Peter Holquist / David Hoffmann）**：超越单纯追问“谁搞垮了沙皇”，现代性学派在 `CLM-hoffmann-2011-continuum-of-total-war-1914-1929`（参见 `sources/monographs/hoffmann_2011_cultivating_masses_zh/ch03_引言.md` L149–185）中指出，1914–1916年沙皇政府与半官方社会组织（特别会议、Zemgor、战时工业委员会）为应对总体战而探索的粮食国家调控、人口统计监测、书信审查与社会动员技术，构成了跨越1917年政权更迭的治理谱系。但史学界同时强调必须区分不同阶段的强制层级：1916年11月里季希推行的**粮食摊派采购制（*razverstka*）**仍属依赖地方自治局、按固定价格向各省分配采购指标的行政摊派（因无力强制而破产），1917年3月临时政府升级为国家粮食专卖，至1918–1920年苏维埃政权才演化为依靠武装征粮队与阶级专政执行的**余粮收集制（*prodrazverstka*）**——三者存在术语渊源与部分技术官僚连续性，但不可将1916年里季希摊派直接等同于后来完整的战时共产主义强制征粮体制（并参 `RN-W32-spitsyn-neo-traditionalist-synthesis-1917-1929` 对跨政权连续性疆域边界的方法论提醒）。
- **自由派反对派的“信任内阁”折中与多重自缚机制（F. A. Gaida / Tsuyoshi Hasegawa）**：Gaida（`ch05` L244–260，`RN-W8-liberal-opposition-and-bolshevik-nationality-policy`）精细拆解了1915–1916年自由派为何节节退缩——这并非单一的“害怕群众革命”，而是四重机制交织的结果：(1) 既想借社会危机逼宫，又恐惧一旦号召街头运动将引发不可控的下层无政府暴动；(2) 自由派内部（莫斯科工业家/进步党“责任内阁”派 vs 米留可夫立宪民主党“信任内阁”派 vs 古奇科夫院外军工/密谋派）激烈的领导权竞逐；(3) 立宪民主党在战局危殆之际并不愿真正接盘承担战时行政管理责任；(4) 自由派在杜马院外缺乏严密政党基层组织（`CLM-gaida-2003-progressive-bloc-dilemma`, `CLM-gaida-2003-liberals-in-february-1917`）。长谷川毅则补充指出，尽管自由派在1916年底前瞻前顾后，但在1917年2月27日起义既成事实之际，杜马临时委员会仍做出了主动接管国家权力的关键政治决断（`CLM-hasegawa-2018-duma-committee-revision`）。同时，在劳工翼侧，格沃兹杰夫领导的中央战时工业委员会“工人小组”虽试图借助合法平台协调国防生产与工人权益，却在沙皇警察猜忌（1917年1月27日[O.S.]全员被捕）与布尔什维克“阶级合作叛徒”攻击的夹击下陷入“皮洛士式惨胜”（`hasegawa_february_1917/ch12` L557–560；其1917年二月后向革命护国主义及联合政府劳工部的演变见 `RN-W5-menshevik-defensism-and-coalition`）。
- **新传统主义“上层精英阴谋”叙事与多维历史综合的对勘（叶·尤·斯皮岑 E. Yu. Spitsyn vs 长谷川毅）**：俄罗斯当代新传统主义教科书作者斯皮岑（B 级当代教辅阐释文献）反对把1914–1916年写成单纯的自发经济危机，强调以 亚历山大·古契科夫（`PER-guchkov`）、Zemgor 领导层与部分高级将领为代表的军工资产阶级和自由派自1915–1916年起便酝酿宫廷政变以逼迫尼古拉二世退位（`CLM-spitsyn-february-1917-elite-conspiracy-thesis`）。学术综合视角（如长谷川毅 `ch10` 及盖达）肯定古奇科夫小组与吕沃夫/克伦斯基圈子在1916年底至1917年初确曾筹议逼宫方案，但实证表明这些密谋因内部不合与行动迟缓，在1917年2月23日下层女工、金属工与随后卫戍部队自发哗变爆发前从未付诸实施，故不可将二月革命简化为单一上层阴谋。
