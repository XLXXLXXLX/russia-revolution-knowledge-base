# 1917年科尔尼洛夫事件

## [T1] 60秒定性微摘要
`1917-08-24 [O.S.] / 09-06 [N.S.]` 至 `08-31 / 09-13` 克伦斯基与科尔尼洛夫在萨文科夫调兵、李沃夫传话及 `08-26` 电报对质后决裂。克雷莫夫第3骑兵军遭铁路拆轨、重装赤卫队与穆斯林代表瓦解；`1917-08-31 [O.S.] / 1917-09-13 [N.S.]`夜彼得格勒苏维埃通过布尔什维克政权决议；主席团改选发生在后续阶段。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络（严守1917年俄历 `+13` 天换算）
- **阶段一：萨文科夫协商、李沃夫穿梭与8月26日休斯电报对质（1917.08.23–08.26 [O.S.] / 09.05–09.08 [N.S.]）**：8月中旬里加失陷后，俄军最高统帅科尔尼洛夫（Stavka，莫吉廖夫）借莫斯科国务会议蓄势，在军事政治与强硬右翼工商界中赢得“救国强人”声望。`08-23–24 [O.S.] / 09-05–06 [N.S.]`，受克伦斯基委派的代理陆军部长萨文科夫赴莫吉廖夫与科尔尼洛夫商妥调集第3骑兵军（不含“野蛮师”与克雷莫夫将军，此系政府预期布尔什维克在半年纪念日暴动之戒严备手）。`1917-08-25–26 [O.S.] / 1917-09-07–08 [N.S.]`，前圣院总监弗·尼·李沃夫擅自充当双边传话人向克伦斯基带回“科尔尼洛夫要求交出全权、宣布首都戒严并设军事独裁内阁”的三点最后通牒；`08-26 [O.S.] / 09-08 [N.S.]` 晚 `20:30–21:30`，克伦斯基在冬宫电报室用**休斯印字电报机（Hughes teleprinter）**以自己和“李沃夫”名义直接向科尔尼洛夫套话确认（科尔尼洛夫电复确认李沃夫曾面谈，并请克伦斯基与萨文科夫 `1917-08-28 [O.S.] / 1917-09-10 [N.S.]` 亲赴大本营），克伦斯基遂认定政变确凿。
- **阶段二：免职令、立宪民主党辞职与苏维埃工人武装反击（1917.08.27–08.29 [O.S.] / 09.09–09.11 [N.S.]）**：`08-27 [O.S.] / 09-09 [N.S.]` 清晨克伦斯基发令免去科尔尼洛夫最高统帅职，立宪民主党部长相继辞职使内阁陷于瘫痪；科尔尼洛夫震怒发布《告全俄人民书》公开抗命，命克雷莫夫率第3骑兵军（含高加索“野蛮师”）急进首都。`08-28 [O.S.] / 09-10 [N.S.]`，工兵与农民全俄中执委及彼得格勒苏维埃联合三大社会主义党派（重新接纳七月后遭通缉的布尔什维克代表）成立**“反革命斗争人民委员会”**，全国各地旋即涌现逾240个同类地方委员会：全俄铁路工会执委会（**维克热尔 Vikzhel**）拆毁卢加、维里察铁轨并截断信号，工厂工人赤卫队由政府军火库与地下隐匿步枪迅速重装起约 **13,000–15,000人（乃至逾20,000人）**，喀琅施塔得3,000名水兵急驰保卫首都。`08-29 [O.S.] / 09-11 [N.S.]`，彼得格勒工人与特别派出的**高加索穆斯林代表团**（含沙米尔之孙与穆斯林苏维埃代表）深入停滞的军列说服“野蛮师”官兵，克雷莫夫部队未放一枪即告解体。
- **阶段三：克雷莫夫自戕、科尔尼洛夫被捕与彼得格勒苏维埃多数易主（1917.08.30–09.01 [O.S.] / 09.12–09.14 [N.S.]）**：`08-30 [O.S.] / 09-12 [N.S.]`，莫吉廖夫大本营孤立，克伦斯基自任最高统帅并召阿列克谢耶夫任总参谋长收拾残局；同日列宁自芬兰致信中央要求“在打击科尔尼洛夫的同时决不支持克伦斯基”。`08-31 [O.S.] / 09-13 [N.S.]` 日间，克雷莫夫赴冬宫对质后开枪自杀；**当晚至 `1917-09-01 [O.S.] / 1917-09-14 [N.S.]` 凌晨约 `05:00`**，彼得格勒苏维埃全体大会就加米涅夫代表布尔什维克党团提出的《关于政权》决议展开通宵激辩，在护国派执委（齐赫伊泽、策烈铁里、丹）以集体辞职相挟之下，大会最终以 **279 票赞成、115 票反对、51 票弃权**（另见加利利所记点名后温和派调回 **135 票** 异文）**历史上首次通过布尔什维克政权决议**！`09-01 [O.S.] / 09-14 [N.S.]`，阿列克谢耶夫在莫吉廖夫正式拘押科尔尼洛夫，克伦斯基单方面宣布“俄罗斯共和国”与五人督政府，而孟什维克撇开立宪民主党组建“清一色民主政府”的企图宣告破产。

### 2.3 史学争鸣光谱（Historiographical Spectrum）：四方核心对勘
- **经验共识**：萨文科夫8月23–24日曾奉命去莫吉廖夫协调整兵进京；8月26日晚克伦斯基与科尔尼洛夫有过一段充满误导性的休斯电报机对话；第3骑兵军进至卢加等地后未经大战即告瓦解，同时彼得格勒工厂工人借平叛重新大批持枪并在8月31日夜使布尔什维克政权决议获得多数；这不等于当夜已完成主席团改选或稳定席次多数。
- **四方核心解释分歧**（详参 `DEB-1917-october-coup-or-social-revolution`）：
  1. **社会史修正派（Alexander Rabinowitch, 1976）**：确认**大本营与右翼确实存在实打实的军事改组与集权预谋**（第3骑兵军自8月初即提前向大卢基/普斯科夫调近，莫吉廖夫串联首都地下军官团），而克伦斯基同时想利用这支力量先击溃布尔什维克再独占权力；事变转折的决定性力量是苏维埃斗争委员会、维克热尔断轨、约13,000–15,000名重新武装的工人赤卫队以及穆斯林代表团瓦解“野蛮师”的自下而上大众防卫动员（参见 `rabinowitch_1976_come_to_power_zh/ch08–ch10`）。
  2. **保守自由派颠覆论（Richard Pipes, 1990）**：提出尖锐反命题——**“根本不存在科尔尼洛夫政变阴谋，有的只是克伦斯基的阴谋”**（`No Kornilov plot, only a Kerensky plot`）。派普斯指出，第3骑兵军调动原系内阁委托萨文科夫防备布尔什维克暴动的合法部署，所谓三点最后通牒纯属李沃夫擅自捏造，8月26日电报对质是克伦斯基一人分饰两角的蓄意诱捕；08-27凌晨 `02:40` 科尔尼洛夫电报实证其未图谋政变，Pipes援引1917年10月设立、1918年6月完成调查的委员会结论，认为其洗清科尔尼洛夫；本卡未独立核阅完整卷宗；克雷莫夫停兵是因为抵达卢加后发现彼得格勒并无布尔什维克暴动，非关工人鼓动，而克伦斯基与萨文科夫反手向布尔什维克发放了约“4万支步枪”（`pipes_1990_russian_rev/ch20_section.md`）。
  3. **孟什维克与工人政治社会史（Ziva Galili, 1989）**：聚焦联合政权与社会心理塌方：立宪民主党人对大本营的同情观望和集体撤出彻底粉碎了孟什维克温和派苦心经营数月的“生机力量（*vital forces*）跨阶级联盟”，使工人、士兵将生存自卫等同于拥护布尔什维克；加利利考证8月31日夜苏维埃先仅有15人举手反对，经点名拉回后也仅得135票反对、仍以 **279票** 告负（其后9月9日反扑亦以 `519:414:67` 落败），Galili将其视为孟什维克首都工兵支持下降的重要节点（`galili_1989_menshevik_leaders/ch15, pp. 379–382`）。
  4. **托洛茨基“双重阴谋与武装彩排”论（Leon Trotsky, 1930）**：在《俄国革命史》第37–38章中作为事变期间仍被拘押的当事人，事后将其解释为“克伦斯基的阴谋”与“科尔尼洛夫叛乱”的交织；对密谈及动机的叙述不是在场见证：克伦斯基原与科尔尼洛夫、萨文科夫暗中合谋借第3骑兵军碾平彼得格勒左翼（乃至在8月26日公然将面包价格翻倍、密嘱萨文科夫准备戒严法），只是发觉科尔尼洛夫意欲取自己而代之后才仓皇反咬一口并扮演“护宪救星”；对无产阶级而言，反击科尔尼洛夫正是“十月武装起义的实战总彩排”。

### 3.2 四家核心原文直引档案
1. **Pipes (1990) 彻底否定“科尔尼洛夫政变论”（`ch20_section.md#L331`）**：
> “Was there a ‘Kornilov plot’? Almost certainly not.”

  Pipes称委员会于1917年10月设立、1918年6月完成调查并否认针对科尔尼洛夫的指控；这是他对该结论的援引及自身判断，非本卡对完整卷宗的独立裁定。

2. **Galili (1989) 论立宪民主党脱敏与8月31日苏维埃决裂（`ch15_nine_revolutionary_defensism_at_an_impas.md`, `p. 380` / PDF `p. 406`）**：
> "Kornilov's defeat was accompanied by a decisive shift to the left among workers and soldiers and an unprecedented radicalization of the entire political atmosphere. Not only were the Kadet leaders completely compromised by their sympathy for Kornilov and their withdrawal from the cabinet on August 27, but the concept of coalition with the 'progressive bourgeoisie,' and indeed with the 'vital forces,' was dealt a fatal blow."

3. **Rabinowitch (1976) 对萨文科夫协议、休斯对话与红卫队/穆斯林代表瓦解野蛮师的记录（`rabinowitch_1976_come_to_power_zh/ch09–ch10`）**：
- 明确记录萨文科夫8月23–24日以合法防暴为名协商第3骑兵军、李沃夫于25–26日夹带独裁方案、26日晚克伦斯基利用休斯电报机交叉诱供，以及8月28–29日超过240个地方斗争委员会、维克热尔拆轨和含沙米尔后裔的穆斯林代表团在卢加一线从内部瓦解“野蛮师”。

4. **Trotsky (1930) 对事后对“克伦斯基—科尔尼洛夫双重阴谋”的解释（`trotsky_1930_history_rr_zh/ch37–ch38`）**：
- 指出克伦斯基事先配合科尔尼洛夫计划用武力解散彼得格勒苏维埃与布尔什维克（萨文科夫甚至筹划军队入城后实行戒严），唯当8月26日察觉大本营企图一并清洗自己时才临阵倒戈，客观上将步枪与苏维埃合法防卫权交到了十月起义者手中。
