## [T1] 60秒定性微摘要

1917年10月24—27日（俄历；公历11月6—9日），军事革命委员会夺取彼得格勒中枢，冬宫陷落，苏维埃二大通过和平、土地法令并建立人民委员会。群众激进化、组织夺权与多党联合失败交织；首都迅速接管不代表全国无血革命。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络

**工兵转向与中央仍有分歧。** 科尔尼洛夫事件后，布尔什维克在彼得格勒、莫斯科苏维埃取得多数，托洛茨基出任首都苏维埃主席。DATA-01所录春夏区杜马布党20.4%、工人部55%、工厂委员会代表会议73%，分母各不相同，不能连成全市民意直线。DATA-07所录莫斯科布党选票由`1917-06-25 [O.S.] / 07-08 [N.S.]`市杜马选举的75,409票（约11.7%–12%，投票率约63%）升至`09-24 [O.S.] / 10-07 [N.S.]`17区杜马选举的199,337票（约51%，投票率约38%），既显示真实扩张，也提示投票率下降与党派支持并非同一指标。农村夺地、停产恐惧与拒战使苏维埃政权口号扩大影响，却不能推出全国已授权布党独掌政府。

**10日与16日起义决议。** `1917-10-10 [O.S.] / 10-23 [N.S.]`中央在苏汉诺夫寓所秘密开会（苏汉诺夫本人不在场），以**10∶2**通过起义方针，加米涅夫、季诺维也夫反对；并未由这一票决直接确定全部行动时刻。`10-16 [O.S.] / 10-29 [N.S.]`扩大会议重申准备起义并设党的军事革命中心。16日票数存在本地版本异文：托洛茨基记20赞成、2反对、3弃权，Rabinowitch本地中译切片记19、2、4；保留出处差别，不造一致数字。`10-18 [O.S.] / 10-31 [N.S.]`加米涅夫在《新生活报》公开说明自己与季诺维也夫反对近期起义，引发列宁指责泄露计划并要求处分。应区分两人党内反对文件、加米涅夫公开发言及列宁的“破坏罢工者”政治定性，不能说两人共同刊出一份完整作战表。依据：十月L3、Rabinowitch ch11–12、中央决议原典入口。

**军革委把进攻部署嵌入防御合法性。** 彼得格勒苏维埃军事革命委员会（MRC）围绕抵制驻军调往前线、保卫首都与苏维埃二大形成，正式架构并不等同党的军事革命中心。托洛茨基把政委副署、军械与要塞归属、驻军拒绝军区命令等步骤写成防御措施，实际剥夺临时政府指挥能力。列宁催促先于二大夺权，托洛茨基更看重苏维埃名义与大会衔接，两者目标趋同而节奏有张力。Rabinowitch据此解释非党工兵为何接受部署；Pipes则视“保卫苏维埃”为掩护预谋进攻的烟幕。

**24—26日接管与冬宫。** `1917-10-24 [O.S.] / 11-06 [N.S.]`清晨政府封闭布党报纸、试图升桥，MRC以反击为名动员；当夜至`10-25 [O.S.] / 11-07 [N.S.]`晨，武装分队控制桥梁、车站、电报等中枢。25日上午宣布临时政府被推翻时，部长仍在冬宫，故文告是夺权宣告而非最后据点已陷的准确战报。晚间阿芙乐尔号空炮、彼得保罗要塞炮击与守军流散并行，冬宫在反复渗入、零星交火后于`10-26 [O.S.] / 11-08 [N.S.]`凌晨约2时陷落，部长被捕；克伦斯基此前已离城求援。首都攻防死亡很少，但不能把Pipes的冬宫局部约五人死亡移作全俄十月死亡数，更不能照搬后来影视中的整齐大冲锋。

**二大：联合政府动议、退场与两项法令。** `1917-10-25 [O.S.] / 11-07 [N.S.]`夜大会开幕，马尔托夫的停止流血、协商全社会主义政府动议最初获广泛支持；孟什维克右翼与右翼社革党抗议夺权退场，使动议丧失跨党落实基础。马尔托夫国际派随后也在内部激辩后退场，苏汉诺夫记其党团约14∶12决断；这不是全部孟什维克最初退场的票数。左翼社革党仍留会。冬宫陷落消息到达后，大会宣告政权转归苏维埃，第一场会议休会。第二场会议于`10-26 [O.S.] / 11-08 [N.S.]`夜通过《和平法令》，并审议《土地法令》，吸收社革党主持汇集的**242份农民委托书**。土地案实际表决和组建人民委员会延至`10-27 [O.S.] / 11-09 [N.S.]`凌晨，法令署日仍从26日会议起算。本卡end日期因此涵盖二大闭幕；未把跨午夜表决挤回前一天。第一届人民委员会由布尔什维克组成，左翼社革党当时留席不等于已入阁。

**维克热尔与莫斯科揭示替代道路。** 全俄铁路工会执委会（Vikzhel／维克热尔）以交通控制力推动全社会主义联合政府谈判；加米涅夫、李可夫、诺金等支持妥协，列宁、托洛茨基与反布党派对权力和人选的要求使谈判破裂，部分温和布党中央委员于`1917-11-04 [O.S.] / 11-17 [N.S.]`辞职。莫斯科则从`10-25 [O.S.] / 11-07 [N.S.]`争权、谈判，进入`10-27 [O.S.] / 11-09 [N.S.]`以后多日街垒战与炮击克里姆林宫，延至`11-02..03 [O.S.] / 11-15..16 [N.S.]`结束。Koenker（1981）强调当地多中心迟疑、工人支持苏维埃却不愿为一党独占冒内战风险；不能把军事持久战解释成莫斯科工人较“落后”。DATA-07用于比较选举与社会基础，具体炮战锚定Koenker论断、RN-W32及原书，不伪称数据表含完整死伤清册。

### 2.3 经验共识与史学争鸣

- **共识层**：布党与MRC有组织夺权，政府缺乏首都工兵有效保卫，二大退场改变政治构成，和平与土地诉求真实存在。“技术性政变”“社会革命”“苏维埃合法性”各回答不同层次，不能互相简单排斥。
- **Pipes／Figes的区别**：Pipes强调少数职业革命家抢在大会之前制造既成事实，甚至是对全国苏维埃的政变；Figes也突出列宁的夺权意志、有限直接参战者与后来民主收缩，但同时写工兵和农民的社会革命，不能把二人并成完全相同的纯阴谋论。两者的制度批判都须与真实选举扩张并读。
- **Rabinowitch（1976）**强调开放、多派的群众政党与苏维埃防卫合法性，解释布党如何取得支持，而非证明支持苏维埃的所有人赞成一党政府。其首都证据须与莫斯科及外省比较，不能直接覆盖全俄。
- **S. A. Smith／Koenker／Suny**分别揭示工厂委员会防御性自救、政策先于党派的工人选择，以及阶级话语和社会极化。Koenker将多数工人的政治同情与实际参战分开；Suny提示“阶级”本身亦在冲突中被塑造。三者都不把工人写成党中央命令的被动载体。
- **苏汉诺夫／托洛茨基**都是行动者兼事后阐释者：苏汉诺夫有会场观察、退场自责，却未亲临10月10日中央会议；他反对纯军事阴谋说，并不接受布党专政。托洛茨基亲自统筹苏维埃与军革委，《俄国革命史》的起义艺术论又包含流亡时期维护革命及本人角色的辩护。苏联正统的统一指挥、必然胜利说与后来庆典叙事均须以当时分歧和各地不同进程校正。
