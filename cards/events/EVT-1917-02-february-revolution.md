## [T1] 60秒定性微摘要
1917年2月23日至3月3日（公历3月8日至16日），彼得格勒爆发民众起义推翻罗曼诺夫王朝。妇女与工人和平抗议迅速演变为卫戍部队大规模倒戈；沙皇尼古拉二世退位，国家杜马临时委员会与彼得格勒苏维埃并立催生“双重政权”，开启俄国长达八个月的宪政民主探索与剧烈社会激进化进程。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络
- **工潮爆发与自发性神话的打破（1917-02-23 → 02-25 [O.S.] / 1917-03-08 → 03-10 [N.S.]）**：国际妇女节当天，彼得格勒维堡区女工因严重面包短缺率先走出纺织厂，迅速引爆普梯洛夫机器制造厂等数万工人同情罢工；24–25日罢工席卷全城（逾20万人），游行口号迅速由“要面包”升级为“打倒沙皇、打倒战争”；长谷川毅考证揭示，区级地下社会主义网络（区联派、布尔什维克区委、孟什维克左翼）在协调工潮中发挥了关键组织神经作用，打破了完全“自发性”的传统神话。
- **卫戍部队倒戈与沙皇政权崩溃（1917-02-26 → 02-27 [O.S.] / 1917-03-11 → 03-12 [N.S.]）**：沙皇下令武力镇压，26日 **兹纳缅斯基广场（Знаменская площадь，现起义广场）** 守军向游行开枪打死数十工人；同日下午巴甫洛夫斯基团部分连冲出营房抗议却当晚被缴械，**27日清晨** 沃伦斯基团后备连教导队由基尔皮奇尼科夫带头击杀拉什克维奇并率先兵变，继鼓动普列奥布拉任斯基团等链式倒戈、下午攻占监狱释放巴甫洛夫斯基团被捕者，引爆首都16万卫戍部队倒戈；工兵攻占军械库、释放政治犯并夺取彼得保罗要塞，沙皇官僚与警察体制瞬间土崩瓦解。
- **双重政权降生与帝制终结（1917-02-27 → 03-03 [O.S.] / 1917-03-12 → 03-16 [N.S.]）**：27日同在塔夫利达宫内，自由派成立 **国家杜马临时委员会（Duma Committee）**，左翼领袖与工人代表成立 **彼得格勒苏维埃（Petrograd Soviet）**；3月1日晚苏维埃通过彻底打破军官特权的《第一号命令》；3月2日夜尼古拉二世在普斯科夫签署退位诏书传位胞弟米哈伊尔大公；3月3日米哈伊尔拒位，米留可夫等自由派宣布临时政府不再受杜马临时委员会监护、独掌行政全权（第四届国家杜马此后仍以非正式会议存续，直至1917年10月6日临时政府宣告解散），与苏维埃形成“双重政权（dvoevlastie）”（`CLM-sukhanov-1922-dual-power-pact`, `CLM-hasegawa-2018-dual-power-origins`）。

### 2.3 史学争鸣光谱（Historiographical Spectrum）
- **经验共识**：二月革命是彼得格勒工人自发抗议与卫戍部队拒绝镇压引爆的无序大革命，沙皇政权在缺乏军队保卫的情况下以惊人速度和平崩解。
- **主要解释分歧**：
  - **[长谷川毅2018重订版实证突破 / Tsuyoshi Hasegawa]** (`CLM-hasegawa-2018-dual-power-origins`, `CLM-hasegawa-2018-duma-committee-revision`, `CLM-hasegawa-2018-sub-elite-activists`):
    1. 证伪完全“自发性”：长谷川毅考证下层激进分子（区联派、布尔什维克地方小组等 sub-elite activists）在维堡区动员中发挥了骨干作用；
    2. 重估杜马临时委员会的行政中枢功能：杜马委员会迅速掌控交通、电报并制止讨伐军，是接管政权的主导力量；
    3. 双重政权悖论新解：米留可夫在3月3日会议上为独揽独裁行政权而废黜了唯一民选合法的代议机构“国家杜马”，导致临时政府自断宪政法统，只能以“革命”为合法性，因而荒谬地反受内部分裂、缺乏行政军纪的彼得格勒苏维埃挟制。
  - **[自由主义与偶然论 / Richard Pipes]**：强调一战给沙俄国家机器带来的外源性超负荷危机；若非尼古拉二世个人的软弱平庸与军事指挥失误，罗曼诺夫王朝绝不会被几日街头骚乱推翻。
  - **[社会史与结构危机论 / Leopold Haimson, S. A. Smith]**：强调1914年战前俄国城市工人与专制国家之间的双重两极分化早已不可调和（Haimson 论题），战时面包危机与恶性通胀只是点燃了长期积聚的阶级火药桶。
  - **[帝国边疆与首都中心并置 / Eric Blanc]** (`CLM-blanc-2021-borderlands-in-1905-and-1917`)：提醒二月剧变不可仅写彼得格勒一隅——莫斯科几乎不流血易帜、前线最高统帅部集体逼退沙皇及外省动员节奏，均参与塑造政权更迭。
