## [T1] 150字定性微摘要
杜马劳动派律师、1917年临时政府司法部长、陆海军部长与总理（07-08[O.S.]/07-21[N.S.]起）。二月率先筹建杜马军事委员会，兼任苏维埃副主席入阁；六月攻势受阻、调防与退阁触发七月危机（07-06/19转全面溃败），八月与科尔尼洛夫决裂，十月离冬宫反扑失败流亡。

## [T2] 核心脉络、关系网络与史学争鸣

### 2.1 核心历史脉络（19世纪俄国内 +12 天，1900.03–1918.01 俄国内 +13 天，欧美流亡依公历 `[N.S.]`）
- **律师、劳动派议员与跨界人脉（1881–1917.02）**：`1881-04-22 [O.S.] / 1881-05-04 [N.S.]` 生于辛比尔斯克（其父任当地中学校长、曾照拂青年列宁一家）。圣彼得堡大学法科毕业后以政治辩护律师闻名全国（1912年4月“勒拿金矿惨案”后率杜马民间调查团赴西伯利亚调查，1913年反对贝利斯案反犹诬陷）；1912年当选第四届国家杜马 `劳动派（Trudovik）` 党团领袖（1917年3月二月后转入 `ORG-psr` 社会革命党）。长期同进步自由派、战时工业委员会及俄国政治共济会圈（与涅克拉索夫、捷列先科、科诺瓦洛夫等）保有密切社交纽带（斯皮岑将此极化为“自由派—共济会颠覆核心”，而西方主流政治史视其主要发挥战时跨党派沙龙联络职能，具体名册与决策实权待一手档案核考）。
- **二月军事先手与首届内阁“人质/桥梁”（1917.02–04）**：`1917-02-27 [O.S.] / 1917-03-12 [N.S.]` 在塔夫利达宫率先建立接待起义兵士的机构并扩编为国家杜马临时委员会军事委员会——**在时间上先于彼得格勒苏维埃军事委员会**（`CLM-hasegawa-2018-duma-committee-revision`）。最初虽遵守苏维埃“不入资产阶级内阁”禁令，旋即独自赴苏维埃全会以戏剧化演说请求认可并打破禁令，**同时身兼彼得格勒苏维埃副主席与首届 `ORG-provisional-government` 司法部长**（废除死刑、释政治犯）。`1917-03-03 [O.S.] / 1917-03-16 [N.S.]` 内阁首次正式会议上，克伦斯基与 `PER-milyukov` 等排挤 `PER-rodzianko`，确立临时政府脱离杜马约束行使全权（`CLM-hasegawa-2018-dual-power-origins`）。
- **陆海军部长、六月攻势与出任总理（1917.05–07）**：四月危机后古契科夫、米留可夫去职，**`1917-05-05 [O.S.] / 1917-05-18 [N.S.]`** 第一届联合内阁成立，克伦斯基转任陆海军部长（下设 `PER-savinkov` 等军政事务专员），换上军装巡回前线鼓动出击，竟在代表大会斥拒战兵士引出 **“难道自由俄国只是一群造反的奴隶之国（a state of rebellious slaves）？”** 名言而激怒基层士兵（Figes `ch17`）。`1917-06-18 [O.S.] / 1917-07-01 [N.S.]` 在苏维埃多数派背书下强行发动加里西亚夏季攻势；攻势在最初两日局部推进后迅速受阻，反战愤怒与首都卫戍部队抗拒前线调防的压力急剧升温，叠加 `07-02 [O.S.] / 07-15 [N.S.]` 立宪民主党部长因乌克兰自治争端集体退阁的直接政治导火索，触发 `1917-07-03`–`07-05 [O.S.] / 07-16`–`07-18 [N.S.]` 七月事变（`EVT-1917-07-july-days`；而 `1917-07-06 [O.S.] / 1917-07-19 [N.S.]` 德奥联军反攻引发的西南战线全面溃败则发生于七月事变启动之后）。危机中他从前线急调部队入京弹压、恢复前线死刑，在 `PER-lvov` 于 `07-07 [O.S.] / 07-20 [N.S.]` 辞职后，于 **`1917-07-08 [O.S.] / 1917-07-21 [N.S.]`** 正式兼任临时政府总理，主导7月底第二届联合内阁。
- **科尔尼洛夫决裂、督政府与十月出逃（1917.08–1970）**：7月委任 `PER-kornilov` 为最高统帅，8月中旬莫斯科国务会议左右撕裂后，经 `PER-savinkov` 往返莫吉廖夫协商调派第3骑兵军控守首都周边。`1917-08-26 [O.S.] / 1917-09-08 [N.S.]` 晚，克伦斯基在冬宫电报室经 **休斯直印电报机（Hughes teleprinter）** 以本人及传话人弗·尼·李沃夫名义向科尔尼洛夫核询李沃夫转达之条件，双方对电复措辞及调兵政治意图的理解存在尖锐分歧（有关“克伦斯基设局”抑或“大本营政变预谋”的解释争鸣详见2.3节）；次日 **`08-27 [O.S.] / 09-09 [N.S.]`** 克伦斯基下令免除科尔尼洛夫总司令职务，冲突彻底公开化并引发第3骑兵军向首都进发（`EVT-1917-08-kornilov-affair`）。为阻截进兵只得依靠苏维埃反革命斗争委员会、维克热尔断轨与上万工人赤卫队，自此在右翼军官（痛恨其“出卖科尔尼洛夫”）与左翼工兵（视其为“科尔尼洛夫密谋同伙”）两头彻底孤立。`1917-09-01 [O.S.] / 1917-09-14 [N.S.]` 宣布建立俄罗斯共和国并组建五人“督政府（Directory）”，9月下旬拼凑第三届联合内阁与毫无实权的“共和国临时议会（前议会）”。`1917-10-24 [O.S.] / 11-06 [N.S.]` 查封《工人之路报》触发起义；**`1917-10-25 [O.S.] / 1917-11-07 [N.S.]`** 晨约9时借美国使馆车辆离冬宫赴普斯科夫北方前线求援（`timeline/L3_daily/1917-10_october_insurrection.md`；Pipes `ch20`），仅促动克拉斯诺夫约700名哥萨克于 `10-28 [O.S.] / 11-10 [N.S.]` 攻占加特契纳与皇村，终在 `10-30 [O.S.] / 11-12 [N.S.]` 普尔科沃高地被红军赤卫队击退。随后化装隐匿转赴摩尔曼斯克，1918年夏流亡英法，二战后移居美国斯坦福大学胡佛研究所著书辩解直至 `1970-06-11 [N.S.]` 逝于纽约。

### 2.3 多视角史学争鸣与阐释边界
- **经验共识**：克伦斯基是1917年3月至10月唯一贯穿四届临时政府、以超党派领袖自居的枢纽人物；六月攻势最终演变为前线溃败及八月科尔尼洛夫事件中的两头失信，令其至十月已丧失任何成建制的兵力或社会依托。
- **核心争鸣（详参 `DEB-1917-dual-power-and-february-origins`、`DEB-1917-july-days-spontaneity-vs-conspiracy` 与 `DEB-1917-october-coup-or-social-revolution`）**：
  - **结构性联合陷阱 vs. 个人演说家迷狂（Ziva Galili, 1989; Orlando Figes, 1996）**：Galili（`CLM-galili-1989-menshevik-worker-alienation`, `CLM-galili-1989-coalition-government-trap`）认为克伦斯基并非仅靠个人虚荣推进战争，而是将温和社会主义者“对内民主调停 + 对外护国作战”的联合政府困局推至极限；Figes（`ch17`）则鲜活勾勒其刻意模仿拿破仑式绑臂军装与“造反的奴隶”激情修辞如何加速在前线士兵中的反讽性疏离。
  - **自下而上士兵激进主义（Alexander Rabinowitch, 1968 / 1976）**：Rabinowitch（`CLM-rabinowitch-1968-grassroots-soldier-sailor-radicalism`）以驻军档案证明，七月与十月叛乱的核心驱动力是首都第一机枪团及卫戍部队抗拒“克伦斯基前线调防与六月送死攻势”，不能把士兵倒向布尔什维克简化为阴谋挑唆。
  - **科尔尼洛夫事件：克伦斯基设局论 vs. 大本营集权预谋与双向博弈论（Richard Pipes vs. Rabinowitch / Galili / Trotsky）**：围绕八月危机存在尖锐史学对立——Pipes（`ch20`, `L228, L331`）提出“根本不存在科尔尼洛夫阴谋，只有克伦斯基的阴谋”，认为第3骑兵军调动系政府防备左翼暴动的合法部署，科尔尼洛夫理解双方为合组强政府而未逐项确认李沃夫转述条件，`08-26 [O.S.] / 09-08 [N.S.]`夜休斯电报实属克伦斯基蓄意设局，致使军官团与临时政府决裂；相对地，Rabinowitch（`rabinowitch_1976_come_to_power_zh/ch08–ch10`）据大本营自8月初提前调兵及串联地下军官团考证莫吉廖夫确有军事改组与集权预谋，克伦斯基则企图借其压制左翼再独占权力；Galili（`galili_1989_menshevik_leaders/ch15`, `pp. 379–382`）聚焦卡德特对大本营的同情退阁如何彻底击碎温和社会主义者的“生机力量”联合路线；Trotsky（《俄国革命史》第37–38章；另参 `CLM-trotsky-1930-dual-power-instability`）则以事后分析将其定性为“克伦斯基阴谋与科尔尼洛夫叛乱的交织”及小资产阶级中派的“波拿巴主义摆动”（详见 `EVT-1917-08-kornilov-affair`）。
  - **二月先手与俄国保守阴谋叙事（Hasegawa, 2018 vs. 斯皮岑新传统派）**：Hasegawa 修正其仅被动接受苏维埃授权之说，凸显其在`02-27 [O.S.] / 03-12 [N.S.]`军事委员会的决断先手；当代俄国新传统派史家斯皮岑（`CLM-spitsyn-february-1917-elite-conspiracy-thesis`）则将其视为摧毁帝国的“自由派—共济会代理核心”，暴露缺乏档案量化证据的反自由派史观偏差。
