## [T1] 60秒定性微摘要
哥萨克平民出身的俄军步兵上将、最高统帅与白卫志愿军缔造者。1917年7月接任最高统帅；临时政府恢复前线死刑，他要求扩大适用，8月底“科尔尼洛夫事件”中与克伦斯基决裂，派克雷莫夫第3骑兵军扑向首都溃败；11月逃赴顿河创建白卫志愿军，`1918-04-13` 强攻叶卡捷琳诺达尔时被红军炮弹击毙。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络
- **哥萨克平民出身、东方学探险家与奥匈越狱英雄（1870–1917.04）**：生于 `1870-08-18 [O.S.] / 1870-08-30 [N.S.]` 西伯利亚乌斯季-卡缅诺戈尔斯克哥萨克翻译官家庭；毕业于米哈伊洛夫炮兵学校与总参谋部学院，通晓多种中亚语言，早年在中亚、阿富汗、波斯从事军事侦察，1907–1911年任驻华武官。一战中率第48步兵师作战，1915年4月在喀尔巴阡山重伤被奥匈帝国俘虏，1916年夏戏剧性越狱归国，一时成为全俄媒体颂扬的民族英雄。1917年二月革命后出任彼得格勒军区司令（`1917-03-02` 至 `1917-04-30 [O.S.] / 1917-03-15` 至 `1917-05-13 [N.S.]`，任职端点待核原令），在四月危机中曾下令调炮兵镇压街头示威，被彼得格勒苏维埃执委会发令拦截后愤而辞职赴西南方面军任第8集团军司令。
- **接任俄军最高统帅、恢复前线死刑与右翼集结（1917.07–08中旬）**：七月事变与加利西亚夏季攻势溃败后，科尔尼洛夫被新任总理克伦斯基任命为俄军最高统帅；本卡原记 `1917-07-19 [O.S.] / 1917-08-01 [N.S.]`，另有 `1917-07-18 [O.S.] / 1917-07-31 [N.S.]` 异文，决定、正式任命与就任日期须核任命令及公告；其大本营驻莫吉廖夫（Stavka）。临时政府恢复前线死刑；他要求扩大死刑适用及战地军事法庭权力，并限制士兵委员会权限，要求把军事管制扩展至后方铁路与军工企业；在8月中旬莫斯科国务会议（`1917-08-12–15 [O.S.] / 1917-08-25–28 [N.S.]`）上，科尔尼洛夫受到有产阶级、立宪民主党与军官团如救世主般的狂热欢呼，并在8月初已预先将克雷莫夫（A. M. Krymov）第3骑兵军（含“高加索野蛮骑兵师”）调往大卢基—普斯科夫铁路沿线待命（`1917-07_july_days_and_kornilov_affair.md`; `RN-W17-psr-dilemma-and-bolsheviks-come-to-power`）。
- **八月“科尔尼洛夫事件”与克雷莫夫骑兵军不战自溃（1917.08.24–09.01 [O.S.]）**：8月21日德军攻陷里加后，`1917-08-23–24 [O.S.] / 1917-09-05–06 [N.S.]` 陆军部代部长萨文科夫赴莫吉廖夫与科尔尼洛夫商定将首都外围划归大本营并调第3骑兵军北上防备“布尔什维克暴动”；但随着投机政客弗·尼·李沃夫（V. N. Lvov）穿梭传话并向克伦斯基递交要求集中一切军政大权的“三点最后通牒”，克伦斯基在 `1917-08-26 [O.S.] / 1917-09-08 [N.S.]` 晚通过休斯直印电报机一人分饰两角，请科尔尼洛夫确认“李沃夫口信”，并于 `08-27 [O.S.]` 晨通电免除其最高统帅职务。科尔尼洛夫盛怒之下拒命，发表《告全俄人民书》斥临时政府受德国代理人挟持，严令第3骑兵军强行进军彼得格勒。在苏维埃“反革命斗争人民委员会”、全俄铁路工会（维克热尔）拆轨堵截、约1.5万名新武装工人赤卫队及穆斯林代表团对“野蛮师”的贴身说服下，第3骑兵军于 `08-29–30 [O.S.]` 未发一枪即告瓦解，克雷莫夫于 `08-31 [O.S.]` 自杀；`1917-09-01 [O.S.] / 1917-09-14 [N.S.]` 科尔尼洛夫被新任总参谋长阿列克谢耶夫逮捕，关押于别霍夫（Bykhov）修道院。这场危机直接促成彼得格勒苏维埃于 `08-31` 夜（`09-01` 凌晨5时）以 **279票赞成、115票反对、51票弃权** 首次通过布尔什维克提出的政权决议；这不是党籍席位统计，主席团改选及稳定多数属于后续问题（`1917-07_july_days_and_kornilov_affair.md`）。
- **越狱奔赴顿河、第一次库班“冰雪行军”与阵亡（1917.11–1918.04）**：十月革命后，科尔尼洛夫于`1917-11-19 [O.S.] / 1917-12-02 [N.S.]`从别霍夫修道院获释/越狱，化装南下顿河新切尔卡斯克，与阿列克谢耶夫、邓尼金共同创建白卫**志愿军（Volunteer Army）**并任军事总司令（阿列克谢耶夫管政治财政）。1918年2月红军攻占顿河畔罗斯托夫后，科尔尼洛夫率约4,000名军官与学生军踏上惨烈的第一次库班战役（“冰雪行军” Ice March）；`1918-04-13 [N.S.]` 清晨，在以劣势兵力强攻北高加索红军首府叶卡捷琳诺达尔（Ekaterinodar，今克拉斯诺达尔）时，其农舍指挥部被红军一枚流弹精准命中，科尔尼洛夫当场身亡，由邓尼金接任志愿军司令率残部北撤（`CLM-mawdsley-1987-white-movement-structural-defeat`）。

### 2.3 史学争鸣光谱（Historiographical Spectrum）
- **经验共识**：1917年8月26–30日[O.S.]克伦斯基与科尔尼洛夫的公开决裂及克雷莫夫第3骑兵军进军首都的溃败，彻底摧毁了临时政府与军官团的信任，并使布尔什维克提出的政权决议在8月31日夜首次获表决多数（279:115:51）；主席团改选及稳定多数须另行区分。
- **主要解释分歧**（详参 `DEB-1917-october-coup-or-social-revolution` 及 `L3 1917-07` `#deb-july-kornilov`）：
  - **[拉比诺维奇档案社会史 / Alexander Rabinowitch 1976]**（`RN-W17-psr-dilemma-and-bolsheviks-come-to-power`, `1917-07_july_days_and_kornilov_affair`）：证实科尔尼洛夫及其大本营幕僚（卢科姆斯基、扎沃伊科）自8月初即有真实的右翼军事夺权部署（预调第3骑兵军至大卢基—普斯科夫、潜伏首都军官小组）；同时指出挫败叛军的是苏维埃“反革命斗争委员会”、维克热尔拆轨、1.5万赤卫队及穆斯林代表团对野蛮师的跨党派草根动员，而非布尔什维克一党包办（`ch08–ch10`）。
  - **[派普斯“克伦斯基阴谋设局论” / Richard Pipes 1990]**（`CLM-pipes-1990-october-classic-coup`, `1917-07_july_days_and_kornilov_affair`）：彻底颠覆传统定性，断言**“根本不存在科尔尼洛夫政变阴谋，有的只是克伦斯基反咬设局的阴谋”**——认为8月24日萨文科夫调兵系合法内阁防暴部署，8月26日夜休斯电报机对话是克伦斯基为甩锅并独占权力而恶意设计的诱供陷阱；克雷莫夫部队停止进军主要是因发现首都并无布尔什维克暴动、不愿对抗合法政府（`Pipes 1990, ch. 20`）。
  - **[托洛茨基“双雄合谋反噬论” / Leon Trotsky 1932]**（`1917-07_july_days_and_kornilov_affair`）：专辟《克伦斯基的阴谋》与《科尔尼洛夫叛乱》两章，指出克伦斯基最初确实与科尔尼洛夫合谋企图用前线铁腕碾碎彼得格勒苏维埃，只是在发觉科尔尼洛夫与有产阶级打算顺带将自己一脚踢开时才在8月26日仓皇反咬；反科尔尼洛夫动员客观上成为“十月起义的武装彩排”（`ch37–ch38`）。
  - **[莫兹利白军结构性败因论 / Evan Mawdsley 1987]**（`CLM-mawdsley-1987-white-movement-structural-defeat`, `RN-W20-civil-war-geopolitics-and-military-specialists`）：指出科尔尼洛夫与阿列克谢耶夫、邓尼金创建的志愿军从诞生起就受困于军官团对政党政治与社会改革的鄙视（“动乱年代 *smuta*”心态）、大俄罗斯沙文主义以及与顿河/库班哥萨克地方自治主义的张力；1918年春仅4,000人的“冰雪行军”虽铸就了白军精神图腾，却暴露了其在广大农民与工人群体中的极端孤立（`pp. 212–218, 287–288`）。

## [T3] 深度考证、分期细目与原文引证档案

### 3.1 1917年8月24–31日[O.S.]“科尔尼洛夫事件”逐日档案复盘（对接 `L3 1917-07` 与 Rabinowitch 1976）
- 对接 [`timeline/L3_daily/1917-07_july_days_and_kornilov_affair.md`](../../timeline/L3_daily/1917-07_july_days_and_kornilov_affair.md)（下篇 `1917-08-24` 至 `09-01 [O.S.]`）与 [`RN-W17-psr-dilemma-and-bolsheviks-come-to-power`](../../reading-notes/hildermeier_rabinowitch1976/RN-W17-psr-dilemma-and-bolsheviks-come-to-power.md)（`ch08–ch11`）：
  1. **8月24–25日 [O.S.] / 9月6–7日 [N.S.] 萨文科夫会谈与李沃夫传话**：
     - 萨文科夫在大本营向科尔尼洛夫传达克伦斯基同意将彼得格勒军区（不含首都直接郊区）划归大本营，并调克雷莫夫第3骑兵军（高加索野蛮师、乌苏里师、第1顿河哥萨克师）北上集结；25日科尔尼洛夫向中间人弗·尼·李沃夫提出宣告首都戒严、军政大权集中于最高统帅、克伦斯基与萨文科夫赴大本营任次席部长的改组要求。
  2. **8月26日 [O.S.] / 9月8日 [N.S.] 晚20:30–21:30 休斯电报机直通对质**：
     - 李沃夫在冬宫向克伦斯基递交三点书面通牒后，克伦斯基在陆军部电报室通过休斯直印电报机（Hughes teleprinter）一人分饰自己与“李沃夫”两角，请科尔尼洛夫在纸带上确认：**“我完全确认此前经弗拉基米尔·尼古拉耶维奇向您转达的全部请求……”**，随即当场逮捕李沃夫并于27日晨通电免除科尔尼洛夫职务。
  3. **8月27–31日 [O.S.] / 9月9–13日 [N.S.] 维克热尔拆轨、赤卫队武装与279:115历史表决**：
     - 科尔尼洛夫拒命并发出《告全俄人民书》，令第3骑兵军强行进军；苏维埃于28日组建包含布尔什维克的“反革命斗争人民委员会”，维克热尔拆毁卢加、维里察道岔阻塞军列，政府军火库向约**1.3万–2万名工人赤卫队**发枪，高加索穆斯林代表团说服“野蛮师”兵不血刃停火（29日），克雷莫夫自戕（31日日间），彼得格勒苏维埃于 `8月31日夜至9月1日凌晨05:00` 以 **279票赞成、115票反对、51票弃权**首次通过布尔什维克政权决议。
