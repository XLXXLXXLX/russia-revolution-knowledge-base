## [T1] 60秒定性微摘要
俄国民粹派革命家、民意党执委会核心领袖。农奴出身，受教育后投身地下斗争；`1879-06-17 [O.S.] / 1879-06-29 [N.S.]` 起参与利佩茨克会议确立集中密谋体制；组织刺杀沙皇案并于法庭上作著名抗辩；`1881-04-03 [O.S.] / 1881-04-15 [N.S.]` 与佩罗夫斯卡娅等共五人被处绞刑。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络
- **农奴出身与激进化（1851–1876）**：生于 `1851-08-17 [O.S.] / 1851-08-29 [N.S.]`（通行传记对照，待核出生登记）**塔夫里达省费奥多西亚县**农奴家庭（出生地具体村名存“尼古拉耶夫卡”与“戈尔诺斯塔耶夫卡”两说冲突，待查费奥多西亚县出生记录裁决）；父母赎身后将他送入中学，后入敖德萨大学（新罗西斯克大学），因参与学生运动被开除，转入民间鼓动的民粹主义地下网络。
- **“到民间去”受挫与城市恐怖转向（1876–1879）**：参与第二代土地与自由社农村宣传，亲历索洛维约夫 `1879-04-02 [O.S.] / 1879-04-14 [N.S.]` 刺沙未遂后全国戒严的高压；与执委会组织核心**亚历山大·米哈伊洛夫**（Александр Дмитриевич Михайлов，1884年死于要塞，须严格区分于1881年同上绞刑架的工人季莫费·米哈伊洛夫）等主张以针对专制中心的政治恐怖凝聚异质激进力量（`CLM-venturi-1960-lipetsk-voronezh-split`）。
- **利佩茨克与沃罗涅日分裂（1879.06–09）**：`1879-06-17 [O.S.] / 1879-06-29 [N.S.]` 至 `1879-06-21 [O.S.] / 1879-07-03 [N.S.]` 利佩茨克会议上，以其民粹良知否决莫罗佐夫纯反专制、缺乏社会内容的纲领草案，却推动通过选举集中制与赋予执委会“党中央政府”权的章程突破（`CLM-venturi-1960-lipetsk-voronezh-split`, `p. 650`）；`1879-06-24 [O.S.] / 1879-07-06 [N.S.]` 沃罗涅日大会上与普列汉诺夫等达成短暂妥协，唯经费分配名义上保留农村三分之二；`1879-08-26 [O.S.] / 1879-09-07 [N.S.]` 执委会正式判处亚历山大二世死刑，`1879-09-12 [O.S.] / 1879-09-24 [N.S.]` 宣告从土地与自由社彻底独立为民意党[^chron-note]。
- **“三月一日案”与法庭抗辩（1880–1881）**：作为执委会实际组织核心协调炸药工坊、军官支部与刺杀行动；`1881-03-01 [O.S.] / 1881-03-13 [N.S.]` 刺杀亚历山大二世成功（热利亚博夫先期被捕，当日由佩罗夫斯卡娅现场指挥）；被捕后受审于参政院特别法庭（通行编年记特别法庭于 `1881-03-26 [O.S.] / 1881-04-07 [N.S.]` 开庭，3月29日 [O.S.] 属后续庭审阶段，待庭审日志原件核实），在庭上以社会复仇论与人民代表权抗辩专制；`1881-04-03 [O.S.] / 1881-04-15 [N.S.]` 与**索菲亚·佩罗夫斯卡娅、尼古拉·基巴尔契奇、季莫费·米哈伊洛夫（Тимофей Михайлович Михайлов）、尼古拉·雷萨科夫**共五人一同被处绞刑（同案盖莉·格尔夫曼因怀孕暂缓未绞）。

[^chron-note]: 注：文图里《革命的根源》第29章年表另记有 `1879-11-18`“民意党成立”异文；正文第21章及论断卡 `CLM-venturi-1960-lipetsk-voronezh-split` 则以 `1879-08-26 [O.S.]` 判处沙皇死刑、`1879-09-12 [O.S.] / 1879-09-24 [N.S.]` 宣告完全自治为据。

### 2.3 史学争鸣光谱（Historiographical Spectrum）
- **经验共识**：热利亚博夫是1879–1881年民意党从组织分裂到“三月一日”刺杀的关键执行者，其农奴出身与法庭演说使其成为民粹烈士象征之一。
- **主要解释分歧**（相关待建争鸣母题卡：`DEB-1879-zemlya-i-volya-split`、`DEB-narodnaya-volya-jacobinism-vs-constitutionalism`）：
  - **[Franco Venturi 结构史解释]**（`CLM-venturi-1960-lipetsk-voronezh-split`）：分裂源于农村工作绝境下恐怖作为“粘合剂”与集中制的组织先发制人，非单纯个人冲突；热利亚博夫名言“我们在吃老本”（*living on capital*）概括民意党把多年民粹资本投入致命一击的战略赌注。
  - **[伯林道德人文主义]**（`CLM-berlin-1960-populism-moral-core`）：即便最雅各宾的恐怖派仍以具体道德主张为暴力辩护，不承认历史必然为之开脱——与后世列宁主义决定论形成对照。
  - **[苏联烈士史学]**：突出阶级成分（农奴子弟）与反专制献身，弱化执委会立宪会议纲领中的复杂政治诉求。
  - **[自由主义连续派]**：将热利亚博夫中心论倾向与布尔什维克集权创伤作直线关联，文图里—伯林谱系则强调民意党立宪构想的内在悖论与限制。
