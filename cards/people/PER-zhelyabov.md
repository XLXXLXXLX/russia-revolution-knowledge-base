## [T1] 150字定性微摘要
农奴出身的俄国民粹派革命家与民意党执委会灵魂领袖。青年时在敖德萨独立开展工人与知识界鼓动，1878年“193人案”获释后于1879年利佩茨克与沃罗涅日会议推动集中制与政治决战，兼抓工人战斗队与军官支部；1881-02-27[O.S.]/03-11[N.S.]被捕，04-03/04-15就义。

## [T2] 核心脉络、关系网络与史学争鸣

### 2.1 核心历史脉络（严守19世纪俄历转公历 +12 天规则）
- **农奴出身与敖德萨独立道路（1851–1878）**：`1851-08-17 [O.S.] / 1851-08-29 [N.S.]` 生于塔夫里达省费奥多西亚县农奴家庭（出生村名存“尼古拉耶夫卡”与“戈尔诺斯塔耶夫卡”两说待核），父母赎身后送其入辛菲罗波尔中学与新罗西斯克（敖德萨）大学；1872年因领导抗议博吉希奇教授（Bogišić）学潮遭开除。此后他**并未加入 `ORG-zemlya-i-volya` 或南方“起义派”**，而是立足敖德萨自由宪政—乌克兰文化圈（Hromada）独自探索工人宣传与政治结合（Venturi `ch22` `p. 645`）；`1874` 年秋因宣传被捕、`1875-03` 获释，与敖德萨自由派市长亚赫年科之女的婚姻因阶级与献身观决裂（致德拉戈马诺夫长信见证了革命青年与温和知识界的分野），并积极推动俄波联合与巴尔干斯拉夫委员会活动。在“193人案”（`EVT-1874-going-to-the-people`）被羁押并受参议院审判后，于 `1878-01-23 [O.S.] / 1878-02-04 [N.S.]` 获判无罪释放（`p. 646`）。
- **利佩茨克—沃罗涅日分裂与立宪民粹综合（1879）**：1879年春经弗罗连科赴敖德萨直接召请，热利亚博夫在“为安抚民粹派良知而仅承诺单次政治刺杀”的前提下赴会（`p. 647`）。在 `1879-06-17`–`06-21 [O.S.] / 1879-06-29`–`07-03 [N.S.]` 利佩茨克秘密会议上，他既支持确立选举集中制与“执行委员会”权威，又与同僚**否决了莫罗佐夫缺乏民粹社会内容的纯反专制纲领草案**（`CLM-venturi-1960-lipetsk-voronezh-split`, `pp. 649–652`；最初五人行政局未列其名，随后入主执委会）。在 `1879-06-24 [O.S.] / 1879-07-06 [N.S.]` 沃罗涅日代表大会上，他力主争取自由政治制度以保障社会主义活动，遭土地与自由社正统派讥为“纯宪政派”（`p. 655`）；随着 `1879-08-26 [O.S.] / 1879-09-07 [N.S.]` 判处 `PER-alexander-ii` 死刑及 `1879-09-12 [O.S.] / 1879-09-24 [N.S.]` 正式分立（同书第29章年表另见 `1879-11-18` 异文），成为 `ORG-narodnaya-volya` 的最高行动核心。
- **工人战斗队、军官组织与“三月一日案”（1879.11–1881.04）**：`1879-11-18 [O.S.] / 1879-11-30 [N.S.]` 亲赴亚历山德罗夫斯克铺设沙皇专列地雷未爆。1880年夏秋面对专制镇压与失业潮，热利亚博夫将大量精力投入城市工人与军界：提出“**在俄国，每次罢工都是政治性的**”（`ch24` `p. 700`），依托工人战斗队（*druzhinas*）与城市先发信号点燃全国革命；于 `1880-12-15 [O.S.] / 1880-12-27 [N.S.]` 主编创刊通俗《工人报》（*Rabochaya Gazeta*，`p. 704`），并于1880年秋组建陆海军“军事组织”（吸纳苏哈诺夫、罗加乔夫等军官，约200–300名彼得堡工人与莫斯科据点）。`1881-02-27 [O.S.] / 1881-03-11 [N.S.]` 傍晚与特里戈尼在涅瓦大街寓所被捕，由 `PER-perovskaya` 接掌指挥并于 `1881-03-01 [O.S.] / 1881-03-13 [N.S.]` 刺死沙皇（`EVT-1881-03-assassination-of-alexander-ii`）。闻讯雷萨科夫供述后，热利亚博夫于 `1881-03-04 [O.S.] / 1881-03-16 [N.S.]` 主动致信检察官要求并案公审，在 `1881-03-26`–`03-29 [O.S.] / 1881-04-07`–`04-10 [N.S.]` 参议院特别法庭作纲领性抗辩（宣告因和平宣传受阻才转向武装斩断专制并诉诸立宪会议）；`1881-04-03 [O.S.] / 1881-04-15 [N.S.]` 与佩罗夫斯卡娅、基巴尔契奇、季莫费·米海洛夫（须严别于执委亚历山大·米哈伊洛夫）、雷萨科夫在谢苗诺夫广场同被绞决（同案格尔弗曼因孕缓刑）。

### 2.3 多视角史学争鸣与阐释边界
- **经验共识**：热利亚博夫是1879—1881年将民粹主义社会理想与有组织政治斗争、城市工人鼓动及弑君决策融于一身的核心行动者，既拒绝纯反专制的无社会纲领，也抗拒永久党专政。
- **核心争鸣（详参 `DEB-1879-narodnaya-volya-to-bolshevism`）**：
  - **“靠老本过活”与非土地与自由社出身考证（Franco Venturi, 1960）**：文图里修正了“热利亚博夫出身土地与自由社农村殖民点”的常见误读，强调他来自敖德萨乌克兰—立宪派交叉环境（`ch22` `p. 645`）；名言“我们一直在吃老本”（*living on capital*）揭示民意党耗尽多年积累投入一击的孤注一掷（`CLM-venturi-1960-lipetsk-voronezh-split`, `CLM-venturi-1960-narodnaya-volya-constitutionalism`）。
  - **“立宪倾向”与“布朗基—雅各宾倾向”二重划分（Plekhanov / Andrzej Walicki, 1969）**：瓦利茨基援引普列汉诺夫对民意党内部的经典剖析（`ch03` `pp. 104–106`），将**热利亚博夫代表的“立宪倾向”**（主张联合自由派推翻专制并确立代议制与政治自由，以米海洛夫斯基《社会主义者的政治书简》为理论支柱）与**奥沙尼娜受扎伊奇涅夫斯基和特卡乔夫影响的“雅各宾倾向”**（及季霍米罗夫的折中摇摆）严格区隔。
  - **民粹伦理理想型与历史决定论的分野（Isaiah Berlin, 1960）**：伯林关于民粹主义总体伦理内核的理想型论述（同时提示民意党内部的集权张力，`CLM-berlin-1960-populism-moral-core`）为理解该代行动者拒斥以抽象历史必然性豁免党专政提供了宏观思想史视角；至于热利亚博夫个人的伦理良知自述，仍须结合参议院特别法庭速记与私人书信原件独立核验。
  - **爱尔福特重审与列宁《怎么办？》的“俄国热利亚博夫”喻（Lars T. Lih, 2006）**：针对自由派连续论（`CLM-pipes-1990-patrimonial-state-and-intelligentsia`）把民意党集中制直接连向布尔什维克极权，Lih 考证 `PER-lenin` 在《怎么办？》中以“革命活动就是我的职业”（源自纳杰日丁所引热利亚博夫）定义“职业革命家”（*revoliutsioner po professii*），并把梅什金、罗加乔夫、热利亚博夫、米哈伊洛夫、佩罗夫斯卡娅、菲格涅尔颂为担起最重责任的群众领袖，呼唤同时造就“俄国的倍倍尔”与“社会民主党的热利亚博夫”——这恰是为服务德国SPD式公开群众路线而挪用民粹派献身典范，而非继承秘密政变教义（`sources/monographs/lih_2006_lenin_rediscovered/ch12_commentary_part_11.md`, `ch26_translation_part_5.md`）。
