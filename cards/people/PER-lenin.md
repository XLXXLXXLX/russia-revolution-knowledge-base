## [T1] 60秒定性微摘要
布尔什维克党缔造者、苏俄人民委员会主席（1917–1924）。1893年投身马克思主义运动，1903年促成布尔什维克分化；1917年发表《四月提纲》并领导十月夺权，历经布列斯特和约、内战与战时共产主义；1921年主持转向新经济政策，晚年（1922–1923）就官僚化与接班人同斯大林冲突。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络
- **扬弃民粹派、地下权威建构与建党分化（1887–1904）**：生于 `1870-04-10 [O.S.] / 1870-04-22 [N.S.]` 辛比尔斯克；父辈合法启蒙理想破产与兄长亚历山大因民意党刺君案于 `1887-05-08 [O.S.] / 1887-05-20 [N.S.]` 就义后，青年列宁夏读车尔尼雪夫斯基《怎么办？》锻造自律人格；1889–1895年在萨马拉至圣彼得堡完成了对俄国民粹派的**辩证扬弃（Aufhebung）**——肯定民意党政治夺权视野与反农奴制彻底性，却以地方自治局农户统计拆穿“同质人民”空想（`“人民是由利益不同的阶级组成的”`），并在1893年底圣彼得堡辩论中力压赫尔曼·克拉辛照搬《资本论》第2卷图式的抽象公式主义（`CLM-loginov-lenin-early-synthesis-and-1917-strategy`）。1895年与马尔托夫等建“工人阶级解放斗争协会”，以业务实干、理论功底与地下分工赢得马尔托夫、塔赫塔廖夫与工人骨干承认的**“平等中的第一人”**自然权威（`CLM-lenin-leader-organizational-ascendancy-pre1914`）。1900年流亡创办《火星报》，1902年撰《怎么办？》论证社会民主主义意识须由职业革命家“从外面灌输”；`1903-07-17 [O.S.] / 1903-07-30 [N.S.]` 至 `08-10 [O.S.] / 08-23 [N.S.]` 社民工党二大期间因党章第一条与中央/《火星报》人选同马尔托夫决裂，促成布尔什维克分化，并在1904年《进一步，退两步》中沿用普列汉诺夫1901年“山岳派（雅各宾派）对吉伦特派”正统马克思主义隐喻回击孟什维克（`CLM-mayer-1999-lenin-jacobin-metaphor-vs-blanquism`）。
- **1905革命、一战转向与《国家与革命》（1905–1917.02）**：1905年撰《两种策略》提出“工农民主专政”；一战爆发后批驳第二国际社会沙文主义，号召“变帝国主义战争为国内战争”，1916年撰《帝国主义论》并探讨民族自决与社会主义国际整合（`CLM-carr-1950-self-determination-to-federal-reunion`）。
- **1917年五次战略即兴、党内制衡与十月夺权（1917.03–1918.03）**：`1917-02-23 [O.S.] / 1917-03-08 [N.S.]` 二月革命后经德国过境于 `1917-04-03 [O.S.] / 1917-04-16 [N.S.]` 抵彼得格勒，面对错综局势并非按单一蓝图推进，而是经历五次剧烈战略即兴与党内多数反复博弈（`CLM-loginov-lenin-vs-party-moderates-1917`, `CLM-loginov-lenin-1917-fleeting-window-of-power`）：
  1. **四月反布朗基主义和平争多数**：`1917-04-04 [O.S.] / 1917-04-17 [N.S.]` 宣读《四月提纲》，搁置“国内战争”口号、否定少数人密谋；`04-06 [O.S.] / 04-19 [N.S.]` 中央主席团加米涅夫与斯大林（`“有模式，但没有事实”`）反对，彼得格勒委员会更以 `13:2:1` 否决。
  2. **七月先刹车再换口号再遭否决**：`1917-07-03 [O.S.] / 1917-07-16 [N.S.]` 闻街头暴动即断定`“这可太不合时宜了”`并由中央禁行；`07-10 [O.S.] / 07-23 [N.S.]` 撰《七月提纲》改判和平口号失效、转入武装起义准备，旋即在 `07-13–14 [O.S.]` 扩大会议遭约10票反对搁置，列宁地下撰《国家与革命》。
  3. **9月初48小时《论妥协》窗口**：科尔尼洛夫叛乱后，`1917-09-01 [O.S.] / 1917-09-14 [N.S.]` 提议由孟什维克与社革党组纯苏维埃政府以求和平演进，两日后见中执委倒向克伦斯基即行撤回。
  4. **9月中旬起义信遭中央否决后的自我纠偏**：`1917-09-12–14 [O.S.] / 09-25–27 [N.S.]` 致信中央要求立即包围“民主会议”发动起义；`09-15 [O.S.] / 09-28 [N.S.]` 中央以 `6:4:6` 仅留单份副本、拒绝即时起义并责成军事组织与彼委防止兵营工厂上街（列宁1921年向克赖比希坦承该方案`“过‘左’……幸运的是它被否决了”`）。
  5. **10月锁定“稍纵即逝的契机”与法令先决**：`10-01`、`10-17` 及 `10-24 [O.S.] / 11-06 [N.S.]` 连函催促`“拖延发动等于自取灭亡”`；`10-18 [O.S.] / 10-31 [N.S.]` 秘密会议采纳左派社革党人拉济米尔任主席的彼得格勒苏维埃**军事革命委员会（ВРК）**作多党合法性司令部；`1917-10-25 [O.S.] / 1917-11-07 [N.S.]` 推翻临时政府后，次晚（`10-26 [O.S.] / 11-08 [N.S.]`）绕开联合组阁僵局率先推动全俄苏维埃二大通过《和平法令》与吸收242份农民委托书的《土地法令》（`WEB-1917-10-26-decrees-peace-land`）。`1918-01-05 [O.S.] / 1918-01-18 [N.S.]` 解散立宪会议，3月力排左翼反对缔结《布列斯特和约》。
- **党国体制成型、二元外交、NEP与“最后斗争”（1918.04–1924.01）**：内战与“极端紧迫”授权推动**人民委员会（Sovnarkom）**（颁 `1,615` 项法令）实质架空全俄中执委（`375` 项），继而1919年八大设政治局、组织局、书记处并强推党团纪律，令国家与党相互吞并（`CLM-carr-1950-soviet-to-party-ascendancy-mechanism`）；对外则在1921–1922年形成兼顾外交人民委员部（《英苏贸易协定》、1922年4月《拉帕洛条约》欧洲均势）与共产国际的“二元外交”，并于1922年底四大完成“保卫苏俄压倒各国革命”的制度逆转（`CLM-carr-1953-dual-foreign-policy-rapallo-comintern`）。1921年3月俄共（布）十大在镇压喀琅施塔得的同时引入新经济政策与派别禁令；1922年5月中风后，1922年末至1923年初口授《给代表大会的信》（建议撤换斯大林总书记职务）与《论合作社》，并在格鲁吉亚事件与外贸垄断权问题上反对斯大林—奥尔忠尼启则—捷尔任斯基的大俄罗斯沙文主义与官僚化，至1923年3月第三次中风失语，`1924-01-21` 逝于戈尔基村。

### 2.3 史学争鸣光谱（Historiographical Spectrum）
- **经验共识**：列宁兼具敏锐的历史转折点直觉与高度集中的组织决断；但从青年地下时期至1917年十月起义前夕，布尔什维克党内均存在实质的制衡与路线博弈，并非他一人发号施令的铁板机器。
- **主要解释分歧**：
  - **[苏联正统叙事]**：将列宁塑造为从1902年到1923年一以贯之的科学无误领袖，掩盖《四月提纲》前后的战略急转、1917年中央对列宁的多次否决，以及1922–1923“遗嘱”对斯大林的批评。
  - **[俄罗斯后苏联档案派 / В. Т. 洛吉诺夫]** (`CLM-loginov-lenin-early-synthesis-and-1917-strategy`, `CLM-lenin-leader-organizational-ascendancy-pre1914`, `CLM-loginov-lenin-1917-fleeting-window-of-power`, `CLM-loginov-lenin-vs-party-moderates-1917`)：依托 РГАСПИ 档案与敌手证言，解构“天生权力狂/催眠术”与“单一密谋时刻表”，证实青年列宁立足俄国实证统计扬弃民粹派并靠业务权威成“平等中的第一人”；1917年则经历了四、七、九月至少三次战略转向与中央多数的公开碰撞（包括9月15日否决其“过左”方案），最终在10月紧扣多党制 ВРК 夺取“稍纵即逝的契机”。
  - **[剑桥概念史与语境修正派 / Robert Mayer, Lars T. Lih]** (`CLM-mayer-1999-lenin-jacobin-metaphor-vs-blanquism`)：Lih 将《怎么办？》复归俄德社会民主主义反“经济派”语境；Mayer 则从词源学证伪派普斯与瓦利茨基的“列宁=特卡乔夫俄国雅各宾密谋派”谱系，证明“俄国雅各宾”乃拉夫罗夫（1874）的贬义发明且为特卡乔夫、民意党所拒绝，列宁1904年的“雅各宾”自称直接承自普列汉诺夫1901年的正统马克思主义修辞，意在比喻不可收买的工人阶级斗争精力。
  - **[制度主义与宏大结构史 / E. H. Carr]** (`CLM-carr-1950-soviet-to-party-ascendancy-mechanism`, `CLM-carr-1950-self-determination-to-federal-reunion`, `CLM-carr-1953-dual-foreign-policy-rapallo-comintern`, `CLM-carr-1979-revolution-from-below-to-revolution-from-above`)：揭示1917年列宁一度顺应并融合“自下而上的分散化革命”，但在国际孤立、内战“极端紧迫”与计划经济压力下，苏俄经过人民委员会压倒中执委、党嵌入苏维埃、民族自决重释为“单一联盟国家”实质平等，以及1922年拉帕洛均势与共产国际四大逆转，在**列宁仍在世时即已定型为党国互吞的单一国家体制**。
  - **[自由-极权主义连续性派 vs 晚期修正与文本批判 / Richard Pipes, Moshe Lewin, В. А. Сахаров]** (`CLM-pipes-1990-october-classic-coup`, `CLM-lewin-1968-georgian-affair-bureaucracy`, `CLM-sakharov-2012-lenin-cooperative-plan-debates`)：Pipes 视十月为马尔帕尔泰式无声政变与一党专政极权起点；Lewin 认为晚年列宁在格鲁吉亚问题上敏锐察觉“大俄罗斯沙文主义与官僚社会基础”，却因囿于一党制而未能根治；Sakharov 则揭示《论合作社》一、二两稿存在“商业供销合作社”向“国有土地生产合作社（集体农庄）”的文本断裂，指出斯大林与布哈林各自只抽取了列宁遗嘱中的一半。
