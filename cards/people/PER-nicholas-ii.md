## [T1] 60秒定性微摘要
俄罗斯帝国末代沙皇（1894–1917在位）。固守东正教君权神授与家产制专制信条；经历1905年血腥星期日并被迫签署《十月宣言》，1915年亲赴莫吉廖夫兼任最高统帅引发宫廷孤立，`1917-03-02 [O.S.] / 1917-03-15 [N.S.]` 在普斯科夫退位，`1918-07-17` 在叶卡捷琳堡伊帕季耶夫宅邸被处决。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络
- **继位、“无谓的迷梦”与日俄战败（1868–1905.01）**：生于 `1868-05-06 [O.S.] / 1868-05-18 [N.S.]` 皇村亚历山大宫，亚历山大三世长子，受保守导师波别多诺斯采夫深刻影响。1894年10月继位并娶黑森-达姆施塔特公主亚历山德拉·费奥多罗夫娜；`1895-01-17 [O.S.] / 1895-01-29 [N.S.]` 接见地方自治局代表时斥责代议参政诉求为“无谓的迷梦（senseless dreams）”，坚信俄国为罗曼诺夫王朝的世袭“家产（patrimony）”（`CLM-pipes-1990-patrimonial-state-and-intelligentsia`）。1904年支持远东冒险引发日俄战争惨败；`1905-01-09 [O.S.] / 1905-01-22 [N.S.]` 军警在冬宫前枪杀加邦神父率领的请愿工人（“血腥星期日”），严重损害了部分工人与农民对“仁慈沙皇小父亲（*batiushka-tsar'*）”的信任，其影响因地区与时间而异。
- **《十月宣言》、削权杜马与六三体制（1905.10–1914）**：面对1905年10月全俄总罢工，尼古拉二世被迫于 `1905-10-17 [O.S.] / 1905-10-30 [N.S.]` 签署维特起草的《十月宣言》许诺立法杜马与公民自由；但在1906年4月局势稍稳后即解雇维特、颁布《基本法》保留沙皇对军政外交的垄断与第87条紧急立法权，并先后解散第一、第二届国家杜马。`1907-06-03 [O.S.] / 1907-06-16 [N.S.]` 以皇帝宣言颁布斯托雷平新选举法（“六三政变”），联合右翼贵族巩固保守议会秩序，但在1911年斯托雷平遇刺前已对其威胁皇室权威心生厌倦（`CLM-manning-1982-june-third-coup-social-basis`）。
- **一战御驾亲征、宫廷孤立与普斯科夫退位（1914–1917.03）**：1915年大撤退后，尼古拉二世于 `1915-08-23 [O.S.] / 1915-09-05 [N.S.]` 不顾内阁集体劝阻，罢免尼古拉·尼古拉耶维奇大公、亲自赶赴莫吉廖夫大本营（Stavka）兼任俄军最高统帅。此举使沙皇直接为前线战败担责，更把首都政务留给深信神秘主义僧侣拉斯普京（1916年12月被贵族刺杀）的亚历山德拉皇后与走马灯式的无能阁员，招致国家杜马“进步同盟”乃至皇亲与军官团的全面离心（`CLM-gaida-2003-progressive-bloc-dilemma`）。`1917-02-24 [O.S.]` 晚戈利岑首次电告首都骚乱，尼古拉二世于 `1917-02-25 [O.S.] / 1917-03-10 [N.S.]` 晚9时向哈巴洛夫发出“朕命令你明天务必平息首都骚乱”的致命镇压令，其执行使镇压升级；群众动员、部队部署、军纪裂解和统帅离心共同影响了随后事态（`RN-W1C-february-insurrection-and-dual-power`, `pp. 233, 257`）。北返专列受阻改道普斯科夫后，在总参谋长阿列克谢耶夫及北方方面军司令鲁兹斯基等全军统帅一致劝退下，于 `1917-03-02 [O.S.] / 1917-03-15 [N.S.]` 签署退位诏书（越过患血友病的皇储阿列克谢传位米哈伊尔大公，后者次日拒位），终结了长达三百余年的罗曼诺夫王朝。
- **皇村与托博尔斯克幽禁及叶卡捷琳堡处决（1917.03–1918.07）**：退位后被临时政府软禁于皇村亚历山大宫，1917年8月移送西伯利亚托博尔斯克；1918年4月底被布尔什维克乌拉尔区域苏维埃押解至叶卡捷琳堡“特殊用途宅邸”（伊帕季耶夫宅邸）。`1918-07-17 [N.S.]` 凌晨，在白军与捷克斯洛伐克军团逼近叶卡捷琳堡之际，乌拉尔地方机关组织实施处决，尼古拉二世与皇后、五名子女及随从共11人在地下室被尤罗夫斯基率领的行刑队集体枪决（`CLM-pipes-1990-red-terror-leninist-logic`）。

### 2.3 史学争鸣光谱（Historiographical Spectrum）
- **经验共识**：尼古拉二世坚持专制权力，1915年兼任最高统帅；1917年2月25日下令迅速平息骚乱，执行中镇压升级。王朝崩溃还涉及群众运动、军队部署与军纪裂解，以及统帅和政治精英离心。
- **主要解释分歧**：
  - **[派普斯“家产制国家”论 / Richard Pipes]**（`CLM-pipes-1990-patrimonial-state-and-intelligentsia`, `CLM-pipes-1990-red-terror-leninist-logic`）：将尼古拉二世定性为1900年代欧洲罕见的“不合时宜的家产制（anachronistic patrimonialism）”化身——他把国家与国库视作罗曼诺夫家族私产，在经济文化现代化的同时死守政治垄断，从而把变革主导权拱手让给同样排斥妥协的激进知识分子；他将1918年7月叶卡捷琳堡处决解释为中央预防性恐怖政治的一部分，但未出示列宁下令处决全家的文件（`RN-W4B-patrimonialism-and-october-coup`, `ch10 L74–124`）。
  - **[长谷川毅二月革命微观决策史 / Tsuyoshi Hasegawa]**（`CLM-hasegawa-2018-duma-committee-revision`, `CLM-hasegawa-2018-dual-power-origins`, `RN-W1C-february-insurrection-and-dual-power`）：2018年增订版据新档案修正指出，尼古拉二世早在 `1917-02-24 [O.S.]` 晚即收到戈利岑关于首都骚乱的首封电报（而非旧说25日傍晚），其25日晚9时命令迅速平息骚乱；镇压升级与群众动员、部队部署及军纪裂解共同构成此后哗变的背景；同时揭示3月2日退位是由渴望秩序的前线将领（阿列克谢耶夫、鲁兹斯基）与具有内生革命意图的国家杜马临时委员会共同完成的（`pp. 233, 257, 369–378, 620–626`）。
  - **[曼宁土地贵族社会史 / Roberta T. Manning]**（`CLM-manning-1982-gentry-fronde-to-reaction`, `CLM-manning-1982-june-third-coup-social-basis`）：反对将帝俄危机简化为尼古拉二世的个人性格缺陷，强调沙皇政权的兴衰取决于其与地方土地缙绅阶层的结构性关系——1905年他向库尔斯克右翼贵族代表团倾斜，1907年六三体制及此后对斯托雷平地方改革的阻挠，均受制于联合贵族会的阶级自保压力（`pp. 80–85, 206–208, 238–239`）。
  - **[费吉斯政治文化与长时段悲剧论 / Orlando Figes]**（`CLM-figes-1996-peasant-moral-economy-1917`, `CLM-figes-1996-soldier-mutiny-and-social-inversion`）：强调尼古拉二世沉溺于17世纪莫斯科公国式的君民神秘纽带幻象，与现代都市社会彻底隔绝；而底层农民与士兵在抛弃沙皇神圣权威后，同样以缺乏宪政法治观念的村社报复与社会颠倒（“人民的悲剧”）埋葬了民主转型可能（`RN-W5-peasant-soldier-revolution-and-tragedy`）。

## [T3] 深度考证、分期细目与原文引证档案

### 3.1 派普斯（1990）论尼古拉二世的“家产制（Patrimonial）”意识形态
- 对接 [`CLM-pipes-1990-patrimonial-state-and-intelligentsia`](../../historiography/claims/CLM-pipes-1990-patrimonial-state-and-intelligentsia.md) 与精读札记 [`RN-W4B-patrimonialism-and-october-coup`](../../reading-notes/pipes_1990_russian_rev/RN-W4B-patrimonialism-and-october-coup.md)（`ch10_section.md L41–124`）：
  - 派普斯指出，至1900年俄国在经济与社会层面已大体脱离家产制，唯独尼古拉二世与宫廷仍将主权（sovereignty）与所有权（ownership）混为一谈，把帝国官僚视为对君主个人而非国家效忠的家臣，并在皇后亚历山德拉“你与俄罗斯合而为一（You and Russia are one and the same）”的强化下，将“知识分子（*intelligentsia*）”痛恨为必须从俄国词典中抹去的瘟疫（`ch10 L74–124`）。
  - 据Pipes（1990，ch10_section，L41–94），皇室保留以君主个人为中心的主权观，与社会变化及政治参与诉求发生冲突；这是对其家产制解释的概述，并非逐字引文。

- **处决的证据层次**：乌拉尔机关实施、沙皇一家及随从被杀是已知事实；中央何时知情、是否事先批准及授权范围仍待证据厘清。Pipes依据当事人回忆和后述证言提出中央归责解释（`ch26_section.md`），这些回忆和证言属于事后材料，并非已发现列宁下令处决全家的文件。

### 3.2 长谷川毅（2018）对1917年2月24日–3月3日沙皇电令与退位时序的档案考订
- 对接 [`CLM-hasegawa-2018-duma-committee-revision`](../../historiography/claims/CLM-hasegawa-2018-duma-committee-revision.md)、[`CLM-hasegawa-2018-dual-power-origins`](../../historiography/claims/CLM-hasegawa-2018-dual-power-origins.md) 及精读札记 [`RN-W1C-february-insurrection-and-dual-power`](../../reading-notes/hasegawa_february_1917/RN-W1C-february-insurrection-and-dual-power.md)：
  1. **2月24日晚首封告警电与2月25日晚9时镇压严令**：
     - 依据 S. V. Kulikov 档案研究，大臣会议主席戈利岑于 `1917-02-24 [O.S.] / 1917-03-09 [N.S.]` 当晚即向莫吉廖夫大本营发出首封报告首都街头骚乱的电报（`ch21, p. 233 & fn. 44`）。
     - `1917-02-25 [O.S.] / 1917-03-10 [N.S.]` 晚9时，尼古拉二世向彼得格勒军区司令哈巴洛夫发出决定性电令：**“朕命令你明天务必平息首都的骚乱（I command you tomorrow to put an end to the disorders in the capital）”**（`ch22, p. 257`），执行中镇压升级，2月26日发生涅夫斯基大街排枪；近卫军哗变还涉及群众运动、部队部署及军纪裂解；同晚26日，面对罗将柯告警长电，沙皇对宫廷大臣弗雷德里克斯嘲讽道：“这个胖子罗将柯又给我写了一堆废话，我连回都不会回他”（`ch23, pp. 274–275`）。
  2. **3月2日普斯科夫退位与3月3日君主制法统断绝**：
     - `1917-02-27 [O.S.] / 1917-03-12 [N.S.]` 晚，尼古拉二世拒绝米哈伊尔大公与罗将柯组建责任内阁的最后请求，促使国家杜马临时委员会于当晚11:30正式决定夺取最高行政权力（`ch27, pp. 369–378`）。
     - `1917-03-02 [O.S.] / 1917-03-15 [N.S.]` 尼古拉二世在普斯科夫签署退位诏书传位米哈伊尔大公；次日（`1917-03-03 [O.S.] / 1917-03-16 [N.S.]`）米哈伊尔大公在罗将柯、克伦斯基等劝说下拒绝即位，彻底斩断君主制法统（`ch40, pp. 620–631`）。
