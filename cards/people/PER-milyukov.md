## [T1] 150字定性微摘要
俄国历史学家、卡德特党核心领袖（1859–1943）。主持解放同盟确立四尾制宪与有偿征地纲领；一战任进步同盟舵手，1916年发表“愚蠢还是叛国”演说；1917年任首届临时政府外长，03-03/03-16架空杜马，因04-18[O.S.]/05-01[N.S.]照会下野，流亡提“新策略”。

## [T2] 核心脉络、关系网络与史学争鸣

### 2.1 核心历史脉络（19世纪俄国内 +12 天，1900.03–1918.01 俄国内 +13 天，西欧流亡依公历 `[N.S.]`）
- **史学名家、解放同盟与卡德特建党（1859–1905）**：`1859-01-15 [O.S.] / 1859-01-27 [N.S.]` 生于莫斯科建筑师家庭。莫斯科大学历史学家，以《俄国文化史大纲》确立“国家学派”与西方宪政发展观；1895年因政治讲演遭革职流放并赴欧美讲学。1902–1904年参与组织“解放同盟”（*Soyuz Osvobozhdeniya*），1904年10月起草“四尾制”（普遍、平等、直接、秘密）立宪会议选举与按公正估价强制征地政纲；1905年5月出任跨职业“全俄各工会联合会”（Union of Unions）主席（Haimson 1987 `ch23 n.12`），旋即在 `1905-10-12`–`10-18 [O.S.] / 10-25`–`10-31 [N.S.]` 莫斯科建党大会后成为 `ORG-kadets`（人民自由党）的灵魂领袖（`CLM-treadgold-1955-kadet-agrarian-and-tactical-failure`, `p. 144`）。
- **杜马反对派与六三体制困境（1905–1914）**：1905年坚决抵制社会主义者“杯葛杜马选举”的战术，斥其为“政治自杀”，同时坚决拒在党纲中宣布共和国或美化革命暴力，强调“革命只是手段而非目的”（`CLM-treadgold-1955-four-party-competition-1905`, `pp. 138–139, 201–216`）。在第一届（179席，1906年拒入 `PER-stolypin` 内阁后被解散，同僚另发《维堡宣言》被剥夺参选权，米留可夫本人因未当选第一、二届议员而幸免于刑）与第二届杜马幕后指挥党团；自1907年第三届杜马起亲任彼得堡议员与卡德特议会党团领袖，在 `1907-06-03 [O.S.] / 06-16 [N.S.]` 六三选举法下讽第三届杜马为“老爷与奴才的杜马”，却也面对党内地方缙绅右翼趋附新选举法的裂痕（`CLM-manning-1982-june-third-coup-social-basis`, `p. 239`）。
- **“进步同盟”、“愚蠢还是叛国”与二月宪制断层（1914–1917.05）**：一战爆发后坚决主战与夺取博斯普鲁斯海峡—君士坦丁堡，1915年8月主导组建跨党派 `ORG-octobrists-and-progressive-bloc`（进步同盟），策略性撤回“对杜马负责内阁”、改倡模糊的“信任内阁（*ministerstvo doveriya*）”，借此防止 `PER-guchkov` 实权派抢位、又回避组织虚弱的卡德特独力收拾战局（`CLM-gaida-2003-progressive-bloc-dilemma`, `pp. 135–136, 166–168`）。`1916-11-01 [O.S.] / 1916-11-14 [N.S.]` 在第四届杜马第五届会议开幕式发表轰动全国的演说，连续列举传闻指斥皇后与首相施蒂默尔并诘问：**“这是什么，愚蠢还是背叛？”**（Gaida 考证该演说曾同协约国外交官协调而非与进步同盟盟友协调，且米留可夫次日仍在编辑部断言革命“还早着呢”，`ch12` `pp. 322–323`）。`1917-02-27 [O.S.] / 03-12 [N.S.]` 在塔夫利达宫被动卷入二月权力真空（曾短促寄望保留罗曼诺夫君主立宪外壳，遭起义兵工压力与米哈伊尔拒位否决）；**`1917-03-03 [O.S.] / 1917-03-16 [N.S.]` 在临时政府首次内阁会议上**，米留可夫排挤 `PER-rodzianko`，主导草案宣称《基本法》因政变失效、全部国家全权由临时政府不受杜马制约独立行使（按 `ORG-kadets` 与 Hasegawa `pp. 626–631` 考证，内阁秘书格林卡拒签正式纪要且政府未发正式法条废除《基本法》第87条，但在政治上彻底切断了对杜马代议制锚点的从属）。就任首任外交部长后，于 `1917-03-23 [O.S.] / 1917-04-05 [N.S.]` 公开宣称夺取海峡、`03-27 [O.S.] / 04-09 [N.S.]` 迫于苏维埃发出妥协宣言，旋于 **`1917-04-18 [O.S.] / 1917-05-01 [N.S.]`** 向协约国发出附有说明的所谓 **“米留科夫照会”**（其重申恪守盟约“决定性胜利”及获取“保障与制裁”之内容未获彼得格勒苏维埃认可；至于临时政府内阁事前审议与事后背书程序，须据内阁会议纪要原件分别查明），激起 `04-20`–`04-21 [O.S.] / 05-03`–`05-04 [N.S.]` 四月危机武装示威并迫使其于 **`1917-05-02 [O.S.] / 1917-05-15 [N.S.]`** 辞去外长职务（由捷列先科接任）。
- **顿河白卫、巴黎流亡与“新策略”分裂（1917.10–1943）**：支持科尔尼洛夫整顿秩序（虽未入其新政权最终既定名单却在政界声援强人路线），十月革命后于 `1917-11-28 [O.S.] / 12-11 [N.S.]` 遭人民委员会“人民公敌党”法令通缉，南下顿河新切尔卡斯克参与阿列克谢耶夫与科尔尼洛夫志愿军早期政治架构（Figes `ch19`；1918年一度因在基辅试探同德军交涉以反布尔什维克遭白卫右翼与卡德特同僚痛斥并暂退）。流亡巴黎后主编俄侨大报《最新消息报》（*Posledniye Novosti*），提出承认苏维埃内部演变与农民既成事实、反对纯靠外国武装干涉复辟的 **“新策略（новая тактика）”**，致使 `ORG-kadets` 于1920–1921年在流亡中正式分裂；撰写《俄国第二次革命史》奠定俄国自由主义史学范式，二战德占期间仍在流亡中呼吁支持祖国抗德，`1943-03-31 [N.S.]` 逝于法国艾克斯莱班。

### 2.3 多视角史学争鸣与阐释边界
- **经验共识**：米留可夫是1905–1917年俄国宪政自由主义最具国际声望与议会手腕的领袖，也是1917年春坚持“将战事进行到决定性胜利”并亲手断绝临时政府同第四届杜马宪制纽带的关键推手。
- **核心争鸣（详参 `DEB-1914-haimson-thesis-stability` 与 `DEB-1917-dual-power-and-february-origins`）**：
  - **“叹着气的革命者”与组织空壳论（Fedor Gaida, 2003）**：据俄国警政与卡德特档案拆解“自由派早有革命密谋”神话——`1916-11-01 [O.S.] / 1916-11-14 [N.S.]`“愚蠢还是叛国”虽轰动一时，实则“连党内盟友都未预先协调”；战争中“信任内阁”只是在防备极右夺权与逃避崩盘责任间走钢丝，二月塔夫利达宫接权更只是作为“场所”而非“机构”的被动占领（`CLM-gaida-2003-progressive-bloc-dilemma`, `CLM-gaida-2003-liberals-in-february-1917`）。
  - **自毁宪制合法性悖论（Tsuyoshi Hasegawa, 2018）**：长谷川毅（`CLM-hasegawa-2018-dual-power-origins`, `pp. 626–638`）反转传统“苏维埃主动让权”说，指出正是 `1917-03-03 [O.S.] / 1917-03-16 [N.S.]` 米留可夫排挤罗将柯、宣布不再召集杜马、拒绝对代议机关负责（同时未正式立法废除第87条），把临时政府推入只有“革命政变”却无民选根基的悬空状态——“米留可夫赢了，但代价是亲手否定了临时政府唯一的法统基石”。
  - **1905四党竞争与卡德特的阶级两难（Donald W. Treadgold, 1955; Roberta T. Manning, 1982）**：Treadgold 揭示米留可夫“拒绝神化革命、只许有偿征地”的欧洲式温和宪政路线在革命海啸中被工农弃绝；Manning 则进一步从社会史揭示六三政变后部分地方缙绅卡德特迅速右转拥护保守选举机器，映照米留可夫议会政治所依赖的脆弱社会底座。
  - **自由派极权批判与俄国内战反省（Richard Pipes, 1990; Orlando Figes, 1996; 斯皮岑新传统派）**：Pipes 总体肯定卡德特的法治理想，但也指出米留可夫与自由派缺乏统治帝国所需之行政决断；Figes 刻画米留可夫十月后赴顿河却与白卫怀旧派同样无法回应农民与民族诉求；当代俄国保守派如斯皮岑（`CLM-spitsyn-february-1917-elite-conspiracy-thesis`）则将米留可夫“愚蠢还是叛国”演说直接归入“自由派—共济会—将领颠覆沙皇救国秩序”的灾难起点（需警惕其浓厚阴谋论预设与反西方修辞）。
