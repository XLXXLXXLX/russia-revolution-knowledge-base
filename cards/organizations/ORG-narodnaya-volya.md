## [T1] 60秒定性微摘要
1879年8月由第二代“土地与自由社”分裂产生的俄国激进民粹派秘密政党，由执行委员会（热利亚博夫、佩罗夫斯卡娅、菲格涅尔等）实行集中地下领导，将推翻沙皇专制、争取立宪会议的政治斗争置于首位；1881年刺杀亚历山大二世后遭严酷镇压，经1883年杰加耶夫叛变至1887年乌里扬诺夫密谋失败而瓦解。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络
- **转向政治斗争与分裂（1878–1879）**：“到民间去”受挫与警察镇压促使部分民粹派反思纯农村鼓动的局限；`1879-06-15 [O.S.] / 1879-06-27 [N.S.]` 利佩茨克秘密会议确立集中密谋与政治刺杀方针，`1879-08-15 [O.S.] / 1879-08-27 [N.S.]` 与“土地平分社”正式分立。
- **执委会网络与“三月一日案”（1879–1881）**：建立地下印刷所、炸药工坊及工人、军官支部；于 `1881-03-01 [O.S.] / 1881-03-13 [N.S.]` 炸死亚历山大二世，`1881-03-10 [O.S.] / 1881-03-22 [N.S.]` 发表致亚历山大三世公开信要求政治大赦与普选立宪会议；`1881-04-03 [O.S.] / 1881-04-15 [N.S.]` 热利亚博夫、佩罗夫斯卡娅等五人被处绞刑。
- **警方渗透、余波与终结（1882–1887）**：1882–1883年因谢尔盖·杰加耶夫被暗探局苏杰伊金策反，维拉·菲格涅尔被捕（`1883-02-10 [O.S.] / 1883-02-22 [N.S.]`），国内中央瘫痪；1884年洛帕京重建尝试失败；`1887-03-01 [O.S.] / 1887-03-13 [N.S.]` 亚历山大·乌里扬诺夫等“民意党恐怖派”谋刺亚历山大三世未遂被处决（`1887-05-08 [O.S.] / 1887-05-20 [N.S.]`）；残余传统经1890年代新民粹派小组于1901年末—1902年初合流为社会革命党（SR）。

### 2.3 史学争鸣光谱（Historiographical Spectrum）
- **经验共识**：民意党标志着俄国民粹派内部从巴枯宁式“反政治主义”向直接挑战沙皇国家政权的重大策略转向，同时女性革命者在最高执委会中占据罕见高比例。
- **主要解释分歧**：
  - **[观念与运动史学派 / Franco Venturi]** (`BIB-001`)：强调执委会《纲领》与《致亚历山大三世信》中的民主立宪诉求（言论自由、普选立宪会议），反对将其简单约化为布朗基式独裁团伙。
  - **[马克思、恩格斯晚年同情评价]**：马恩高度赞赏民意党人的革命胆识，并在1882年《共产党宣言》俄文版序言中设想俄国革命若成为西方无产阶级革命信号，村社或可成为共产主义发展起点。
  - **[俄国马克思主义批判 / 普列汉诺夫、列宁]**：与马恩的同情存在明显张力——普列汉诺夫系统批判其忽视俄国资本主义既成事实与脱离群众的个人恐怖；列宁在批判恐怖替代群众运动的同时，汲取其严密职业革命家组织经验。
  - **[保守自由派连续性叙事 / Richard Pipes]** (`BIB-012`)：将民意党的秘密警察对决与少数精英暴力视为直通布尔什维克政治文化的源头。
