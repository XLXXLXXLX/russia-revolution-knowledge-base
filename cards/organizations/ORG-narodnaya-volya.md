## [T1] 150字定性微摘要
1879年夏秋自土地与自由社分裂产生的俄国激进民粹派秘密政党，由执行委员会实行集中地下领导。该党虽以政治刺杀挑战沙皇专制并在1881年3月炸死亚历山大二世，其1879年纲领与致新皇信仍明确诉诸立宪会议与普选自由，绝非纯虚无暗杀团伙；1883年前后国内中枢瓦解。

## [T2] 核心脉络、时效关系边表与史学争鸣光谱

### 2.1 核心历史脉络（严守19世纪俄历转公历 +12 天规则）
- **1879年分裂与集中制确立（1879.06–09）**：`1879-06-17`–`06-21 [O.S.] / 1879-06-29`–`07-03 [N.S.]` 利佩茨克会议确立选举集中制与执委会最高权威，但 `PER-zhelyabov` 等人以民粹社会良知否决了莫罗佐夫纯政治反专制草案；经 `1879-06-24 [O.S.] / 07-06 [N.S.]` 沃罗涅日妥协失败后，据文图里依回忆录重构（`p. 656`；同书第29章年表另见 `1879-11-18` 异文，原始分立会议记录尚缺），执委会于 `1879-08-26 [O.S.] / 1879-09-07 [N.S.]` 宣判 `PER-alexander-ii` 死刑，并于 `1879-09-12 [O.S.] / 1879-09-24 [N.S.]` 正式宣告完全自治、与 `ORG-chernyi-peredel` 分割印刷所与资金（`CLM-venturi-1960-lipetsk-voronezh-split`, `p. 656`）。
- **1879年《执委会纲领》中的立宪诉求与国家社会学**：与“纯粹暗杀虚无主义”刻板印象相反，执委会（通归季霍米罗夫起草、于 `1880-01-01 [O.S.] / 1880-01-13 [N.S.]` 首刊于党报第3号）在《纲领》中指出沙皇国家本身即是俄国“最大的地主与最大的资本主义力量”，既无法指望懦弱资产阶级，革命党须用政治颠覆夺权并立即移交普选产生的**立宪会议（Учредительное собрание）**——同时设立言论、出版、集会与竞选完全自由，将土地归人民、工厂交工人、保卫村社与地方自治；执委会明确抨击特卡乔夫式长期党专政为“专制乌托邦”，仅在民众毫无生气的“最坏情形”下保留临时革命政府应急选项（`CLM-venturi-1960-narodnaya-volya-constitutionalism`, `pp. 667–681`）。
- **“三月一日案”与《致亚历山大三世公开信》（1881.03–04）**：经铁路与冬宫多次未遂爆破后，`PER-zhelyabov` 于行动前被捕，`PER-perovskaya` 临危接掌现场指挥，于 `1881-03-01 [O.S.] / 1881-03-13 [N.S.]` 在圣彼得堡叶卡捷琳娜运河旁炸毙 `PER-alexander-ii`（`EVT-1881-03-assassination-of-alexander-ii`）。九日后执委会署 `1881-03-10 [O.S.] / 1881-03-22 [N.S.]` 发表《致亚历山大三世信》（`03-12 [O.S.] / 03-24 [N.S.]` 付印；`WEB-1881-03-10-letter-to-alexander-iii`），声明只要满足两项条件——政治犯全面大赦、由全俄各阶级按人口比例自由选举**“人民会议”（народное собрание）**（信面用此词而非“立宪会议”，选举期间实行四项完全自由）——民意党即停止武装斗争并解散战斗机关。沙皇拒绝对话，“三月一日案”于 `1881-03-26`–`03-29 [O.S.] / 04-07`–`04-10 [N.S.]` 开庭，热利亚博夫、佩罗夫斯卡娅、基巴尔契奇、季·米海洛夫与雷萨科夫五人于 `1881-04-03 [O.S.] / 04-15 [N.S.]` 被绞决。
- **瓦解、杰加耶夫叛变与1887年余波边界（1882–1887）**：虽获马克思、恩格斯在 `1882-01-21 [N.S.]` 《共产党宣言》俄文二版序言中的革命敬意（预印于《民意》第8–9号 `1882-02-05 [O.S.] / 02-17 [N.S.]`），但国内组织并未激起农民起义，反而消耗了大量骨干。因军官成员谢尔盖·杰加耶夫被保安局苏杰伊金策反，留守执委会最后的支柱 `PER-figner` 于 `1883-02-10 [O.S.] / 1883-02-22 [N.S.]` 在哈尔科夫被捕，1879年执委会的国内中枢自此彻底瘫痪；1884年洛帕京重建再次受挫，至于 `1887-03-01 [O.S.] / 03-13 [N.S.]` 亚历山大·乌里扬诺夫等“民意党恐怖派”谋刺亚历山大三世未遂及 `1887-05-08 [O.S.] / 05-20 [N.S.]` 处决，仅属原党瓦解后独立重组小圈子的直接余波（本卡据此将 `1887-05-20` 列为**分析性余波终点锚点**，并非原执委会连续存续至1887年的组织实证）。其零星人脉经1890年代新民粹派小组汇入 `ORG-psr`。

### 2.3 多视角史学争鸣与阐释边界
- **经验共识**：民意党执委会打破了70年代民粹派反政治主义传统，在工人、军官与青年知识分子中建起高效率地下技术网络（含空前比例的女性领导者），却因未能动员农民响应而随1881年镇压与1883年叛变迅速崩溃。
- **核心争鸣（详参 `DEB-1879-narodnaya-volya-to-bolshevism`）**：
  - **立宪主义与“吃老本”策略论（Franco Venturi, 1960）**：正本清源地拆解“纯虚无主义暗杀团伙”冷战标签，揭示执委会纲领与致亚历山大三世信包含严密的普选立宪会议与自由权利方案，同时指出奥沙尼娜—列别捷娃应急专政条款内的雅各宾张力，以及热利亚博夫“靠老本过活（living on capital）”赌注的脆弱性（`CLM-venturi-1960-narodnaya-volya-constitutionalism`）。
  - **道德人类学与反决定论（Isaiah Berlin, 1960）**：认为民意党暴力始终在个人良知审查与自由契约界限内运作，即使走上恐怖道路也与列宁主义历史决定论党国哲学本质异质（`CLM-berlin-1960-populism-moral-core`）。
  - **反“雅各宾”谱系考古与爱尔福特重审（Robert Mayer, 1999; Lars T. Lih, 2006）**：彻底切断“民意党→布尔什维克”的直线意识形态投射——菲格涅尔与季霍米罗夫本人公开拒斥“雅各宾”称谓（除奥沙尼娜等极个别外）；`PER-lenin` 在《怎么办？》中是借70年代地下技艺服务于德国SPD式群众政党路线，其1904年“雅各宾”隐喻系反击 `PER-plekhanov` 1901年修辞，而非认祖特卡乔夫或民意党（`CLM-mayer-1999-lenin-jacobin-metaphor-vs-blanquism`, `CLM-lih-2006-erfurtian-merger-formula`）。
  - **马恩赞誉与俄国马派批判的张力**：1882年《宣言》序言视俄国刺沙皇斗争为“欧洲革命运动前卫”，而 `PER-plekhanov` 等则敏锐抓住执委会忽视资本主义现实与工人阶级自觉运动的致命缺陷；冷战保守派（`CLM-pipes-1990-patrimonial-state-and-intelligentsia`）将执委会与布尔什维克单线相连，在史学实证上忽略了二者在国家观与党群众关系上的根本断层。
